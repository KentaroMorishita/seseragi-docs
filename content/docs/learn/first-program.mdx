荷物が準備中なら「Preparing」、発送済みなら発送先の都市名を表示します。配送状態を表す型と、表示する文字列を返す関数を作ります。

## 状態を表す型

準備中と発送済みを、`Parcel`という型の二つのケースとして定義します。

```seseragi
type Parcel =
  | Packing
  | Sent String
```

`Packing`は準備中を表します。`Sent`は発送済みを表し、発送先の都市名を`String`として持ちます。このように複数のケースからなる型を、代数的データ型と呼びます。

`Sent "Kyoto"`と書くと、発送先がKyotoの値を作れます。`Packing`と`Sent "Kyoto"`は、どちらも`Parcel`です。

## 状態から文字列を作る

`label`は`Parcel`を受け取り、表示する`String`を返す関数です。

```seseragi
fn label parcel: Parcel -> String =
  match parcel {
    Packing -> "Preparing"
    Sent city -> `Sent to ${city}`
  }
```

`fn`の後ろに関数名と引数を書きます。`parcel: Parcel`は引数とその型、最後の`String`は結果の型です。`=`の右側に本体の式を書きます。

`match`は、受け取った値がどのケースに一致するかを調べます。`Packing`なら`"Preparing"`を返します。`Sent city`なら、値に含まれる発送先を`city`として取り出します。

バッククォートで囲んだ文字列では、`${city}`の位置に値を埋め込めます。`Sent "Kyoto"`を受け取った場合の結果は`"Sent to Kyoto"`です。

## 関数をつないで出力する

関数を呼び出すには、名前の後ろに引数を空白で並べます。たとえば、`label (Sent "Kyoto")`は発送済みの値を`label`へ渡します。

`|>`を使うと、左側の値を右側の関数へ渡せます。

```seseragi
pub effect fn main =
  Sent "Kyoto"
  |> label
  |> println
```

まず`Sent "Kyoto"`を`label`へ渡し、その結果の文字列を`println`へ渡します。

`main`はプログラムの入口です。画面への出力を伴うため、`pub effect fn`で宣言します。`label`は文字列を返す通常の関数で、出力は`println`が行います。

## 完成したプログラム

```seseragi title="parcel.ssrg"
type Parcel =
  | Packing
  | Sent String

fn label parcel: Parcel -> String =
  match parcel {
    Packing -> "Preparing"
    Sent city -> `Sent to ${city}`
  }

pub effect fn main =
  Sent "Kyoto"
  |> label
  |> println
```

実行すると、次の一行を出力します。

```text title="実行結果"
Sent to Kyoto
```

[Playground](https://seseragi.vercel.app/)へ完成したコードを貼り付けて実行してください。CLIが使える場合は、`parcel.ssrg`へ保存して次のコマンドで実行できます。

```sh
seseragi run parcel.ssrg
```

## 状態を変えてみる

`main`の`Sent "Kyoto"`を`Packing`に置き換えると、出力は`Preparing`になります。都市名を`"Sapporo"`へ変えると、`Sent to Sapporo`になります。

次に、`Parcel`へ新しいケース`Arrived`を追加してみてください。`label`の`match`にはそのケースを処理する分岐がないので、コンパイルエラーになります。すべてのケースを扱うことで、処理の抜けを実行前に確認できます。

## TypeScriptで書くと

TypeScriptでは、判別用のフィールドを持つユニオン型と、`switch`で同じ状態を表せます。

```ts
type Parcel =
  | { kind: "packing" }
  | { kind: "sent"; city: string };

function label(parcel: Parcel) {
  switch (parcel.kind) {
    case "packing":
      return "Preparing";
    case "sent": {
      const { city } = parcel;
      return `Sent to ${city}`;
    }
  }
}

console.log(label({
  kind: "sent",
  city: "Kyoto",
}));
```

Seseragiでは、`Packing`と`Sent`というケースを型の宣言に直接書きます。`match`の`Sent city`でケースの判別と都市名の取り出しを一緒に行えます。
