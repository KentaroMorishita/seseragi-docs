---

まずは`Hello, Seseragi!`と表示するプログラムを動かしてみましょう。表示できたら、文字列を変えてもう一度実行します。

## 一行を表示する

{/* example: examples/hello.ssrg */}

```seseragi title="hello.ssrg"
pub effect fn main =
  println "Hello, Seseragi!"
```

`main`は、プログラムを実行したときに最初に呼ばれる関数です。`pub`はこの関数を外から呼べるように公開する印、`effect fn`は画面への出力のような副作用を行う関数の印です。

`println`は、文字列を一行表示する関数です。Seseragiでは、関数に引数を渡すときに括弧を使わず、関数名の後ろに空白を空けて引数を書きます。

## ブラウザで実行する

[Playground](https://seseragi.vercel.app/)を開き、上のコードを貼り付けて実行してください。インストールは要りません。

実行すると、次の一行が表示されます。

```text title="実行結果"
Hello, Seseragi!
```

## 手元で実行する

CLIを使う場合は、上のコードを`hello.ssrg`という名前で保存します。CLIをまだ入れていなければ、先に[ローカルで使う](/docs/learn/local-development)の手順で用意してください。

保存したディレクトリで、次のコマンドを実行します。

```sh
seseragi run hello.ssrg
```

同じ`Hello, Seseragi!`が表示されます。

## 表示する文字列を変える

`"Hello, Seseragi!"`を`"Hello, Kyoto!"`に書き換えて、もう一度実行してください。表示も`Hello, Kyoto!`に変わります。

自分の名前や好きなメッセージにしても構いません。文字列の両端のダブルクォートは消さないでください。
