まず、`Hello, Seseragi!`を表示するプログラムを実行します。表示できたら文字列を変えて、もう一度実行してみましょう。

## 一行を表示する

{/* example: examples/hello.ssrg */}

```seseragi title="hello.ssrg"
pub effect fn main =
  println "Hello, Seseragi!"
```

`main`がプログラムの入口です。`pub`で入口を公開し、出力を行うため`effect fn`で宣言します。

`println`は文字列を一行表示する関数です。関数名の後へ、空白で区切って`"Hello, Seseragi!"`を渡します。ダブルクォートは文字列の始まりと終わりを表します。

## ブラウザで実行する

[Playground](https://seseragi.vercel.app/)を開き、上のコードを貼り付けて実行してください。インストールは不要です。

実行すると、次の一行が表示されます。

```text title="実行結果"
Hello, Seseragi!
```

## 手元で実行する

CLIを使う場合は、上のコードを`hello.ssrg`に保存します。まだ導入していなければ、[ローカルで使う](/docs/learn/local-development)の手順を先に確認してください。

ファイルを保存した場所で、次のコマンドを実行します。

```sh
seseragi run hello.ssrg
```

同じ`Hello, Seseragi!`が表示されます。

## 表示する文字列を変える

`"Hello, Seseragi!"`を`"Hello, Kyoto!"`に変え、もう一度実行してください。表示も`Hello, Kyoto!`へ変わります。

文字列の内容を自分の名前や好きなメッセージに変えても構いません。両端のダブルクォートは残してください。
