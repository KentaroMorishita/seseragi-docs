title: "再帰"
description: "終了条件を決め、局所関数と末尾再帰で入力を小さくして計算する。"
---

再帰では、関数が自分を呼び出して問題を小さくします。まず小さい整数の階乗で終了条件を確認し、その後で合計、相互再帰、木の処理へ進みます。

## 小さい例で終了を確認する

階乗は、5なら`5 * 4 * 3 * 2 * 1`です。次の宣言をモジュールに置きます。

{/* example: examples/learn/focused/recursion-factorial.ssrg#declaration */}
```seseragi title="関数の宣言"
fn factorial n: Int -> Int =
  if n <= 1 then
    1
  else
    n * factorial (n - 1)
```

次は`main`内の束縛です。

{/* example: examples/learn/focused/recursion-factorial.ssrg#inputs */}
```seseragi title="main内の束縛"
let zero = factorial 0
let five = factorial 5
```

`zero`は1、`five`は120です。`n <= 1`なら終了し、それ以外は小さくした`n - 1`で同じ関数を呼びます。この実装は負の入力にも1を返します。入力の範囲を拒否したい場合は、呼ぶ前に検査するなどの方針を決めます。

再帰の後に乗算が残るので、この関数は末尾再帰ではありません。ここでは小さい入力で構造を確かめます。大きい入力の扱いは、次の合計の例で見ていきます。

## 終了条件と次の入力を決める

{/* example: examples/learn/recursion.ssrg */}
```seseragi title="recursion.ssrg"
fn sumUpTo limit: Int -> Int = {
  fn loop n: Int -> total: Int
    -> Int =
    if n <= 0 then
      total
    else
      loop (n - 1) (total + n)

  loop limit 0
}

pub effect fn main =
  100000
  |> sumUpTo
  |> show
  |> println
```

```text title="実行結果"
5000050000
```

`loop n total`で`n <= 0`なら終了です。そうでなければ、`n`を一つ減らし、`total`へ現在の`n`を足して、同じ関数を呼びます。どちらの分岐も`Int`を返します。

`sumUpTo`に負の値を渡すと、この定義では0を返します。入力を受け入れる範囲と、範囲外の入力をどう扱うかは関数の設計です。再帰という構文自体が、正の入力や終了を保証するわけではありません。

## 局所関数で必要な引数を保つ

`loop`は`sumUpTo`のブロック内で宣言しています。外から呼べるのは`sumUpTo`で、計算途中の`total`を渡す必要はありません。

局所関数は、自分の名前と、宣言より前の束縛を参照できます。宣言より後の局所的な値や関数を暗黙に取り込むことはできません。関数の引数と戻り値には型を書き、再帰しても結果型が安定するようにします。

## 末尾再帰を見分ける

この`loop`では、再帰呼び出しの結果をそのまま返します。呼び出しの後に加算などの処理が残っていません。これが末尾位置の直接自己再帰です。

Seseragiは、通常の純粋な関数の直接自己末尾呼び出しを、入力件数に比例してhostの呼び出しスタックが増えない形で実行します。この例は100000回分の計算を確認しています。

`n + sumUpTo (n - 1)`のように結果へ加算を残した呼び出し、相互再帰、部分適用した関数やcallbackを経由した呼び出しには、同じ保証はありません。`effect fn`にも純粋関数用の同期ループの保証をそのまま当てはめません。詳しい範囲は[パフォーマンス](/docs/reference/performance)を参照してください。

## 相互再帰はrecでまとめる

二つの関数が互いを呼ぶ場合は、関数のブロック内の同じ`rec`グループに置きます。`rec { ... }`をモジュールのトップレベルへ直接置くことはできません。次はモジュールに置く通常の関数です。

{/* example: examples/learn/focused/recursion-mutual.ssrg#declaration */}
```seseragi title="関数の宣言"
fn parity n: Int -> String = {
  rec {
    fn even n: Int -> Bool =
      if n == 0 then True
      else odd (n - 1)

    fn odd n: Int -> Bool =
      if n == 0 then False
      else even (n - 1)
  }
  if even n then "even" else "odd"
}
```

`parity 6`は`even`、`parity 7`は`odd`です。内側のevenとoddは、同じグループにある相手を参照します。

これは0以上を想定した定義です。負の値なら0へ近づかないので終了しません。また、相互再帰には直接自己末尾再帰のスタック保証がないため、大きい入力を扱う実装の代わりに使う例ではありません。

### 再帰的なデータをたどる

再帰は、データの中に同じ型が現れる場合にも使えます。次の型は、葉一つか、二つの木を組み合わせた枝です。モジュールに置く宣言です。

{/* example: examples/learn/focused/recursion-tree.ssrg#data */}
```seseragi title="型の宣言"
type Tree =
  | Leaf
  | Branch (Tree, Tree)
```

葉の数を数える関数では、葉なら1、枝なら左右の結果を足します。

{/* example: examples/learn/focused/recursion-tree.ssrg#declaration */}
```seseragi title="関数の宣言"
fn countLeaves tree: Tree -> Int =
  match tree {
    Leaf -> 1
    Branch (left, right) -> {
      let leftCount =
        countLeaves left
      let rightCount =
        countLeaves right
      leftCount + rightCount
    }
  }
```

次は`main`内の使い方です。

{/* example: examples/learn/focused/recursion-tree.ssrg#input */}
```seseragi title="main内の式"
let pair = Branch (Leaf, Leaf)
Branch (pair, Leaf)
|> countLeaves
|> show
|> println
```

結果は3です。各Branchでは左右をそれぞれたどり、Leafに到達するとその呼び出しが終わります。左右の結果を足す処理が残るので、これも末尾再帰ではありません。

## コレクションの処理と使い分ける

合計だけなら、rangeと`sum`でも表せます。標準の走査関数で目的を表せる場合は、その関数を使うと終了や処理順を読み取りやすくなります。

再帰は、木のように再帰的なデータを処理したり、次の入力を自分で選ぶ処理に使えます。Arrayを毎回先頭と残りへ分ける場合のコストは、[ArrayとList](/docs/learn/arrays-and-lists)で扱っています。

## 境界を試す

`main`の100000を0、1、5へ変えると、それぞれ0、1、15です。終了条件を削除すると、入力を減らし続けるだけになり、結果を返せません。終了に近づく変化が毎回あるかを、再帰を読むときに確認してください。
