title: "再帰"
description: "終了条件を決め、局所関数と末尾再帰で入力を小さくして計算する。"
---

再帰は、関数が自分自身を呼び出して、問題を少しずつ小さくしていく書き方です。Arrayの`map`や`reduce`では書きにくい繰り返しも、再帰なら書けます。

この章では、階乗で再帰の基本を確かめてから、大きな数の合計、互いに呼び合う関数、木の形のデータへと進みます。

## 小さい例で終了を確認する

5の階乗は`5 * 4 * 3 * 2 * 1`です。再帰で書くと次のようになります。

{/* example: examples/learn/focused/recursion-factorial.ssrg#declaration */}
```seseragi title="関数の宣言"
fn factorial n: Int -> Int =
  if n <= 1 then
    1
  else
    n * factorial (n - 1)
```

{/* example: examples/learn/focused/recursion-factorial.ssrg#inputs */}
```seseragi title="main内の束縛"
let zero = factorial 0
let five = factorial 5
```

`zero`は1、`five`は120です。`n <= 1`なら1を返して終わり、そうでなければ一つ小さい`n - 1`で自分を呼びます。再帰では、この「終わる条件」と「入力を小さくすること」の二つが欠かせません。なお、この書き方だと負の数にも1を返します。

この`factorial`は、自分を呼んだあとに掛け算が残っています。このような再帰は、入力が大きいとスタックが足りなくなることがあります。大きな入力でも安全な書き方を、次の例で見ていきます。

## 終了条件と次の入力を決める

{/* example: examples/learn/recursion.ssrg */}
```seseragi title="recursion.ssrg"
fn sumUpTo limit: Int -> Int = {
  fn loop n: Int -> total: Int
    -> Int =
    if n <= 0 then
      total
    else
      loop (n - 1) (total + n)

  loop limit 0
}

pub effect fn main =
  100000
  |> sumUpTo
  |> show
  |> println
```

```text title="実行結果"
5000050000
```

`loop n total`は、`n`が0以下なら途中までの合計`total`を返して終わります。そうでなければ、`n`を一つ減らし、`total`に`n`を足して、もう一度自分を呼びます。

負の数を渡すと、この`sumUpTo`は0を返します。範囲外の入力をどう扱うかは、関数を書く人が決めることです。

## 関数の中に関数を書く

`loop`は`sumUpTo`の中で宣言したローカル関数です。外からは`sumUpTo`だけが見えるので、呼ぶ側が途中経過の`total`を渡す必要はありません。

ローカル関数の中では、自分自身と、それより前に`let`した値を使えます。後ろで宣言した値は使えません。再帰する関数には、引数と結果の型を書いてください。

## 末尾再帰

`loop`は、自分を呼んだ結果をそのまま返していて、そのあとに足し算などの処理が残っていません。このように、最後の処理として自分を呼ぶ再帰を末尾再帰と呼びます。

Seseragiは、末尾再帰をループに変換して実行します。何回繰り返してもスタックが増えないので、この例のように100000回でも問題なく動きます。

`n + sumUpTo (n - 1)`のように呼んだあとに処理が残る再帰や、次に出てくる互いに呼び合う再帰、引数で渡された関数を経由する呼び出しは、ループに変換されません。`effect fn`も対象外です。詳しくは[パフォーマンス](/docs/reference/performance)を見てください。

## 互いに呼び合う関数はrecでまとめる

ローカル関数どうしが互いを呼ぶときは、`rec { ... }`でまとめます。`rec`は関数の中でだけ使え、ファイルの一番外側には書けません。

{/* example: examples/learn/focused/recursion-mutual.ssrg#declaration */}
```seseragi title="関数の宣言"
fn parity n: Int -> String = {
  rec {
    fn even n: Int -> Bool =
      if n == 0 then True
      else odd (n - 1)

    fn odd n: Int -> Bool =
      if n == 0 then False
      else even (n - 1)
  }
  if even n then "even" else "odd"
}
```

`parity 6`は`even`、`parity 7`は`odd`です。`even`と`odd`は、同じ`rec`の中にある相手を呼んでいます。

この例は0以上の数を前提にしています。負の数を渡すと0に近づかないので、終わりません。また、互いに呼び合う再帰はループに変換されないので、大きな数には向きません。

### 再帰的なデータをたどる

再帰は、データの中に同じ型が入っている場合にも使えます。次の`Tree`は、「葉」か、「二つの`Tree`を持つ枝」のどちらかです。

{/* example: examples/learn/focused/recursion-tree.ssrg#data */}
```seseragi title="型の宣言"
type Tree =
  | Leaf
  | Branch (Tree, Tree)
```

葉の数を数える関数は、葉なら1、枝なら左右それぞれの葉の数を足して求めます。

{/* example: examples/learn/focused/recursion-tree.ssrg#declaration */}
```seseragi title="関数の宣言"
fn countLeaves tree: Tree -> Int =
  match tree {
    Leaf -> 1
    Branch (left, right) -> {
      let leftCount =
        countLeaves left
      let rightCount =
        countLeaves right
      leftCount + rightCount
    }
  }
```

{/* example: examples/learn/focused/recursion-tree.ssrg#input */}
```seseragi title="main内の式"
let pair = Branch (Leaf, Leaf)
Branch (pair, Leaf)
|> countLeaves
|> show
|> println
```

3と表示されます。枝では左右をそれぞれたどり、葉にたどり着くとそこで終わります。データの形がそのまま処理の形になっていることが分かります。

## 再帰と標準関数の使い分け

合計を求めるだけなら、`1..=100000 |> sum`のように範囲と`sum`でも書けます。標準の関数で書けるなら、そのほうが何をしているか分かりやすく、終わらない心配もありません。

再帰が向いているのは、木のように入れ子になったデータを処理するときや、次に何を処理するかを自分で決めるときです。

## 境界を試す

`main`の100000を0、1、5に変えると、それぞれ0、1、15になります。終わる条件の`if n <= 0`を消すと、いつまでも終わらなくなります。再帰を読むときは、呼ぶたびに入力が終わる条件に近づいているかを確かめてください。

次の[Effect](/docs/learn/effects)では、計算と、画面への出力のような外部とのやり取りを組み合わせます。再帰の細かい決まりは[関数](/docs/reference/functions)にあります。
