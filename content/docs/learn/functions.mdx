この章では、二つの整数を足す関数を作って呼び出すところから始めます。そのあと、引数を一部だけ渡す部分適用と、名前を付けずに関数を作るラムダを学びます。関数をつなぐ`|>`と、括弧を減らす`$`は、次の二つの章で扱います。

## 関数を宣言して呼び出す

関数は`fn 名前 引数: 型 -> 結果の型 = 本体`の形で宣言します。引数が二つあるときは、次のように`->`で並べます。

```seseragi
fn add x: Int -> y: Int -> Int =
  x + y
```

`add`へ20と22を渡す呼び出しは、次のように書きます。

```seseragi title="呼び出しの式"
add 20 22
```

関数名の後ろに、引数を空白で区切って並べます。TypeScriptの`add(20, 22)`にあたり、結果は42です。

宣言と呼び出しを合わせて、実行できるプログラムにしてみます。

{/* example: examples/learn/function-application.ssrg */}
```seseragi title="function-application.ssrg"
fn add x: Int -> y: Int -> Int =
  x + y

pub effect fn main = {
  let answer = add 20 22
  println `answer: ${answer}`
}
```

```text title="実行結果"
answer: 42
```

`add`は計算結果を返すだけの普通の関数です。`main`ではその結果に`answer`という名前を付け、前の章の文字列テンプレートで表示しています。

### 引数のない宣言を呼び出す

引数のない関数を呼び出すときは、`Unit`型の値`()`を渡します。次は、引数のない関数の宣言です。

{/* example: examples/learn/focused/function-unit.ssrg#declaration */}
```seseragi title="関数の宣言"
fn ready -> String = "ready"
```

`main`の中で、次のように呼び出して表示できます。

{/* example: examples/learn/focused/function-unit.ssrg#use */}
```seseragi title="main内の式"
ready ()
|> println
```

`ready`と表示されます。`ready ()`の`()`は、TypeScriptの「空の引数リスト」ではなく、`()`という一つの値を引数として渡しています。`()`を付けずに`ready`とだけ書くと、呼び出す前の関数そのものを指します。

## 一部の引数を渡す

`add`の型は`Int -> Int -> Int`です。これは`Int -> (Int -> Int)`、つまり「整数を一つ受け取って、『整数を一つ受け取って整数を返す関数』を返す関数」と読みます。そのため`add 1`は、残りの整数を一つ待っている関数になります。

`let increment = add 1`は「1を足す関数」です。`increment 20`を呼ぶと、`add 1 20`と同じ21になります。このように引数を一部だけ渡して新しい関数を作ることを、部分適用と呼びます。

## 式を一つの引数として渡す

引数に計算式を渡すときは、その式を括弧で囲みます。次の例は、先ほどの`add`を使います。

{/* example: examples/learn/focused/function-grouping.ssrg#arithmetic */}
```seseragi title="main内の束縛"
let grouped = add (20 + 1) 22
```

`20 + 1`が一つ目の引数になるので、`add`は21と22を受け取り、`grouped`は43です。この括弧は式をひとまとめにしているだけで、`add(20, 22)`のような呼び出しの括弧ではありません。

関数の結果を別の関数に渡すときも、同じように括弧で囲みます。ここでは、数を2倍にする`fn double n: Int -> Int = n * 2`も宣言してあるものとします。

{/* example: examples/learn/focused/function-grouping.ssrg#nested */}
```seseragi title="main内の束縛"
let nested = double (add 20 1)
```

`add 20 1`の結果の21が`double`に渡り、`nested`は42です。括弧が重なってきたら、[パイプライン](/docs/learn/pipelines)の`|>`や[関数適用演算子](/docs/learn/application-operator)の`$`で書き直せます。

## 名前を付けずに関数を作る

ラムダを使うと、`fn`で宣言せずにその場で関数を作れます。TypeScriptのアロー関数`(n) => n * 2`にあたります。

{/* example: examples/learn/focused/function-lambda.ssrg#lambda */}
```seseragi title="main内の束縛"
let double = \n: Int -> n * 2
```

作った関数は、普通の関数と同じように呼び出せます。

{/* example: examples/learn/focused/function-lambda.ssrg#call */}
```seseragi title="main内の式"
double 21
|> show
|> println
```

42と表示されます。引数の型が前後から分かる場合は、`\n -> n * 2`のように型を省けます。引数が二つなら`\x y -> x + y`です。[ArrayとList](/docs/learn/arrays-and-lists)では、ラムダを`map`や`filter`に渡して使います。

### 外側の値を使う関数を返す

関数は、結果として別の関数を返すこともできます。次の`prefixWith`は、接頭辞を受け取って「その接頭辞を名前の前に付ける関数」を返します。

{/* example: examples/learn/focused/function-closure.ssrg#declaration */}
```seseragi title="関数の宣言"
fn prefixWith prefix: String
  -> (String -> String) =
  \name -> `${prefix}${name}`
```

使い方は次のとおりです。

{/* example: examples/learn/focused/function-closure.ssrg#use */}
```seseragi title="main内の式"
let welcome = prefixWith "Hi, "
welcome "Aki"
|> println
```

`Hi, Aki`と表示されます。返されたラムダは、`prefixWith`の呼び出しが終わったあとも`prefix`の値を覚えています。このように外側の値を覚えている関数をクロージャと呼びます。覚えた値を書き換える方法はありません。`"Hello, "`を渡せば、別の接頭辞を覚えた関数がもう一つできます。

## 適用と計算の境界

関数の引数は、左から右へ順に一度ずつ評価されます。関数を呼んでも、外側で`let`した値が書き換わることはありません。

この章の`add`や`double`は、値を返すだけの関数です。一方`println`は「出力する」という処理を返すので、それを使う`main`は`effect fn`にしています。この違いは[Effect](/docs/learn/effects)の章で詳しく扱います。
