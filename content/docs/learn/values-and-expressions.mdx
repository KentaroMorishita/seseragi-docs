[最初のプログラム](/docs/learn/first-program)では、文字列を一つ表示しました。この章では、値に名前を付ける、条件で値を選ぶ、文字列に値を埋め込む、の三つを一つずつ試します。

## 値には型がある

`82`は`Int`、`True`は`Bool`、`"pass"`は`String`です。数値でも`82.0`は`Float`で、`Int`とは別の型です。`Int`と`Float`を暗黙に変換して足すことはできません。

型によって、その値でできることが決まります。整数どうしの`20 + 22`は42、比較の`82 >= 80`は`True`です。比較の結果は整数ではなく`Bool`になります。

## letで値に名前を付ける

`let message = "Hello, Seseragi"`と書くと、文字列に`message`という名前が付きます。名前を付けることを束縛と呼びます。`main`の本体を`{ ... }`で囲むと、その中に束縛と出力を順に書けます。

{/* example: examples/learn/values-and-expressions.ssrg */}
```seseragi title="values-and-expressions.ssrg"
pub effect fn main = {
  let message = "Hello, Seseragi"
  println message
}
```

```text title="実行結果"
Hello, Seseragi
```

`println message`では、`message`という名前が指す文字列を渡しています。`message`の型は右辺から`String`だと分かるので、型を書く必要はありません。型を書きたいときは、次のようにします。

```seseragi
let message: String = "Hello"
```

`let`で束縛した名前に、あとから別の値を代入することはできません。名前が使えるのは、束縛したブロックの中だけです。内側のブロックで同じ名前をもう一度`let`すると、内側ではその新しい値が見えます（シャドーイング）。これは外側の値を書き換えているわけではありません。

## ifで値を選ぶ

次の例では、82が80以上なら`"pass"`、そうでなければ`"retry"`を選び、その結果に`verdict`という名前を付けます。

{/* example: examples/learn/conditional-expressions.ssrg */}
```seseragi title="conditional-expressions.ssrg"
pub effect fn main = {
  let verdict =
    if 82 >= 80 then
      "pass"
    else
      "retry"
  println verdict
}
```

```text title="実行結果"
pass
```

Seseragiの`if ... then ... else ...`は、値を返す式です。TypeScriptの三項演算子`? :`に近いものと考えてください。この例ではどちらの分岐も`String`なので、`if`式全体も`String`になります。`else`は省略できず、二つの分岐は同じ型でなければなりません。

条件には`Bool`しか使えません。整数の0や空文字列を「偽」として扱うことはありません。実行されるのは選ばれた分岐だけです。

## 文字列に値を埋め込む

ダブルクォートで囲むと普通の文字列、バッククォートで囲むと値を埋め込める文字列テンプレートになります。

{/* example: examples/learn/string-templates.ssrg */}
```seseragi title="string-templates.ssrg"
pub effect fn main = {
  let name = "Aki"
  println `Hello, ${name}`
}
```

```text title="実行結果"
Hello, Aki
```

`${name}`の位置に、`name`の値が入ります。整数など文字列以外の値も埋め込めます。値がどう文字列になるかは、後の[型クラス](/docs/learn/type-classes)で扱います。

## ブロックの最後の式が結果になる

ブロック`{ ... }`の中では、途中の値に名前を付けながら、最後に一つの結果を返せます。次の例では、右辺のブロックが`"Hello, Aki"`を返し、それが`message`に束縛されます。

```seseragi
let message = {
  let name = "Aki"
  `Hello, ${name}`
}
```

ブロックの最後の式がそのまま結果になるので、`return`は書きません。`name`はこのブロックの中だけで使える名前で、外からは`message`だけが見えます。

## ほかの値の表記を調べる

`Int`は、−9007199254740991から9007199254740991までの整数を正確に扱います。この範囲を超える計算をすると、値を丸めたり桁あふれさせたりせず、その場でプログラムが止まります。もっと大きな整数や小数を扱う型は[標準ライブラリ](/docs/reference/library)にあります。

`'a'`は一文字を表す`Char`、`"a"`は`String`で、別の型です。`()`は「意味のある値がない」ことを表す`Unit`型の値で、空のレコード`{}`とは別物です。型と書き方の一覧は[型リファレンス](/docs/reference/types)にあります。

## 一つずつ変えて確かめる

最初の例では、`message`の文字列を好きなものに変えてみてください。条件式の例では、82を79にすると`retry`、80にすると`pass`が表示されます。さらに`else`の結果だけを整数の0にすると、二つの分岐の型が合わないので、実行する前にエラーになります。

文字列テンプレートの例では、`name`を`"Haru"`にすると`Hello, Haru`が表示されます。一度に変えるのは一か所だけにすると、何が結果に影響したかが分かりやすくなります。

次は[関数](/docs/learn/functions)で、計算に名前を付けて関数にします。書き方の細かい決まりは[構文](/docs/reference/syntax)にまとめています。
