点の座標を二つの整数としてまとめます。元の点を変更せず、横へ移動した新しい点を返す関数を作ります。

## レコードは必要なフィールドで使う

`{ x: 1, y: 2 }`は、名前付きフィールドを持つレコードです。型は`{ x: Int, y: Int }`になります。フィールドは`point.x`のように読み取ります。

レコードは構造で型を判定します。たとえば、次の宣言は`name`を持つレコードを受け取る形です。

{/* example: examples/learn/focused/record-fields.ssrg#declaration */}
```seseragi title="関数の宣言"
fn nameOf value: { name: String }
  -> String = value.name
```

`{ name: "Aki", score: 42 }`には必要な`name: String`があるので渡せます。余分なフィールドを許すこの規則をwidth subtypingと呼びます。必要なフィールドがない場合や、その型が異なる場合には渡せません。

次は`main`内に置く式です。`score`を使わない`nameOf`へ、`score`も持つレコードを渡します。

{/* example: examples/learn/focused/record-fields.ssrg#use */}
```seseragi title="main内の式"
{ name: "Aki", score: 42 }
|> nameOf
|> println
```

結果は`Aki`です。関数が要求するフィールドを、関数の型から確認できます。

## structは名前を持つ型

`struct Point`は`Point`という型を定義します。`Point { x: 1, y: 2 }`でその値を作り、`x`と`y`を読み取れます。

同じフィールド構成の`struct Size`を別に定義しても、`Point`と`Size`は別の型です。レコードとは違い、フィールドが一致するだけで代わりに渡せません。このように宣言の名前で区別する性質をnominal typingと呼びます。

まず、モジュールにこのstructを宣言します。

{/* example: examples/learn/focused/struct-fields.ssrg#declaration */}
```seseragi title="structの宣言"
struct Point {
  x: Int,
  y: Int,
}
```

次は`main`内に置く生成と読み取りです。

{/* example: examples/learn/focused/struct-fields.ssrg#access */}
```seseragi title="main内の式"
let point = Point { x: 3, y: 4 }
point.x
|> show
|> println
```

結果は3です。`Point { ... }`で生成し、`.x`でフィールドを読むところまでを、この例で確認します。

同じフィールドを持つ次の型を別に宣言しても、Pointにはなりません。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#size */}
```seseragi title="別のstructの宣言"
struct Size {
  x: Int,
  y: Int,
}
```

この関数が要求するのはPointです。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#declaration */}
```seseragi title="関数の宣言"
fn readX point: Point -> Int =
  point.x
```

次の`main`内の束縛は、意図したコンパイルエラーの例です。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#invalid */}
```seseragi title="型エラーになる束縛"
let size = Size { x: 3, y: 4 }
let wrong = readX size
```

`readX size`は、Pointを要求する場所へSizeを渡しているため`SES-T0101`になります。レコードの「必要なフィールドがあれば渡せる」という規則を、structには当てはめません。

### レコードのspreadだけを試す

次の束縛は`main`内に置きます。

{/* example: examples/learn/focused/record-spread.ssrg#update */}
```seseragi title="main内の束縛"
let base = { name: "Aki", score: 30 }
let next = { ...base, score: 42 }
```

`base.score`は30、`next.score`は42です。`next.name`は元の`"Aki"`を引き継ぎます。レコードのspreadで既存フィールドをコピーし、後ろのフィールドで新しい値を指定しています。元の`base`は変わりません。

## 元の値を保って更新する

{/* example: examples/learn/records-and-structs.ssrg */}
```seseragi title="records-and-structs.ssrg"
struct Point {
  x: Int,
  y: Int,
}

fn moveX amount: Int
  -> point: Point -> Point =
  Point {
    ...point,
    x: point.x + amount,
  }

pub effect fn main = do {
  let start = Point { x: 1, y: 2 }
  let moved = moveX 3 start
  println `${start.x}, ${start.y}`
  println `${moved.x}, ${moved.y}`
}
```

```text title="実行結果"
1, 2
4, 2
```

`moveX 3 start`は`start`の`x`に3を足した新しい`Point`を返します。`Point { ...point, x: ... }`では、まず元のフィールドを引き継ぎ、後ろに書いた`x`だけを置き換えます。元の`start`は`1, 2`のままです。

structの生成では全フィールドが必要です。spreadで引き継ぐ場合は、同じstruct型の値を一つだけ先頭に置けます。レコードにもspreadがあり、複数のレコードを左から右へ組み合わせられます。詳しい違いは[データ型](/docs/reference/data-types)で確認できます。

## 分解して名前を付ける

tupleやレコード、structは、パターンで必要な値を取り出せます。これは`moveX`の中へ置く場合の断片です。

```text
let Point { x, y } = point
let offset = { x: amount, y: 0 }
let { x: dx, y: dy } = offset
```

`x: dx`は、フィールド`x`の値を`dx`という名前で取り出します。値を別のフィールドへ書き込む操作ではありません。structには型名を付けたパターンを使い、レコードには名前のないパターンを使います。

レコードの分解だけを試すなら、`main`内で次の値を用意します。

{/* example: examples/learn/focused/record-decomposition.ssrg#point */}
```seseragi title="main内の束縛"
let point = { x: 3, y: 4 }
```

続けて、フィールドとは違う名前で取り出します。

{/* example: examples/learn/focused/record-decomposition.ssrg#rename */}
```seseragi title="main内の束縛"
let { x: dx, y: dy } = point
```

`dx`は3、`dy`は4です。値の取り出しと、更新用レコードの作成を分けて確認できます。

## データ型を選ぶ

関数が少数のフィールドだけを必要とするなら、レコード型で必要な形を示せます。座標、金額、識別子のように用途を型の名前で区別したい場合は、structや[newtype](/docs/reference/data-types)を使います。

structにメソッドを定義することもできますが、データを変更するオブジェクトである必要はありません。この例では入力の`Point`から出力の`Point`を返す通常の関数で移動を表しています。

## 別の移動を作る

`moveX`を参考に`moveY`を追加し、`start`を上へ5移動させてください。元の点も出力し、元の値が変更されていないことを確認します。次に同じフィールドを持つ`Size`を定義して`moveX`へ渡すと、型の不一致になります。

次は[代数的データ型](/docs/learn/algebraic-data-types)で、複数の値を同時に持つ形から、複数の状態のどれかを取る形へ進みます。
