この章では、複数の値を一つにまとめる方法を学びます。最後に、座標を表す点を作り、元の点を書き換えずに「横へ動かした新しい点」を返す関数を書きます。

## レコードは形で型が決まる

`{ x: 1, y: 2 }`は、名前付きのフィールドを持つレコードです。TypeScriptのオブジェクトリテラルとほぼ同じで、型は`{ x: Int, y: Int }`です。フィールドは`point.x`のように読み取ります。

レコードの型は、どんなフィールドを持っているかという「形」で決まります。次の関数は、`name`を持つレコードなら何でも受け取ります。

{/* example: examples/learn/focused/record-fields.ssrg#declaration */}
```seseragi title="関数の宣言"
fn nameOf value: { name: String }
  -> String = value.name
```

`{ name: "Aki", score: 42 }`は`name: String`を持っているので、余分な`score`があっても渡せます。TypeScriptの構造的な型付けと同じ考え方です。`name`がない場合や、`name`の型が違う場合は渡せません。

{/* example: examples/learn/focused/record-fields.ssrg#use */}
```seseragi title="main内の式"
{ name: "Aki", score: 42 }
|> nameOf
|> println
```

`Aki`と表示されます。関数がどのフィールドを使うのかは、関数の型を見れば分かります。

## structは名前で区別される

`struct`を使うと、名前の付いた型を定義できます。レコードと違い、structは形が同じでも名前が違えば別の型として扱われます。

まず`Point`を宣言します。

{/* example: examples/learn/focused/struct-fields.ssrg#declaration */}
```seseragi title="structの宣言"
struct Point {
  x: Int,
  y: Int,
}
```

`Point { ... }`で値を作り、`.x`でフィールドを読み取ります。

{/* example: examples/learn/focused/struct-fields.ssrg#access */}
```seseragi title="main内の式"
let point = Point { x: 3, y: 4 }
point.x
|> show
|> println
```

3と表示されます。

では、`Point`とまったく同じフィールドを持つ`Size`を宣言してみます。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#size */}
```seseragi title="別のstructの宣言"
struct Size {
  x: Int,
  y: Int,
}
```

次の関数は`Point`を受け取ります。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#declaration */}
```seseragi title="関数の宣言"
fn readX point: Point -> Int =
  point.x
```

ここに`Size`を渡すと、コンパイルエラーになります。

{/* example: examples/learn/focused/struct-nominal-error.ssrg#invalid */}
```seseragi title="型エラーになる束縛"
let size = Size { x: 3, y: 4 }
let wrong = readX size
```

`readX size`は、`Point`が必要な場所に`Size`を渡しているので`SES-T0101`エラーになります。フィールドの形が同じでも、名前の違う型どうしは取り違えられません。座標と大きさのように、形は同じでも意味が違う値を区別したいときに役立ちます。

### スプレッドで一部だけ変える

レコードは、TypeScriptと同じ`...`のスプレッド構文で、一部のフィールドだけを変えたコピーを作れます。

{/* example: examples/learn/focused/record-spread.ssrg#update */}
```seseragi title="main内の束縛"
let base = { name: "Aki", score: 30 }
let next = { ...base, score: 42 }
```

`next.score`は42、`next.name`は`base`から引き継いだ`"Aki"`です。`...base`でフィールドをコピーし、後ろに書いた`score`で上書きしています。`base.score`は30のまま変わりません。

## 元の値を保って更新する

{/* example: examples/learn/records-and-structs.ssrg */}
```seseragi title="records-and-structs.ssrg"
struct Point {
  x: Int,
  y: Int,
}

fn moveX amount: Int
  -> point: Point -> Point =
  Point {
    ...point,
    x: point.x + amount,
  }

pub effect fn main = do {
  let start = Point { x: 1, y: 2 }
  let moved = moveX 3 start
  println `${start.x}, ${start.y}`
  println `${moved.x}, ${moved.y}`
}
```

```text title="実行結果"
1, 2
4, 2
```

`moveX 3 start`は、`start`の`x`に3を足した新しい`Point`を返します。structでもスプレッドが使え、`Point { ...point, x: ... }`は元のフィールドを引き継いで`x`だけを置き換えます。元の`start`は`1, 2`のままです。

structを作るときは、すべてのフィールドが必要です。スプレッドを使う場合、structでは同じ型の値を一つだけ先頭に置けます。レコードでは、複数のレコードを並べて左から順に重ねられます。細かい違いは[データ型](/docs/reference/data-types)にまとめています。

## 分解して名前を付ける

タプル・レコード・structからは、パターンを使って中の値を取り出せます。TypeScriptの分割代入に近いものです。たとえば`moveX`の中で、次のように書けます。

```seseragi
let Point { x, y } = point
let offset = { x: amount, y: 0 }
let { x: dx, y: dy } = offset
```

`x: dx`は、フィールド`x`の値に`dx`という名前を付けて取り出します（TypeScriptの`const { x: dx } = offset`と同じです）。structのときは`Point { x, y }`のように型名を付け、レコードのときは型名なしで書きます。

試してみましょう。まず、レコードを用意します。

{/* example: examples/learn/focused/record-decomposition.ssrg#point */}
```seseragi title="main内の束縛"
let point = { x: 3, y: 4 }
```

フィールドとは違う名前で取り出します。

{/* example: examples/learn/focused/record-decomposition.ssrg#rename */}
```seseragi title="main内の束縛"
let { x: dx, y: dy } = point
```

`dx`は3、`dy`は4になります。

## レコードとstructの使い分け

関数がいくつかのフィールドだけを使うなら、レコード型で「これだけあればいい」という形を書けます。座標・金額・IDのように、意味の違いを型の名前で区別したいなら、structや[newtype](/docs/reference/data-types)を使います。

structにはメソッドも定義できますが、値を書き換えるオブジェクトにする必要はありません。この章の`moveX`のように、`Point`を受け取って新しい`Point`を返す普通の関数で十分です。

## 別の移動を作る

`moveX`をまねて`moveY`を書き、`start`を上へ5動かしてみてください。元の点も表示して、書き換わっていないことを確かめます。次に、同じフィールドを持つ`Size`の値を`moveX`に渡すと、型エラーになることも確かめてください。

次の[代数的データ型](/docs/learn/algebraic-data-types)では、「複数の値をまとめて持つ」型から一歩進んで、「いくつかの状態のどれか一つ」を表す型を作ります。
