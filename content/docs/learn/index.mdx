Seseragiでは、データを型で表し、関数で変換し、出力や状態の変更をEffectとして組み合わせます。このLearnは、その考え方を小さなプログラムから順に学ぶためのコースです。

関数、配列、オブジェクト、条件分岐を使ったことがあれば読み進められます。代数的データ型や型クラスの知識は前提にしていません。TypeScriptとの違いをまとめて確認したい場合は、[TypeScriptから始める](/docs/guides/typescript-to-seseragi)も参照してください。

## まず一つ動かす

[最初のプログラム](/docs/learn/first-program)で、一つの文字列を表示し、実行して、文字列を変えてみます。[ローカルで使う](/docs/learn/local-development)では、CLIとエディターを用意して、同じHello worldを手元で実行します。

各章の完成したコードにはファイル名と実行結果を載せています。 小さい例では、モジュールに置く宣言やmain内の式を抜粋し、置き場所を明記しています。一つの操作を確かめてから、章の後半でそれらを組み合わせます。まずそのまま実行し、次に章末の課題で入力や型を変えてください。予想した結果と実際の結果を比べると、構文だけでなく型と評価の関係を確認できます。

## 1. 値を関数で変換する

| 章 | 分かること |
| --- | --- |
| [値と式](/docs/learn/values-and-expressions) | 不変の値、型、ブロック、条件式 |
| [関数とパイプライン](/docs/learn/functions-and-pipelines) | 関数適用、部分適用、ラムダ、処理の組み合わせ |

文字列への命名、条件による値の選択、関数の呼び出しを別々の例で学びます。それらを使えるようになってから、関数を組み合わせます。通常の値を返す`fn`と、出力などの計算を作る`effect fn`の違いも、例に沿って確認します。

## 2. データの形と状態を表す

| 章 | 分かること |
| --- | --- |
| [レコードとstruct](/docs/learn/records-and-structs) | 複数の値をまとめ、元の値を保ったまま変更する |
| [代数的データ型](/docs/learn/algebraic-data-types) | 取りうる状態をケースとして定義する |
| [パターンマッチ](/docs/learn/pattern-matching) | ケースを判別し、必要な値を取り出す |
| [ArrayとList](/docs/learn/arrays-and-lists) | 列を変換・選別・集計する |
| [MaybeとEither](/docs/learn/maybe-and-either) | 値の欠如と、理由のある失敗を区別する |

データの形を決めると、関数が受け取れる入力と処理すべき分岐が決まります。`null`に意味を重ねたり、独立したBoolを増やしたりする前に、状態を型で表せるかを考えます。

## 3. 共通の処理と再帰を使う

| 章 | 分かること |
| --- | --- |
| [ジェネリクス](/docs/learn/generics) | 型が変わっても使える関数とデータ型 |
| [再帰](/docs/learn/recursion) | 終了条件、局所関数、末尾再帰 |

ジェネリクスはデータの型を変えて処理を再利用します。再帰は、問題を小さくした入力に同じ関数を適用します。型を一般化することと、処理を繰り返すことは別の仕組みです。

## 必要な情報を調べる

Learnは考え方を順に理解するための説明です。構文や契約を確認するときは[リファレンス](/docs/reference)を使ってください。標準関数を探すときは[標準ライブラリ](/docs/reference/library)、コマンドを確認するときは[CLI](/docs/reference/cli)が入口です。

完成した実行例はSeseragi 0.61.25で確認しています。言語とツールは開発中です。説明中の型・実行結果を保つため、CLIを更新した場合も例を実行して確認してください。
