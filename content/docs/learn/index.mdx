Seseragiでは、データの形を型で表し、関数で変換し、出力や状態の変更をEffectとして組み立てます。この「学ぶ」では、その考え方を小さなプログラムを動かしながら順に身につけます。

関数・配列・オブジェクト・条件分岐を使ったことがあれば、読み進められます。代数的データ型や型クラスを知らなくても大丈夫です。TypeScriptとの違いを先にざっと知りたい場合は、[TypeScriptから始める](/docs/guides/typescript-to-seseragi)を読んでください。

## まず一つ動かす

[最初のプログラム](/docs/learn/first-program)では、文字列を一行表示して、その文字列を書き換えてみます。[ローカルで使う](/docs/learn/local-development)では、CLIとエディターを用意して、同じプログラムを手元で動かします。

各章のコードには、ファイル名と実行結果を付けています。短い抜粋には「関数の宣言」「main内の式」のように、どこに置くコードかを書いています。

読むときは、まずコードをそのまま実行してみてください。章の終わりには、値や型を一か所だけ変えてみる課題があります。結果を予想してから実行すると、型と評価の関係がよく分かります。

## 1. 値を関数で変換する

| 章 | 分かること |
| --- | --- |
| [値と式](/docs/learn/values-and-expressions) | 不変の値、型、ブロック、条件式 |
| [関数](/docs/learn/functions) | 関数の宣言と呼び出し、部分適用、ラムダ |
| [パイプライン](/docs/learn/pipelines) | `|>`で処理の順に関数をつなぐ |
| [関数適用演算子](/docs/learn/application-operator) | `$`で重なった括弧を減らす |

値に名前を付ける、条件で値を選ぶ、関数を呼び出す、を一つずつ試してから、関数を組み合わせます。値を返すだけの`fn`と、出力などを行う`effect fn`の違いもここで出てきます。

## 2. データの形と状態を表す

| 章 | 分かること |
| --- | --- |
| [レコードとstruct](/docs/learn/records-and-structs) | 複数の値をまとめ、元の値を保ったまま変更する |
| [代数的データ型](/docs/learn/algebraic-data-types) | 取りうる状態をケースとして定義する |
| [パターンマッチ](/docs/learn/pattern-matching) | ケースを判別し、必要な値を取り出す |
| [ArrayとList](/docs/learn/arrays-and-lists) | 列を変換・選別・集計する |
| [MaybeとEither](/docs/learn/maybe-and-either) | 値の欠如と、理由のある失敗を区別する |

データの形を決めると、関数が受け取る入力と、処理すべき場合分けが決まります。`null`にいくつもの意味を持たせたり、フラグ用のBoolを増やしたりする代わりに、状態そのものを型で表す方法を学びます。

## 3. 共通の処理と再帰を使う

| 章 | 分かること |
| --- | --- |
| [ジェネリクス](/docs/learn/generics) | 型が変わっても使える関数とデータ型 |
| [再帰](/docs/learn/recursion) | 終了条件、局所関数、末尾再帰 |

ジェネリクスは、扱うデータの型が変わっても同じ処理を使い回す仕組みです。再帰は、問題を小さくしながら同じ関数を繰り返し呼ぶ仕組みです。

## 必要な情報を調べる

「学ぶ」は、考え方を順に理解するためのページです。構文や細かい決まりを調べるときは[リファレンス](/docs/reference)、標準の関数を探すときは[標準ライブラリ](/docs/reference/library)、コマンドの使い方は[CLI](/docs/reference/cli)を見てください。

このページの例は、すべてCLIで実行して確かめています。ただし言語とツールは開発中なので、新しいバージョンで結果が変わることがあります。
