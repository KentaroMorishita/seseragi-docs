整数を包む型と文字列を包む型を別々に書く代わりに、中身の型を引数にする`Box<A>`を作れます。`A`は実行時の値ではなく、宣言の中で使う型の名前です。

## 引数と結果の型を同じに保つ

まず、型引数を一つ使う小さな関数をモジュールに宣言します。

{/* example: examples/learn/focused/generic-identity.ssrg#declaration */}
```seseragi title="関数の宣言"
fn identity<A> value: A -> A = value
```

`A`は呼び出しごとに具体的な型になります。次は`main`内で型引数を明示する束縛です。

{/* example: examples/learn/focused/generic-identity.ssrg#explicit */}
```seseragi title="main内の束縛"
let number = identity<Int> 42
let text = identity<String> "hello"
```

`number`はIntの42、`text`はStringの`"hello"`です。関数の同じ本体を使いながら、引数と結果が同じ型である関係を保ちます。整数の引数から、無関係なStringを返す宣言ではありません。

## 型を引数にする

{/* example: examples/learn/generics.ssrg */}
```seseragi title="generics.ssrg"
struct Box<A> {
  value: A,
}

fn unbox<A> box: Box<A> -> A =
  box.value

fn identity<A> value: A -> A =
  value

pub effect fn main = do {
  let number = Box { value: 42 }
  let text = Box { value: "hello" }
  number
  |> unbox
  |> identity
  |> show
  |> println
  text
  |> unbox
  |> identity
  |> show
  |> println
}
```

```text title="実行結果"
42
hello
```

`Box { value: 42 }`は`Box<Int>`、`Box { value: "hello" }`は`Box<String>`です。フィールドの値から型引数を決められるので、生成時に型を明示する必要はありません。

`unbox<A>`は`Box<A>`から`A`を取り出します。整数なら整数、文字列なら文字列が返ります。呼び出しごとに型の関係を保ちます。出力するときは`show`で`String`へ変えて、文字列を受け取る`println`へ渡します。

## 型引数は宣言の中で使う

`identity<A> value: A -> A`は、受け取った型と同じ型を返します。引数と戻り値を別の不明な型にする宣言ではありません。`identity 42`の結果は`Int`です。

この関数は`A`にどんな型が来るかを仮定できません。たとえば`value + 1`に変えると、任意の`A`で整数の加算ができるとは限らず、エラーになります。型ごとの操作が必要なら、[型クラス](/docs/learn/type-classes)の制約でその要件を表します。

## 推論できない場合は明示する

型引数は、引数の型や期待する結果型から推論されます。必要なら`identity<String> "hello"`のように明示できます。関数名と`<`の間には空白を置きません。

空のコレクションなど、値から要素型が分からない場合もあります。`let empty: Array<Int> = []`なら期待型を与えられます。型を決められない場合、コンパイラーは`Any`へ逃がさず注釈を求めます。

### 入力とは違う型へ変換する

Boxの中の値を変換する関数では、入力の型Aと出力の型Bを分けます。次の宣言は、上のBoxを使います。

{/* example: examples/learn/focused/generic-map-box.ssrg#declaration */}
```seseragi title="関数の宣言"
fn mapBox<A, B> f: (A -> B)
  -> box: Box<A> -> Box<B> =
  Box { value: f box.value }
```

次は`main`内の束縛です。

{/* example: examples/learn/focused/generic-map-box.ssrg#transform */}
```seseragi title="main内の束縛"
let number: Box<Int> =
  Box { value: 42 }
let labeled: Box<String> =
  number
  |> mapBox (\n -> `score: ${n}`)
```

`number`は`Box<Int>`、`labeled`は`Box<String>`です。`labeled.value`は`score: 42`になります。変換関数がIntからStringを返し、その関係がBoxの型にも反映されます。

## データの形を型で再利用する

ADTも型引数を持てます。次の断片では、成功値の型を`A`で表します。

{/* example: examples/learn/focused/generic-result.ssrg#data */}
```seseragi title="型の宣言"
type Result<A> =
  | Failed String
  | Succeeded A
```

`Result<Int>`と`Result<String>`は、同じケース構成を持ちつつ異なるpayload型を保ちます。`Maybe<A>`や`Either<E, A>`も、このように型引数で中身を指定する型です。

型へ別の名前を付けるだけなら、`alias Pair<A> = (A, A)`と書けます。aliasは新しいnominal型を作りません。名前によって区別するstructやnewtypeとは役割が違います。

このResultから値を取り出す関数も、型引数を保って書けます。モジュールに置く宣言です。

{/* example: examples/learn/focused/generic-result.ssrg#declaration */}
```seseragi title="関数の宣言"
fn valueOr<A> fallback: A
  -> result: Result<A> -> A =
  match result {
    Failed _ -> fallback
    Succeeded value -> value
  }
```

次は`main`内の束縛です。

{/* example: examples/learn/focused/generic-result.ssrg#inputs */}
```seseragi title="main内の束縛"
let number =
  Succeeded 42
  |> valueOr 0
let text =
  Failed "unavailable"
  |> valueOr "untitled"
```

`number`は42、`text`は`untitled`です。成功値と既定値が同じAなので、関数の結果もそのAになります。失敗理由を表示するか、既定値へ置き換えるかは、この関数を選ぶ側の方針です。

## letで束縛した関数も再利用できる

非再帰的な`let`で束縛した関数は、利用ごとに型を具体化できます。たとえば、ブロックの中で`let same = \value -> value`を束縛し、整数と文字列にそれぞれ使えます。これをlet-polymorphismと呼びます。

次の断片を`main`内に置くと、同じ関数を二つの型へ適用できます。

{/* example: examples/learn/focused/generic-local-function.ssrg#polymorphic */}
```seseragi title="main内の束縛"
let same = \value -> value
let number = same 42
let text = same "hello"
```

`number`は42、`text`は`hello`です。一つの関数の型を、最初の呼び出しの型だけへ固定しているわけではありません。

型の一般化は、同じArrayに異なる要素型を混ぜることを許す規則ではありません。`Array<Int>`と`Array<String>`は別の型です。また、`Box<Int>`が`Box<Float>`へ暗黙に変換されることもありません。

## 別の型を取り出す

例の`Box { value: "hello" }`を`Box { value: True }`へ変えてください。`unbox`の宣言を変えずに、結果が`Bool`になります。次に`unbox`の結果へ常に1を足すようにすると、genericな宣言として成り立たなくなります。

次は[再帰](/docs/learn/recursion)で、型の一般化とは別に、入力を小さくして処理を繰り返す関数を作ります。型引数の構文と規則は[型リファレンス](/docs/reference/types)を参照してください。
