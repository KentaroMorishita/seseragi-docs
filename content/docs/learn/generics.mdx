---
title: "ジェネリクス"
description: "型引数を使って、異なる型にも同じ処理とデータの形を使う。"
---

整数を入れる箱と文字列を入れる箱を別々に作る代わりに、中身の型を引数にした`Box<A>`を一つ作れます。これがジェネリクスで、TypeScriptの`Box<T>`と同じ考え方です。`A`は値ではなく、型の名前の代わりに置く記号です。

この章のコードでは、[関数](/docs/learn/functions)、[パイプライン](/docs/learn/pipelines)の`|>`と`show`、[レコードとstruct](/docs/learn/records-and-structs)、[代数的データ型](/docs/learn/algebraic-data-types)、[パターンマッチ](/docs/learn/pattern-matching)の`match`を使います。`main`の`do { ... }`は、中の処理を上から順に実行する書き方です。詳しくは[Effect](/docs/learn/effects)で扱います。

## 引数と結果の型を同じに保つ

まず、型引数を一つ使う小さな関数を書きます。関数名の後ろの`<A>`が型引数です。

{/* example: examples/learn/focused/generic-identity.ssrg#declaration */}
```seseragi title="関数の宣言"
fn identity<A> value: A -> A = value
```

`A`は、呼び出すたびに具体的な型に置き換わります。`<Int>`のように、型を明示して呼ぶこともできます。

{/* example: examples/learn/focused/generic-identity.ssrg#explicit */}
```seseragi title="main内の束縛"
let number = identity<Int> 42
let text = identity<String> "hello"
```

`number`は`Int`の42、`text`は`String`の`"hello"`です。同じ関数を使いながら、「受け取った型と同じ型を返す」という関係は保たれます。

## 型を引数にする

{/* example: examples/learn/generics.ssrg */}
```seseragi title="generics.ssrg"
struct Box<A> {
  value: A,
}

fn unbox<A> box: Box<A> -> A =
  box.value

fn identity<A> value: A -> A =
  value

pub effect fn main = do {
  let number = Box { value: 42 }
  let text = Box { value: "hello" }
  number
  |> unbox
  |> identity
  |> show
  |> println
  text
  |> unbox
  |> identity
  |> show
  |> println
}
```

```text title="実行結果"
42
hello
```

`Box { value: 42 }`は`Box<Int>`、`Box { value: "hello" }`は`Box<String>`です。中の値から型が分かるので、作るときに型を書く必要はありません。

`unbox<A>`は`Box<A>`から中身の`A`を取り出します。`Box<Int>`なら整数が、`Box<String>`なら文字列が返ります。

## 型引数には何でも入る

`identity<A> value: A -> A`は、どんな型でも受け取れる代わりに、`A`がどんな型かを何も知りません。たとえば本体を`value + 1`に変えると、`A`が数とは限らないのでエラーになります。「足し算ができる型だけ」のように条件を付けたいときは、[型クラス](/docs/learn/type-classes)の制約を使います。

## 推論できない場合は明示する

型引数は、ふつうは引数や結果の型から自動で決まります。書くときは`identity<String> "hello"`のように、関数名と`<`の間に空白を入れません。

空のArrayのように、値から型が分からない場合もあります。そのときは`let empty: Array<Int> = []`のように型を書きます。型が決まらないとき、コンパイラーは何でもありの型で済ませず、型を書くよう求めます。

### 入力とは違う型へ変換する

Boxの中身を変換する関数では、変換前の型`A`と変換後の型`B`の二つの型引数を使います。

{/* example: examples/learn/focused/generic-map-box.ssrg#declaration */}
```seseragi title="関数の宣言"
fn mapBox<A, B> f: (A -> B)
  -> box: Box<A> -> Box<B> =
  Box { value: f box.value }
```

{/* example: examples/learn/focused/generic-map-box.ssrg#transform */}
```seseragi title="main内の束縛"
let number: Box<Int> =
  Box { value: 42 }
let labeled: Box<String> =
  number
  |> mapBox (\n -> `score: ${n}`)
```

`number`は`Box<Int>`、`labeled`は`Box<String>`で、`labeled.value`は`score: 42`です。変換する関数が`Int`を`String`にするので、Boxの型も`Box<Int>`から`Box<String>`に変わります。

## データの形を型で再利用する

ADTも型引数を持てます。次の`Result<A>`は、成功したときの値の型を`A`にしています。

{/* example: examples/learn/focused/generic-result.ssrg#data */}
```seseragi title="型の宣言"
type Result<A> =
  | Failed String
  | Succeeded A
```

`Result<Int>`と`Result<String>`は、ケースは同じで、成功の値の型だけが違います。前の章の`Maybe<A>`や`Either<E, A>`も、こうして作られた型です。

型に別名を付けるだけなら、`alias Pair<A> = (A, A)`と書けます。`alias`は名前を付けるだけで、新しい型は作りません。

`Result`から値を取り出す関数も、型引数を使って書けます。

{/* example: examples/learn/focused/generic-result.ssrg#declaration */}
```seseragi title="関数の宣言"
fn valueOr<A> fallback: A
  -> result: Result<A> -> A =
  match result {
    Failed _ -> fallback
    Succeeded value -> value
  }
```

{/* example: examples/learn/focused/generic-result.ssrg#inputs */}
```seseragi title="main内の束縛"
let number =
  Succeeded 42
  |> valueOr 0
let text =
  Failed "unavailable"
  |> valueOr "untitled"
```

`number`は42、`text`は`untitled`です。成功の値と代わりの値がどちらも`A`なので、結果も`A`になります。

## letで作った関数もいろいろな型に使える

`let`で束縛した関数も、使うたびに違う型で使えます。

{/* example: examples/learn/focused/generic-local-function.ssrg#polymorphic */}
```seseragi title="main内の束縛"
let same = \value -> value
let number = same 42
let text = same "hello"
```

`number`は42、`text`は`hello`です。最初に整数で呼んだからといって、`same`が整数専用になるわけではありません。

ただし、ジェネリクスは一つのArrayに違う型の要素を混ぜられるという意味ではありません。`Array<Int>`と`Array<String>`は別の型です。`Box<Int>`が`Box<Float>`に自動で変換されることもありません。

## 別の型を取り出す

例の`Box { value: "hello" }`を`Box { value: True }`に変えてみてください。`unbox`は書き換えなくても、結果が`Bool`になります。次に`unbox`の中で値に1を足すようにすると、`A`が数とは限らないのでエラーになります。

次の[再帰](/docs/learn/recursion)では、入力を小さくしながら同じ関数を繰り返し呼ぶ書き方を学びます。型引数の細かい決まりは[型リファレンス](/docs/reference/types)にあります。
