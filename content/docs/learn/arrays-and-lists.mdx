Arrayの要素を変える操作と、残す要素を選ぶ操作を別々に試します。その後で、添字、集計、Listの扱いを確認し、最後に関数を組み合わせます。

## 要素を変えるmap

`[1, 2, 3]`は`Array<Int>`です。`map`は各要素へ関数を適用し、同じ個数の新しいArrayを作ります。次は`main`内に置く式です。

{/* example: examples/learn/focused/array-map.ssrg#map */}
```seseragi title="main内の式"
[1, 2, 3]
|> map (\n -> n * 2)
|> show
|> println
```

```text title="実行結果"
[2, 4, 6]
```

ここでは、一つの整数を2倍するラムダを、三つの要素へそれぞれ適用しています。元のArrayは変わりません。`map`はpreludeから使え、別の型にも使える仕組みは[型クラス](/docs/learn/type-classes)で学びます。

## 残す要素を選ぶfilter

`filter`では、Boolを返す関数がTrueになる要素だけを残します。先に、モジュールで次のimportを置きます。

{/* example: examples/learn/focused/array-filter.ssrg#import */}
```seseragi title="importの宣言"
import * as arrays from "std/array"
```

次は`main`内の束縛です。

{/* example: examples/learn/focused/array-filter.ssrg#keep */}
```seseragi title="main内の束縛"
let kept =
  [1, 2, 3, 4]
  |> arrays.filter (\n -> n % 2 == 0)
```

`kept`は`[2, 4]`です。同じ条件でも、偶数がない入力なら空になります。

{/* example: examples/learn/focused/array-filter.ssrg#empty */}
```seseragi title="main内の束縛"
let removed =
  [1, 3, 5]
  |> arrays.filter (\n -> n % 2 == 0)
```

`removed`は`[]`です。mapは要素の値を変え、filterは残す要素を選びます。filterが空を返すことは、実行の失敗ではありません。

## 添字の結果はMaybe

`[10][0]`の型は`Maybe<Int>`で、値は`Just 10`です。`[10][99]`のような範囲外の添字や、負の添字ならNothingです。`[10][0] ?? 0`は、見つかった値を取り出し、存在しなければ0を使います。

`[1, "two"]`のように要素の型を混ぜることはできません。空の配列も要素型が必要です。型を周囲から決められない場合は、`let empty: Array<Int> = []`と注釈します。

空の場合だけ既定値を使う動作を、短い例で比べます。次は`main`内の束縛です。

{/* example: examples/learn/focused/array-missing-index.ssrg#index */}
```seseragi title="main内の束縛"
let empty: Array<Int> = []
let first = [10][0] ?? 99
let missing = empty[0] ?? 99
```

`first`は10、`missing`は99です。値の10が存在する場合と、添字0が存在しない場合を分けて扱っています。

### 初期値と畳み込み

`reduce`は、初期値から始め、要素を順に使って一つの結果を作ります。合計以外の例として、整数を文字列の末尾へ順に付けます。これはモジュールに置く関数です。

{/* example: examples/learn/focused/array-reduce.ssrg#declaration */}
```seseragi title="関数の宣言"
fn appendDigit text: String
  -> n: Int -> String =
  `${text}${n}`
```

次の式は`main`内に置きます。

{/* example: examples/learn/focused/array-reduce.ssrg#fold */}
```seseragi title="main内の式"
[1, 2, 3]
|> reduce "" appendDigit
|> println
```

結果は`123`です。`reduce`の引数は、初期値、更新関数、入力の順です。最初の`""`から`"1"`、`"12"`、`"123"`と進みます。結果の型は入力要素と同じである必要はありません。入力が空なら、更新関数を呼ばず初期値を返します。

## Listは別のコレクション

Arrayは`[1, 2, 3]`、Listは先頭にバッククォートを付けた`` `[1, 2, 3] ``です。どちらも不変ですが、Arrayは添字によるアクセス、Listは先頭の追加と残りの共有に向いています。暗黙には変換されません。

まず、空と先頭だけを調べる関数をモジュールに置きます。ここでは再帰を使いません。

{/* example: examples/learn/focused/list-empty-and-head.ssrg#declaration */}
```seseragi title="関数の宣言"
fn caption values: List<Int>
  -> String =
  match values {
    `[] -> "empty"
    `[head, ..._] -> `first: ${head}`
  }
```

次は`main`内の束縛です。

{/* example: examples/learn/focused/list-empty-and-head.ssrg#inputs */}
```seseragi title="main内の束縛"
let empty = caption `[]
let full = caption (1 : `[2, 3])
```

`empty`の値は文字列`"empty"`、`full`は`"first: 1"`です。`1 : ...`で先頭へ追加し、パターンでその先頭を取り出しています。残りのListを使わない部分には`_`を置いています。

`1 : tail`はListの先頭に1を追加します。次の完成した例では、Listを空か先頭と残りかに分けます。

{/* example: examples/learn/list-patterns.ssrg */}
```seseragi title="list-patterns.ssrg"
fn total values: List<Int> -> Int =
  match values {
    `[] -> 0
    `[head, ...tail] ->
      head + total tail
  }

pub effect fn main =
  1 : `[2, 3]
  |> total
  |> show
  |> println
```

```text title="実行結果"
6
```

`total`の結果は整数です。`show`で文字列へ変えてから`println`へ渡します。

`` `[head, ...tail] ``の`tail`は`List<Int>`です。Arrayの`[head, ...tail]`なら`tail`もArrayになります。Listには添字アクセスの構文はありません。変換するときは`std/array`の`toList`、`std/list`の`toArray`を使います。

### ArrayとListを明示的に変換する

モジュールに次のimportを置きます。

{/* example: examples/learn/focused/list-array-conversion.ssrg#imports */}
```seseragi title="importの宣言"
import * as arrays from "std/array"
import * as lists from "std/list"
```

次は`main`内の式です。

{/* example: examples/learn/focused/list-array-conversion.ssrg#conversion */}
```seseragi title="main内の式"
[1, 2]
|> arrays.toList
|> lists.toArray
|> show
|> println
```

結果は`[1, 2]`です。要素と順序を保ち、ArrayからListへ、ListからArrayへ変換しています。コピーを伴う変換を繰り返す前に、その後の処理がどちらの形を必要とするかを決めます。

## rangeと内包表記を使う

rangeは整数の範囲を表す値です。Arrayそのものではありません。内包表記で範囲から要素を取り出すと、Arrayを作れます。次の二つの束縛は`main`内に置きます。

{/* example: examples/learn/focused/array-ranges.ssrg#inclusive */}
```seseragi title="main内の束縛"
let inclusive = [n | n <- 1..=3]
```

{/* example: examples/learn/focused/array-ranges.ssrg#exclusive */}
```seseragi title="main内の束縛"
let exclusive = [n | n <- 1..3]
```

`inclusive`は`[1, 2, 3]`、`exclusive`は`[1, 2]`です。`..=`は終点を含み、`..`は含みません。

変換する式と、残す条件も書けます。

{/* example: examples/learn/focused/array-ranges.ssrg#comprehension */}
```seseragi title="main内の束縛"
let squares =
  [n * n | n <- 1..=5, n % 2 == 0]
```

`squares`は`[4, 16]`です。`|`の右側は左から処理され、`n <- ...`が値を取り出し、後続のBool条件が要素を選びます。内包表記は純粋な計算です。

## 走査の方法を選ぶ

Listの先頭と残りを分ける処理は、既存の残りを共有できます。Arrayを`[head, ...tail]`で繰り返し分けると、残りのArrayを毎回作るため、大量の要素には向きません。Arrayの全体走査には`map`、`filter`、`reduce`などを使います。

上のList例の`head + total tail`は、再帰の後にも加算が残るため末尾再帰ではありません。長いListを合計するなら標準の`sum`を使えます。自分で再帰を書く場合の終了とスタックの扱いは[再帰](/docs/learn/recursion)で説明します。

## 学んだ操作を組み合わせる

{/* example: examples/learn/arrays-and-lists.ssrg */}
```seseragi title="arrays-and-lists.ssrg"
import * as arrays from "std/array"

fn square n: Int -> Int =
  n * n

fn even n: Int -> Bool =
  n % 2 == 0

pub effect fn main = do {
  let numbers = [1, 2, 3, 4, 5]
  let total =
    numbers
    |> map square
    |> arrays.filter even
    |> sum
  let first = numbers[0] ?? 0
  println `total: ${total}`
  println `first: ${first}`
}
```

```text title="実行結果"
total: 20
first: 1
```

`numbers`は`Array<Int>`です。`map square`は`[1, 4, 9, 16, 25]`を返し、`arrays.filter even`は`[4, 16]`を返します。`sum`で20になります。どの段階も、元の`numbers`を変更しません。

`map`と`sum`はpreludeから使えます。`filter`はここでは`std/array`を`arrays`という名前でimportしています。`map`は型クラスによって別の型にも同じ意味で使える操作で、その仕組みは[型クラス](/docs/learn/type-classes)で扱います。



この完成コードの`do`は、二つの出力を順に実行するために使っています。計算の順番と外部処理の合成は、後の[Effect](/docs/learn/effects)で詳しく扱います。

## 条件を変える

最初の例で`even`を`n % 2 != 0`へ変えると、合計は35です。`numbers[0]`を`numbers[99]`へ変えると、既定値の0が出力されます。欠如を既定値で埋めずに表示し分ける方法は、次の[MaybeとEither](/docs/learn/maybe-and-either)で扱います。

関数一覧は[標準ライブラリ](/docs/reference/library)、型と添字の契約は[データ型](/docs/reference/data-types)を参照してください。
