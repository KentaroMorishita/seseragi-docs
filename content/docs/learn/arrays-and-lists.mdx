この章では、たくさんの値をまとめて扱うArrayとListを学びます。要素を変換する`map`と、要素を選ぶ`filter`から始めて、添字・集計・Listへと進み、最後にそれらを組み合わせます。

この章のコードでは、[関数](/docs/learn/functions)のラムダ、[パイプライン](/docs/learn/pipelines)の`|>`と`show`、[パターンマッチ](/docs/learn/pattern-matching)の`match`を使います。

## 要素を変えるmap

`[1, 2, 3]`は`Array<Int>`型の配列です。`map`は、各要素に関数を適用した新しいArrayを作ります。TypeScriptの`array.map(...)`と同じ働きです。

{/* example: examples/learn/focused/array-map.ssrg#map */}
```seseragi title="main内の式"
[1, 2, 3]
|> map (\n -> n * 2)
|> show
|> println
```

```text title="実行結果"
[2, 4, 6]
```

整数を2倍するラムダを、三つの要素それぞれに適用しています。元のArrayは変わりません。`map`はimportしなくても使えます。Array以外の型にも使える仕組みは、[型クラス](/docs/learn/type-classes)で学びます。

## 残す要素を選ぶfilter

`filter`は、条件の関数が`True`を返した要素だけを残します。`filter`は`std/array`モジュールにあるので、ファイルの先頭でimportします。importの書き方は[モジュール](/docs/learn/modules)で詳しく扱います。

{/* example: examples/learn/focused/array-filter.ssrg#import */}
```seseragi title="importの宣言"
import * as arrays from "std/array"
```

{/* example: examples/learn/focused/array-filter.ssrg#keep */}
```seseragi title="main内の束縛"
let kept =
  [1, 2, 3, 4]
  |> arrays.filter (\n -> n % 2 == 0)
```

`kept`は`[2, 4]`です。偶数が一つもなければ、結果は空のArrayになります。

{/* example: examples/learn/focused/array-filter.ssrg#empty */}
```seseragi title="main内の束縛"
let removed =
  [1, 3, 5]
  |> arrays.filter (\n -> n % 2 == 0)
```

`removed`は`[]`です。空になってもエラーではなく、「残る要素がなかった」という普通の結果です。

## 添字で読むと結果はMaybeになる

TypeScriptでは、`array[99]`のように範囲外を読むと`undefined`が返り、型には現れません。Seseragiでは、添字で読んだ結果の型が`Maybe<Int>`になります。`[10][0]`は`Just 10`、範囲外の`[10][99]`や負の添字は`Nothing`です。「値がないかもしれない」ことが型に出るので、見落とせません。

`??`を使うと、値があればそれを、なければ代わりの値を使えます。

{/* example: examples/learn/focused/array-missing-index.ssrg#index */}
```seseragi title="main内の束縛"
let empty: Array<Int> = []
let first = [10][0] ?? 99
let missing = empty[0] ?? 99
```

`first`は10、`missing`は99です。空のArrayには添字0の要素がないので、代わりの99が使われます。

なお、`[1, "two"]`のように型の違う要素を混ぜることはできません。空のArrayも要素の型を持つので、型が前後から分からないときは`let empty: Array<Int> = []`のように書きます。

### 初期値と畳み込み

`reduce`は、初期値から始めて、要素を一つずつ使いながら一つの結果にまとめます。ここでは、整数を文字列の後ろに順につなげてみます。

{/* example: examples/learn/focused/array-reduce.ssrg#declaration */}
```seseragi title="関数の宣言"
fn appendDigit text: String
  -> n: Int -> String =
  `${text}${n}`
```

{/* example: examples/learn/focused/array-reduce.ssrg#fold */}
```seseragi title="main内の式"
[1, 2, 3]
|> reduce "" appendDigit
|> println
```

`123`と表示されます。`reduce`の引数は、初期値・関数・入力の順です。`""`から始まり、`"1"`、`"12"`、`"123"`と進みます。この例のように、結果の型（`String`）は要素の型（`Int`）と違っていて構いません。入力が空なら、初期値がそのまま結果になります。

## List

Seseragiには、Arrayとは別にListもあります。Arrayは`[1, 2, 3]`、Listは先頭にバッククォートを付けて`` `[1, 2, 3] ``と書きます。どちらも中身を書き換えられません。Arrayは添字で読むのが得意で、Listは先頭に要素を足したり、先頭と残りに分けたりするのが得意です。ArrayとListは別の型で、自動では変換されません。

まず、Listが空かどうかと、先頭の要素を調べる関数を書きます。

{/* example: examples/learn/focused/list-empty-and-head.ssrg#declaration */}
```seseragi title="関数の宣言"
fn caption values: List<Int>
  -> String =
  match values {
    `[] -> "empty"
    `[head, ..._] -> `first: ${head}`
  }
```

{/* example: examples/learn/focused/list-empty-and-head.ssrg#inputs */}
```seseragi title="main内の束縛"
let empty = caption `[]
let full = caption (1 : `[2, 3])
```

`empty`は`"empty"`、`full`は`"first: 1"`です。`` 1 : `[2, 3] ``は、Listの先頭に1を足して`` `[1, 2, 3] ``を作ります。パターンの`` `[head, ..._] ``は、先頭を`head`として取り出し、残りは使わないので`_`にしています。

次は、Listを「空」か「先頭と残り」かに分けて、合計を求める例です。

{/* example: examples/learn/list-patterns.ssrg */}
```seseragi title="list-patterns.ssrg"
fn total values: List<Int> -> Int =
  match values {
    `[] -> 0
    `[head, ...tail] ->
      head + total tail
  }

pub effect fn main =
  1 : `[2, 3]
  |> total
  |> show
  |> println
```

```text title="実行結果"
6
```

`` `[head, ...tail] ``の`tail`は、残りの要素の`List<Int>`です。`total`は、先頭に「残りの合計」を足すことで全体の合計を求めています。

Arrayでも`[head, ...tail]`と書け、そのときの`tail`はArrayです。Listには添字で読む書き方はありません。

### ArrayとListを変換する

変換には、`std/array`の`toList`と`std/list`の`toArray`を使います。

{/* example: examples/learn/focused/list-array-conversion.ssrg#imports */}
```seseragi title="importの宣言"
import * as arrays from "std/array"
import * as lists from "std/list"
```

{/* example: examples/learn/focused/list-array-conversion.ssrg#conversion */}
```seseragi title="main内の式"
[1, 2]
|> arrays.toList
|> lists.toArray
|> show
|> println
```

`[1, 2]`と表示されます。ArrayからListへ、ListからArrayへと変換しても、要素と順番は変わりません。変換のたびにコピーが作られるので、何度も行き来するより、使い方に合うほうを最初から選びましょう。

## 範囲と内包表記

`1..=3`のような範囲（Range）は、整数の範囲を表す値です。Arrayそのものではありませんが、内包表記で範囲から値を取り出すと、Arrayを作れます。

{/* example: examples/learn/focused/array-ranges.ssrg#inclusive */}
```seseragi title="main内の束縛"
let inclusive = [n | n <- 1..=3]
```

{/* example: examples/learn/focused/array-ranges.ssrg#exclusive */}
```seseragi title="main内の束縛"
let exclusive = [n | n <- 1..3]
```

`inclusive`は`[1, 2, 3]`、`exclusive`は`[1, 2]`です。`..=`は終わりの値を含み、`..`は含みません。

内包表記では、値を変換する式と、残す条件も書けます。

{/* example: examples/learn/focused/array-ranges.ssrg#comprehension */}
```seseragi title="main内の束縛"
let squares =
  [n * n | n <- 1..=5, n % 2 == 0]
```

`squares`は`[4, 16]`です。`|`の右側では、`n <- 1..=5`が1から5を順に取り出し、`n % 2 == 0`が偶数だけを残します。残った値を`|`の左側の`n * n`で変換します。

## どちらを使うか

Listを先頭と残りに分けるとき、残りのListはコピーされず、元のListの一部がそのまま使われます。一方Arrayを`[head, ...tail]`で分けると、毎回残りのArrayがコピーされるので、要素が多いと遅くなります。Arrayを最初から最後まで処理するときは、`map`・`filter`・`reduce`などを使いましょう。

上のListの例の`total`は、自分を呼んだあとにまだ足し算が残っている（末尾再帰ではない）ため、要素がとても多いとスタックが足りなくなることがあります。長いListの合計には、標準の`sum`を使えます。再帰を安全に書く方法は[再帰](/docs/learn/recursion)の章で説明します。

## 学んだ操作を組み合わせる

{/* example: examples/learn/arrays-and-lists.ssrg */}
```seseragi title="arrays-and-lists.ssrg"
import * as arrays from "std/array"

fn square n: Int -> Int =
  n * n

fn even n: Int -> Bool =
  n % 2 == 0

pub effect fn main = do {
  let numbers = [1, 2, 3, 4, 5]
  let total =
    numbers
    |> map square
    |> arrays.filter even
    |> sum
  let first = numbers[0] ?? 0
  println `total: ${total}`
  println `first: ${first}`
}
```

```text title="実行結果"
total: 20
first: 1
```

`map square`で`[1, 4, 9, 16, 25]`、`arrays.filter even`で`[4, 16]`、`sum`で20になります。どの段階でも、元の`numbers`は変わりません。

`map`と`sum`はimportなしで使え、`filter`は`std/array`を`arrays`という名前でimportして使っています。`main`の`do`は、二つの`println`を順に実行するためのものです。`do`については[Effect](/docs/learn/effects)の章で詳しく扱います。

## 条件を変える

最後の例で`even`を`n % 2 != 0`に変えると、合計は35になります。`numbers[0]`を`numbers[99]`に変えると、代わりの値の0が表示されます。値がないときに代わりの値で埋めるのではなく、場合分けして扱う方法は、次の[MaybeとEither](/docs/learn/maybe-and-either)で学びます。

関数の一覧は[標準ライブラリ](/docs/reference/library)、型と添字の細かい決まりは[データ型](/docs/reference/data-types)にあります。
