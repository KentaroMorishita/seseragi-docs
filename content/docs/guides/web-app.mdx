title: Webアプリを作る
description: Signalに数を保存し、ボタンで更新するカウンターを作る。
---

「Add one」で数が増え、「Reset」で0に戻るカウンターを作ります。数を[Signal](/docs/learn/signals)に保存し、数が変わると画面も変わるようにつなぎます。

ボタンには、クリック時に実行する`Task<Unit>`を渡します。これは`Effect<{}, Never, Unit>`の別名で、必要なサービスも失敗もなく、結果として`Unit`を返す処理です。処理を作ることと実行することの違いは[Effect](/docs/learn/effects)、ラムダと部分適用は[関数](/docs/learn/functions)で説明しています。

## プロジェクトを作る

```sh
seseragi new web counter
cd counter
```

`src/main.ssrg`を次のコードに置き換えてください。最初からある`src/app.ssrg`は、このガイドでは使いません。

`seseragi.toml`はそのままで構いません。CLIとBunの準備は[ローカルで使う](/docs/learn/local-development)を見てください。

## カウンター全体を書く

{/* example: examples/guides/web-app/src/main.ssrg */}
```seseragi title="src/main.ssrg"
import * as dom from "std/web/dom"
import * as html from "std/web/html"
import * as signals from "std/signal"
import { MutableSignal }
  from "std/signal"

alias Counter = MutableSignal<Int>
alias View = html.Html<Task<Unit>>

fn view count: Counter
  -> current: Int -> View =
  html.main {
    style: html.style {
      margin: "32px auto",
      maxWidth: "32rem",
      padding: "24px"
    },
    children: [
      html.h1 { children: "Counter" },
      html.p {
        children: `Count: ${current}`
      },
      html.button {
        buttonType: "button",
        onClick: signals.update
          (\n: Int -> n + 1) count,
        children: "Add one"
      },
      html.button {
        buttonType: "button",
        onClick: signals.set 0 count,
        children: "Reset"
      }
    ]
  }

fn perform action: Task<Unit>
  -> Task<Unit> = action

fn queryError error: dom.DomError
  -> String = show error

alias DomFailure =
  dom.DomRuntimeError<Never>

fn runtimeError error: DomFailure
  -> String = show error

pub effect fn main = do {
  count <- signals.make 0
  let content =
    signals.map (view count) count
  target <-
    dom.query "#app"
    |> mapError queryError
  let opts = dom.defaultOptions ()
  dom.run opts target perform content
  |> mapError runtimeError
}
```

`Counter`は`MutableSignal<Int>`、`View`は`Html<Task<Unit>>`に付けた[型の別名](/docs/learn/records-and-structs)です。`view`には、更新先のSignalと、表示する現在の整数を渡します。HTMLのpropsはレコードで、`children`に文字や子要素を入れます。

`signals.update`は今の値から次の値を計算するTaskを作り、`signals.set`は指定した値に変えるTaskを作ります。`onClick`に書いた時点では実行されません。クリックされると`dom.run`が`perform`へ渡し、返されたTaskを実行します。

## 開発サーバーで操作する

ロックファイルを更新してから、開発サーバーを起動します。

```sh
seseragi lock update
seseragi dev --open
```

`http://127.0.0.1:3000/`を開くと、「Count: 0」と表示されます。「Add one」を二回押すと「Count: 2」、「Reset」を押すと「Count: 0」に戻ります。

ソースを保存するとページが再読み込みされるので、カウンターも0に戻ります。

## Signalを画面につなぐ

`main`で`signals.make 0`を一回実行して、数を保存する場所を作ります。`signals.map (view count) count`は、数からHTMLを計算する読み取り専用のSignalです。数が変わると、新しい数で`view`を呼んだ結果に追従します。画面を計算するたびに状態を作り直すことはありません。

`dom.query`で表示先の`#app`を取得し、`dom.run`に画面のSignalを渡します。`dom.run`は、画面の変化とイベントを受け取り続け、終了時には購読とリスナーを解除します。イベントは起きた順に処理されます。細かい決まりは[Web UIリファレンス](/docs/reference/web-ui)にあります。

`queryError`と`runtimeError`は、表示先の取得や画面の実行で起きる失敗を`String`に変える関数です。`mapError`で失敗の型を揃えています。失敗の扱い方は[失敗を扱う](/docs/guides/error-handling)で説明しています。

## 見た目を整えてビルドする

`style`には、`html.style`で作ったスタイルを渡せます。この例では、`maxWidth`・`margin`・`padding`で幅を抑えて中央に寄せ、内側に余白を付けています。CSSのクラス名を使うときは`class`を使います。

開発サーバーを`Ctrl-C`で止め、ロックファイルを更新してからビルドします。

```sh
seseragi lock update
seseragi build .
```

`dist/`に`index.html`やJavaScript、CSSができます。HTMLファイルを直接開くのではなく、HTTPサーバーや静的ホスティングで配信してください。
