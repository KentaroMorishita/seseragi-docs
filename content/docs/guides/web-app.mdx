title: Webアプリを作る
description: 純粋な更新関数とHTMLから、操作できるカウンターを作る。
---

「Add one」で数が増え、「Reset」で0に戻るカウンターを作ります。状態は`Int`、ボタンの操作は`Action`という型、画面は状態から作るHTMLで表します。ブラウザへの表示は`dom.app`に任せます。

Actionの定義には、「学ぶ」の[代数的データ型](/docs/learn/algebraic-data-types)と[パターンマッチ](/docs/learn/pattern-matching)の内容を使います。

## プロジェクトを作る

```sh
seseragi new web counter
cd counter
```

`src/main.ssrg`を次のコードに置き換えてください。最初からある`src/app.ssrg`は、このガイドでは使いません。

`seseragi.toml`はそのままで構いません。CLIとBunの準備は[ローカルで使う](/docs/learn/local-development)を見てください。

## カウンター全体を書く

{/* example: examples/guides/web-app/src/main.ssrg */}
```seseragi title="src/main.ssrg"
import * as dom from "std/web/dom"
import * as html from "std/web/html"

type Action =
  | Increment
  | Reset

alias View = html.Html<Action>

fn update action: Action -> n: Int
  -> Int =
  match action {
    Increment -> n + 1
    Reset -> 0
  }

fn view count: Int -> View =
  html.main {
    style: html.style {
      margin: "32px auto",
      maxWidth: "32rem",
      padding: "24px"
    },
    children: [
      html.h1 { children: "Counter" },
      html.p {
        children: `Count: ${count}`
      },
      html.button {
        buttonType: "button",
        onClick: Increment,
        children: "Add one"
      },
      html.button {
        buttonType: "button",
        onClick: Reset,
        children: "Reset"
      }
    ]
  }

pub effect fn main =
  dom.app {
    target: "#app",
    initial: 0,
    update,
    view
  }
```

`Increment`と`Reset`は、ユーザーが何をしたかを表します。`update`は、今の数とActionから次の数を返すだけの関数で、画面には触りません。`view`も、今の数から画面（`Html<Action>`）を作るだけの関数です。

`onClick: Increment`には、クリックで実行する処理ではなく、クリックされたら送るActionを書きます。

## 開発サーバーで操作する

ロックファイルを更新してから、開発サーバーを起動します。

```sh
seseragi lock update
seseragi dev --open
```

`http://127.0.0.1:3000/`を開くと、「Count: 0」と表示されます。「Add one」を二回押すと「Count: 2」、「Reset」を押すと「Count: 0」に戻ります。

ソースを保存するとページが再読み込みされるので、カウンターも0に戻ります。

## 状態とDOMの管理を読む

`dom.app`は、初期値を入れたSignalを作り、`view`で画面を作ります。イベントが起きるたびに`update`で次の状態を計算し、変わったところだけ画面に反映します。中で特別なことをしているわけではなく、Signalの作成・表示先の取得・イベントの接続をまとめた、普通の標準ライブラリの関数です。

イベントは起きた順に処理されます。細かい決まりは[Web UIリファレンス](/docs/reference/web-ui)にあります。

## 見た目を整えてビルドする

`style`には、`html.style`で作ったスタイルを渡せます。この例では、`maxWidth`・`margin`・`padding`で幅を抑えて中央に寄せ、内側に余白を付けています。CSSのクラス名を使うときは`class`を使います。

開発サーバーを`Ctrl-C`で止め、ロックファイルを更新してからビルドします。

```sh
seseragi lock update
seseragi build .
```

`dist/`に`index.html`やJavaScript、CSSができます。HTMLファイルを直接開くのではなく、HTTPサーバーや静的ホスティングで配信してください。
