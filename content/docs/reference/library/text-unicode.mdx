## 選び方と注意

- 正規化のformは明示します。canonicalなNFC/NFDとcompatibilityなNFKC/NFKDでは、同一化する範囲が違います。
- StringのEqはscalar列の完全一致です。同じ見た目でも、正規化前の異なる列を自動で等しく扱いません。
- simpleCaseFoldは一scalarから一scalar、fullCaseFoldは複数scalarへの展開も許します。どちらもロケール非依存です。
- Unicode data versionはtoolchainとruntimeで固定・照合されます。ホスト ICUや実行OSのUnicode versionへ意味を委ねません。
