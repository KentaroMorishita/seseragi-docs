## import

```seseragi
import * as benchmark
  from "std/benchmark"
```

## 選び方と注意

- Benchmarkは計測bodyを持つ通常のtreeです。測る計算をbody実行ごとに構築し、先に一度求めた結果の取得時間だけを測らないでください。
- blackBoxは同じ値を返すoptimization barrierです。コンパイル時定数の除去を防ぐもので、allocationや実行順を変える機能ではありません。
- inputSizeは正のproblem sizeをreportへ付けます。warmup、sample、ホスト/toolchain version、profileを揃えてbaselineを比較します。
- bodyの型付き失敗、defect、リソースの解放漏れはcaseの失敗として扱います。追加serviceをprovideし、計測用の共有mutable stateをtreeの外へ置かない構成にします。
