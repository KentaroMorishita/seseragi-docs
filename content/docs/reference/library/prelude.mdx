Preludeの名前はimportせずに使えます。用途ごとの操作は明示的なmoduleへ分けられています。

## このページの読み方

以下のsignatureは引数の順に型を並べ、最後に結果の型を示します。カリー化・制約・Effectの環境については[型の読み方](/docs/reference/library#型の読み方)で確認できます。

## 関数と演算子

### `-` / Sub.sub

<small className="api-kind">演算子</small>

operandの型で選択された標準trait instanceへdispatchします。

```seseragi
- via Sub.sub
```

### `:` / List cons

<small className="api-kind">演算子</small>

persistent Listのconsです。優先順位4・右結合で、head、tailを一度ずつ評価し、tailをO(1)で共有します。(:)はcurriedな関数です。

```seseragi
A : List<A> -> List<A>
```

### `!=` / Eq.eq

<small className="api-kind">演算子</small>

operandの型で選択された標準trait instanceへdispatchします。

```seseragi
!= via Eq.eq
```

### `??` / List cons

<small className="api-kind">演算子</small>

Maybe専用fallbackです。優先順位0・右結合で、左辺を一度評価し、Nothingのときだけfallbackを評価します。構文専用で、operator sectionやoverloadはありません。

```seseragi
Maybe<A> ?? A -> A
```
