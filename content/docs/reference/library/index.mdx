Seseragiの標準ライブラリを、Preludeを含む63の項目に分け、1,452の公開名を収録しています。用途からmoduleを選び、その型と関数を確認できます。

## 型の読み方

関数はカリー化されています。型は引数の順に並び、最後が結果の型です。コレクションの操作では、処理対象を最後の引数に置く関数が多く、[縦に並べたパイプライン](/docs/learn/functions-and-pipelines)へつなげられます。`where`は必要な[型クラス](/docs/reference/type-classes)の制約です。掲載するsignatureは型の表記であり、実行する定義ではありません。

`Effect<R, E, A>`の型引数は、必要な環境、型付きの失敗、成功値を表します。moduleをimportしてもEffectは実行されず、providerが提供されるわけでもありません。[Effect](/docs/reference/effects)と[runtime provider](/docs/reference/runtime-providers)で境界を確認できます。内部表現を隠した型には、必ずしも`Show`のinstanceがあるとは限りません。

## 実行環境

`process`はCLIやserverのprocess、`browser`はWebアプリやPlaygroundのブラウザ実行を表します。両環境のinterfaceがあっても、選んだproviderが必要な能力を提供する必要があります。moduleの対応環境だけでなく、signatureの環境と失敗型も確認してください。

## まだ提供されていない契約

`std/http/bun`はidentityと契約を持ちますが、公開interfaceはなく、importできません。現在提供されているserver APIは[`std/http/server`](/docs/reference/library/http-server)で確認してください。
