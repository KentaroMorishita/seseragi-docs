## import

```seseragi
import * as json from "std/json"
```

## 使ってみる

{/* example: examples/library/json.ssrg */}

```seseragi
import * as json from "std/json"

pub effect fn main =
  match json.parse
    "{\"ready\":true}" {
    Right _ -> println "Valid JSON"
    Left _ -> println "Invalid JSON"
  }
```

出力:

```text
Valid JSON
```

## 目的から試す

各断片は、このページ冒頭のimportを使い、`main`の`do`ブロック内で一つずつ試せます。下に示す出力は、断片を含むプログラムで確認しています。入口と実行手順は[最初のプログラム](/docs/learn/first-program)、`do`の順次実行は[Effect](/docs/learn/effects)を参照してください。

### JSONの文字列を出力する

JsonStringはJSONの値を作り、stringifyは引用符を含むJSONテキストへ変換します。

{/* example: examples/library/json-recipes.ssrg#stringify */}

```seseragi
json.JsonString "hello"
|> json.stringify
|> println
```

出力:

```text
"hello"
```

### JSONとして読めない入力

閉じていないオブジェクトはparseに失敗します。Leftを処理することで、後のdecodeへ進めない入力を分けられます。

{/* example: examples/library/json-recipes.ssrg#invalid-syntax */}

```seseragi
match json.parse "{" {
  Right _ -> println "Valid JSON"
  Left _ -> println "Invalid JSON"
}
```

出力:

```text
Invalid JSON
```

### JSONの数値をIntで読む

型注釈でIntのdecodeを選びます。JSONの数値42はRight 42として読み取れます。

{/* example: examples/library/json-recipes.ssrg#decode-int */}

```seseragi
let decodedNumber:
  Either<json.JsonReadError, Int> =
    json.decodeString "42"
match decodedNumber {
  Right n -> println (show n)
  Left _ -> println "Not an Int"
}
```

出力:

```text
42
```

### 正しいJSONでも型が違う入力

trueは正しいJSONですがIntではありません。構文の読み取りと、欲しい型へのdecodeは別の段階です。

{/* example: examples/library/json-recipes.ssrg#wrong-type */}

```seseragi
let typeMismatch:
  Either<json.JsonReadError, Int> =
    json.decodeString "true"
match typeMismatch {
  Right n -> println (show n)
  Left _ -> println "Not an Int"
}
```

出力:

```text
Not an Int
```

## 選び方と注意

- JSON numberは正確なDecimalとしてparseします。重複object fieldは後勝ちにせずエラーで、NaN・infinity・comment・trailing commaも受理しません。
- 構文失敗とdomain decode失敗を区別します。decoderのエラーのpathはrootから失敗field/indexまでを保持するため、その情報をStringだけへ潰さず扱います。
- requiredなMaybe fieldもfield自体は必要で、Nothingはexplicit nullです。optional fieldのmissingとは違うので、schemaでpresenceの扱いを決めます。
- stringifyはobjectの挿入順を保ちます。Eqが順序を無視するMap同士でも、シリアライズが同じバイトになる保証はありません。

## 型と型クラス

### `DecodeError`

<small className="api-kind">内部表現を隠したstruct</small>

decode失敗のrootからleafまでのpathと失敗種別を報告します。

```text
DecodeError
```

### `DecodeErrorKind`

<small className="api-kind">内部表現を隠した型</small>

```text
DecodeErrorKind
```

### `Decoder`

<small className="api-kind">型alias</small>

path付きの型付きDecodeErrorを返すpureなJson decoderです。

```text
Decoder<_>
```

### `Encoder`

<small className="api-kind">型alias</small>

値をJsonへencodeするpure関数です。

```text
Encoder<_>
```

### `Json`

<small className="api-kind">内部表現を隠した型</small>

正確なDecimal数値と順序付きobject fieldを持つJSON値です。

```text
Json
```

### `JsonParseError`

<small className="api-kind">内部表現を隠した型</small>

不正な構文または重複object fieldを報告します。

```text
JsonParseError
```

### `JsonPathSegment`

<small className="api-kind">内部表現を隠した型</small>

```text
JsonPathSegment
```

### `JsonReadError`

<small className="api-kind">内部表現を隠した型</small>

JSONの構文失敗と値のdecode失敗を区別します。

```text
JsonReadError
```

## 関数と演算子

### `array`

<small className="api-kind">関数</small>

JSON Arrayの全要素をsource順に復号します。

```text
array<A>
  (Json -> Either<DecodeError, A>)
  -> Json
  -> Either<DecodeError, Array<A>>
```

### `decodeString`

<small className="api-kind">関数</small>

選択されたJsonDecode辞書でtextをparseしてdecodeします。

```text
decodeString<A>
  String
  -> Either<JsonReadError, A>
where
  JsonDecode<A>
```

### `encodeString`

<small className="api-kind">関数</small>

選択されたJsonEncode辞書で値をencodeします。

```text
encodeString<A>
  A
  -> String
where
  JsonEncode<A>
```

### `field`

<small className="api-kind">関数</small>

必須object fieldを復号し、失敗pathの先頭へfieldのsegmentを追加します。

```text
field<A>
  String
  -> (
       Json
       -> Either<DecodeError, A>
     )
  -> Json
  -> Either<DecodeError, A>
```

### `flatMap`

<small className="api-kind">関数</small>

成功したdecoder結果から、次のdecoderを選びます。

```text
flatMap<A, B>
  (
    A
    -> Json
    -> Either<DecodeError, B>
  )
  -> (
       Json
       -> Either<DecodeError, A>
     )
  -> Json
  -> Either<DecodeError, B>
```

### `index`

<small className="api-kind">関数</small>

Arrayの一つの位置を復号し、失敗pathの先頭へindexを追加します。

```text
index<A>
  Int
  -> (
       Json
       -> Either<DecodeError, A>
     )
  -> Json
  -> Either<DecodeError, A>
```

### `map`

<small className="api-kind">関数</small>

decoderの成功結果を変換します。

```text
map<A, B>
  (A -> B)
  -> (
       Json
       -> Either<DecodeError, A>
     )
  -> Json
  -> Either<DecodeError, B>
```

### `oneOf`

<small className="api-kind">関数</small>

decoderを順に試し、最初の成功結果を返します。

```text
oneOf<A>
  Array<
    (Json -> Either<DecodeError, A>)
  >
  -> Json
  -> Either<DecodeError, A>
```

### `optionalField`

<small className="api-kind">関数</small>

object fieldをMaybeとして復号し、field不在だけをNothingとして受理します。

```text
optionalField<A>
  String
  -> (
       Json
       -> Either<DecodeError, A>
     )
  -> Json
  -> Either<DecodeError, Maybe<A>>
```

### `parse`

<small className="api-kind">関数</small>

RFC 8259 JSONを正確なDecimal数値としてparseし、重複fieldを拒否します。

```text
parse
  String
  -> Either<JsonParseError, Json>
```

### `record`

<small className="api-kind">関数</small>

宣言した同種object field集合を復号し、未知のfieldを拒否します。

```text
record<A>
  Array<
    (
      String,
      (
        Json
        -> Either<DecodeError, A>
      )
    )
  >
  -> Json
  -> Either<
       DecodeError,
       Array<(String, A)>
     >
```

### `stringify`

<small className="api-kind">関数</small>

最小限のescapeで、compactかつ決定的なJSONを書きます。

```text
stringify
  Json
  -> String
```
