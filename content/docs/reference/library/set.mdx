## import

```seseragi
import * as set from "std/set"
```

## 選び方と注意

- 重複を除くmembershipにはSetを使います。要素は`Eq`と`Hash`を必要とし、反復は最初の挿入順です。
- 既存要素の挿入は順序を変えず、削除後の再挿入は末尾へ入ります。`union`は左側を保ち、右側だけの要素を後へ加えます。
- 変換後の同値な要素は一つになります。Setには形を保つFunctor instanceがないため、`std/set`の`map`を明示して使います。
- SetのEqは順序を無視します。ハッシュが適切ならmembershipは期待計算量O(1)ですが、ハッシュ衝突のコストは残ります。
