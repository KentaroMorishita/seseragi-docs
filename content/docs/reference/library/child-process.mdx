## 型と型クラス

### `CapturedProcess`

<small className="api-kind">struct</small>

```text
struct CapturedProcess {
  status: ChildExitStatus,
  stdout: Bytes,
  stderr: Bytes
}
```

- `status`: 子processが終了したときの結果。
- `stdout`: captureした標準出力のBytes。
- `stderr`: captureした標準エラー出力のBytes。
