## 使ってみる

{/* example: examples/library/bytes-hex.ssrg */}

```seseragi
import * as bytes from "std/bytes"
import * as hex from "std/bytes/hex"

pub effect fn main =
  match bytes.fromInts [65, 66] {
    Right value ->
      value
      |> hex.encode
      |> println
    Left _ -> println "Invalid byte"
  }
```

出力:

```text
4142
```

## このページの読み方

以下のsignatureは引数の順に型を並べ、最後に結果の型を示します。カリー化・制約・Effectの環境については[型の読み方](/docs/reference/library#型の読み方)で確認できます。

## 型と型クラス

### `HexDecodeError`

<small className="api-kind">内部表現を隠した型</small>

不正なhex text入力を、そのUTF-8 byte位置とともに表します。

```text
HexDecodeError
```

## コンストラクタと値

### `InvalidHexDigit`

<small className="api-kind">コンストラクタ</small>

最初のhex以外のdigitのUTF-8 byte offsetを報告します。

```text
InvalidHexDigit
  { offset: Int }
  -> HexDecodeError
```

### `OddHexLength`

<small className="api-kind">コンストラクタ</small>

UTF-8 byte数で測った、奇数長のhex入力を報告します。

```text
OddHexLength
  Int
  -> HexDecodeError
```

## 関数と演算子

### `decode`

<small className="api-kind">関数</small>

ASCIIのhex textを復号し、最初の失敗を型付きerrorで返します。

```text
decode
  String
  -> Either<HexDecodeError, Bytes>
```

### `encode`

<small className="api-kind">関数</small>

Bytesをcanonicalなlowercase hex textへencodeします。

```text
encode
  Bytes
  -> String
```
