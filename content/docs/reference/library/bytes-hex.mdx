## import

```seseragi
import * as bytes_hex
  from "std/bytes/hex"
```

## 使ってみる

{/* example: examples/library/bytes-hex.ssrg */}

```seseragi
import * as bytes from "std/bytes"
import * as hex from "std/bytes/hex"

pub effect fn main =
  match bytes.fromInts [65, 66] {
    Right value ->
      value
      |> hex.encode
      |> println
    Left _ -> println "Invalid byte"
  }
```

出力:

```text
4142
```

## 目的から試す

各断片は、このページ冒頭のimportを使い、`main`の`do`ブロック内で一つずつ試せます。下に示す出力は、断片を含むプログラムで確認しています。入口と実行手順は[最初のプログラム](/docs/learn/first-program)、`do`の順次実行は[Effect](/docs/learn/effects)を参照してください。

### 16進文字列をBytesへ戻す

decodeが成功するとBytesを得ます。encodeで戻すと、同じ16進文字列を確認できます。

{/* example: examples/library/bytes-hex-recipes.ssrg#roundtrip */}

```seseragi
match bytes_hex.decode "4142" {
  Right bytes ->
    bytes
    |> bytes_hex.encode
    |> println
  Left _ -> println "Invalid hex"
}
```

出力:

```text
4142
```

### 16進数以外の文字を受け取る

Zは16進数の桁として読めないため、decodeはLeftを返します。

{/* example: examples/library/bytes-hex-recipes.ssrg#invalid */}

```seseragi
match bytes_hex.decode "ZZ" {
  Right _ -> println "Valid hex"
  Left _ -> println "Invalid hex"
}
```

出力:

```text
Invalid hex
```

## このページの読み方

以下のsignatureは引数の順に型を並べ、最後に結果の型を示します。カリー化・制約・Effectの環境については[型の読み方](/docs/reference/library#型の読み方)で確認できます。

## 型と型クラス

### `HexDecodeError`

<small className="api-kind">内部表現を隠した型</small>

不正なhex text入力を、そのUTF-8 byte位置とともに表します。

```seseragi
HexDecodeError
```

## コンストラクタと値

### `InvalidHexDigit`

<small className="api-kind">コンストラクタ</small>

最初のhex以外のdigitのUTF-8 byte offsetを報告します。

```seseragi
InvalidHexDigit
  { offset: Int }
  -> HexDecodeError
```

### `OddHexLength`

<small className="api-kind">コンストラクタ</small>

UTF-8 byte数で測った、奇数長のhex入力を報告します。

```seseragi
OddHexLength
  Int
  -> HexDecodeError
```

## 関数と演算子

### `decode`

<small className="api-kind">関数</small>

ASCIIのhex textを復号し、最初の失敗を型付きerrorで返します。

```seseragi
decode
  String
  -> Either<HexDecodeError, Bytes>
```

### `encode`

<small className="api-kind">関数</small>

Bytesをcanonicalなlowercase hex textへencodeします。

```seseragi
encode
  Bytes
  -> String
```
