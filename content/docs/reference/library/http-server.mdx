## 選び方と注意

- 現在のrequest bodyはBytesのsnapshotです。textやJSONへはdecodeを明示し、ホストのRequest objectを直接操作しません。
- server境界のhandlerはNever failureです。アプリの型付きエラーはrecoverHandlerなどでresponseへ写し、暗黙の500 responseへ変換する挙動に依存しません。
- serverとrequestは親子のリソースのスコープを持ちます。close、client disconnect、root キャンセルではrequestの処理やstream bodyを終了して後始末します。
- streamResponseのchunkは1〜65,536バイトです。送信先の要求に合わせて送り、defectとキャンセルを起動時の型付き失敗へ混ぜません。
