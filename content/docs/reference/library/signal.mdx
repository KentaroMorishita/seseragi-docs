## import

```seseragi
import * as signal from "std/signal"
```

## 選び方と注意

- 現在値のreadと元Signalの更新はEffectです。pureなmap/combineはdependencyを明示し、関数内のreadを自動追跡しません。
- 同じ値のsetも既定では通知します。重複を止める場合はEqを必要とするdistinctを明示します。
- 複数更新はtransactionで一度commitし、安定したderived値だけを通知します。複数readが同じsnapshotになる保証はないため、組のsnapshotにはcombineしたSignalを一度readします。
- subscribeは現在値を一度通知し、その後も順番にobserverを実行します。observerのfailureはNeverへ揃え、購読はスコープ終了かunsubscribeで解除します。

## 関数と演算子

### `combine`

<small className="api-kind">関数</small>

```text
combine<A, B, C>
  (A -> B -> C)
  -> Signal<A>
  -> Signal<B>
  -> Signal<C>
```

### `constant`

<small className="api-kind">関数</small>

```text
constant<A>
  A
  -> Signal<A>
```

### `distinct`

<small className="api-kind">関数</small>

```text
distinct<A>
  Signal<A>
  -> Signal<A>
where
  Eq<A>
```

### `make`

<small className="api-kind">関数</small>

Effect内でmutable Signalを作ります。

```text
make<A>
  A
  -> Effect<
       {},
       Never,
       MutableSignal<A>
     >
```

### `map`

<small className="api-kind">関数</small>

各現在値を変換するderived Signalを作ります。

```text
map<A, B>
  (A -> B)
  -> Signal<A>
  -> Signal<B>
```

### `planSet`

<small className="api-kind">関数</small>

```text
planSet<A>

  -> MutableSignal<A>
  -> SignalChange
```

### `planUpdate`

<small className="api-kind">関数</small>

```text
planUpdate<A>

  -> MutableSignal<A>
```

### `read`

<small className="api-kind">関数</small>

