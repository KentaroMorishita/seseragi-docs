## 使ってみる

{/* example: examples/library/float.ssrg */}

```seseragi
import * as floats from "std/float"

pub effect fn main =
  match floats.parse "1.5" {
    Right value ->
      value
      |> floats.format
      |> println
    Left _ ->
      println "Invalid number"
  }
```

出力:

```text
1.5
```

## 選び方と注意

- NaNが反射律を壊すため、Floatに標準Eq・Ord・Hashはありません。IEEE equalityにはieeeEq、全順序にはtotalCompareを明示します。
- parseは前後の空白を受理せず、有限な文字列表記のoverflowを型付きエラーにします。NaN・infinity・負のゼロは別の状態として扱います。
- Intへ変換するときは丸めmodeを指定し、finiteとsafe integer範囲を検査します。Floatを整数に見える表示だけでIntとして扱わないでください。
- Floatには標準JSON codecがありません。wireの数値方針を決め、Decimalや明示converterを使います。
