## import

```seseragi
import * as web_html
  from "std/web/html"
```

## 使ってみる

{/* example: examples/library/web-html.ssrg */}

```seseragi
import * as html from "std/web/html"

pub effect fn main =
  html.p { children: "Hello" }
  |> html.renderToString
  |> println
```

出力:

```text
<p>Hello</p>
```

## 選び方と注意

- Htmlはpureな不変treeで、componentは普通の関数です。treeを作るだけでDOM、購読、hookのstateを生成しません。
- childrenはString、Html、そのArray/Listなどです。数値はshow/textで明示変換し、ArrayでStringとHtmlをarbitrary unionにしません。
- textはSSR/DOMのsinkで一度escapeします。URLとcustom attributeは検査済みの値を使い、raw HTML Stringをuncheckedに挿入しません。
- SSRはeventを実行せず、event propやキーをattributeへ出しません。browserのDOM接続はstd/web/domへ分けます。
