## import

```seseragi
import * as test from "std/test"
```

## 選び方と注意

- Testは通常の不変treeで、構築時にbodyを実行しません。runnerが選択したcaseだけを実行し、tests rootではpub let testsとして公開します。
- equalはEqで比較し、失敗表示にはDebugを使います。Floatには標準Eqがないため、目的に合う名前付き比較でBoolを作って検査します。
- expectFailureは型付き失敗だけを対象にします。defectやキャンセルを「期待どおりのエラー」として成功へ変えません。
- caseごとのenvironmentとリソースのスコープは独立です。追加serviceはtest doubleをprovideし、seedやpropertyの最小化inputを保存して再現します。
