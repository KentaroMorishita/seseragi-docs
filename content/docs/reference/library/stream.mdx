## import

```seseragi
import * as stream from "std/stream"
```

## 選び方と注意

- Streamはcoldで、終端操作ごとに独立したproducerとスコープを作ります。同じStreamを二度実行しても購読を共有しません。
- 既定はpull-basedです。bufferは満杯ならproducerを待たせ、dropする方針はbufferDroppingなどで明示します。
- flatMapは各innerを順番に最後まで処理します。mergeは別の並行合成で、順序とfailureの選択をその契約に従って扱います。
- runCollectは有限Streamに使います。無限Streamでは完了せず値を保持し続けるため、必要ならtakeなどで止めます。途中終了やキャンセルでも上流のリソースを閉じます。
