## このページの読み方

## 型と型クラス

### `Base64DecodeError`

<small className="api-kind">内部表現を隠した型</small>

厳密なRFC 4648 Base64復号の失敗を表します。

```seseragi
Base64DecodeError
```

## コンストラクタと値

### `InvalidBase64Digit`

<small className="api-kind">コンストラクタ</small>

最初の不正なBase64 digitのUTF-8 byte offsetを報告します。

```seseragi
InvalidBase64Digit
  { offset: Int }
  -> Base64DecodeError
```

### `InvalidBase64Length`

<small className="api-kind">コンストラクタ</small>

UTF-8 byte数で測った、不正なBase64入力長を報告します。

```seseragi
InvalidBase64Length
  Int
  -> Base64DecodeError
```

### `InvalidBase64Padding`

<small className="api-kind">コンストラクタ</small>

不正なBase64 paddingのUTF-8 byte offsetを報告します。

```seseragi
InvalidBase64Padding
  { offset: Int }
  -> Base64DecodeError
```

### `NonCanonicalBase64Bits`

<small className="api-kind">コンストラクタ</small>

最後のBase64 sextetで、未使用bitが0ではないことを報告します。

```seseragi
NonCanonicalBase64Bits
  { offset: Int }
  -> Base64DecodeError
```
