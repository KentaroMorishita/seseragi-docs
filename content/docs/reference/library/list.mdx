## import

```seseragi
import * as list from "std/list"
```

## 使ってみる

{/* example: examples/library/list.ssrg */}

```seseragi
import * as lists from "std/list"

pub effect fn main =
  `[10, 20, 30]
  |> lists.toArray
  |> show
  |> println
```

出力:

```text
[10, 20, 30]
```

## 選び方と注意

- 先頭を追加しながら組み立てる列にはListを使います。consとtailはO(1)で、既存tailを共有できます。
- `length`、`get`、`last`、`init`は線形走査です。添字を繰り返し使う処理にはArrayを検討してください。
- `append suffix values`はvaluesの後へsuffixを連結し、valuesの長さに比例します。末尾へのappendを繰り返す構成はコストが積み重なります。
- Arrayへの変換は順序を保つコピーです。Listの結果もstrictなので、遅延した無限列としては使いません。

## 関数と演算子

### `append`

<small className="api-kind">関数</small>

collectionの値の後ろへsuffixを連結します。

```text

  List<A>
  -> List<A>
  -> List<A>
```

<small className="api-kind">関数</small>

