## import

```seseragi
import * as bytes from "std/bytes"
```

## 選び方と注意

- Bytesは不変のバイト列です。foreignのUint8Array境界では両方向にコピーし、ホストのmutable viewを共有しません。
- Byteの構築は0〜255を検査します。getは範囲外をNothing、sliceは不正な終端を含まない範囲を型付きエラーで返し、clampしません。
- sliceは内部ストレージを共有できます。小さいsliceを長期間保持して元の大きなストレージを解放したい場合はコピーを使います。
- Bytesをtextとして扱う場合は文字encodingを明示します。strictなUTF-8 decodeは不正位置を返し、lossy decodeは置換文字へ置換する別の方針です。

## 型と型クラス

### `Byte`

<small className="api-kind">内部表現を隠した型</small>

0〜255を含む範囲のopaqueなunsigned 8-bit値です。

```text
Byte
```

### `ByteError`

<small className="api-kind">内部表現を隠した型</small>

Byteで表せないIntを表します。

```text
ByteError
```

### `Bytes`

<small className="api-kind">内部表現を隠した型</small>

copyの境界を明示した不変byte列です。

```text
Bytes
```

### `BytesSliceError`

<small className="api-kind">内部表現を隠した型</small>

不正な半開Bytes slice範囲を表します。

```text
BytesSliceError
```

## コンストラクタと値

### `ByteOutOfRange`

<small className="api-kind">コンストラクタ</small>

<small className="api-kind">コンストラクタ</small>

## 関数と演算子

### `append`

<small className="api-kind">関数</small>

collectionの値の後ろへsuffixを連結します。

```text

  Bytes
  -> Bytes
  -> Bytes
```

### `byte`

<small className="api-kind">関数</small>

Intを検査し、opaque Byteへ変換します。

```text
byte
  Int
  -> Either<ByteError, Byte>
```

### `concat`

<small className="api-kind">関数</small>

```text

  Array<Bytes>
  -> Bytes
```

### `copy`

<small className="api-kind">関数</small>

元のBytesから独立したcopyを作ります。

```text
copy
  Bytes
  -> Bytes
```

### `empty`

<small className="api-kind">関数</small>

空の不変Bytesを作ります。

```text
empty
  Unit
  -> Bytes
```

### `fromArray`

<small className="api-kind">関数</small>

```text
fromArray
  Array<Byte>
  -> Bytes
```

### `fromInts`

<small className="api-kind">関数</small>

```text

  Array<Int>
  -> Either<ByteError, Bytes>
```
