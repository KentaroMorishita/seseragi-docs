### `take`

<small className="api-kind">Effectを返す関数</small>

Queueから一つの値を取り出すEffectを返します。空なら値を待ち、閉じられたQueueに残りの値がなければQueueClosedで失敗します。

```seseragi
take<A>
  Queue<A>
  -> Effect<{}, QueueClosed, A>
```
