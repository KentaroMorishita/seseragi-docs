## 選び方と注意

- 表示上のcursor移動や文字数制限には、extended grapheme clusterを使います。結合文字やemojiをscalar数だけで切らないためのAPIです。
- 分割はUnicodeのUAX #29規則に従いますが、正規化はしません。clusterを連結すると元のStringへバイト単位で戻ります。
- atは範囲外をNothing、sliceは不正な終端を含まない範囲を型付きエラーで返します。indexを暗黙にclampしません。
- 各操作は入力バイト数に対する走査を必要とします。繰り返し位置を使う場合は、clustersやバイトBoundariesを一度求める構成を検討してください。
