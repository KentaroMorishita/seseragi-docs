## import

```seseragi
import * as time from "std/time"
```

## 選び方と注意

- Instant、localな日時、UTC offset、time zoneは別の型です。壁時計の表示とtimeline上の時点を、暗黙変換で混ぜません。
- Durationは非負で、構築と加算の範囲を検査します。不正な日付や時刻も、自動補正せず型付きエラーとして扱います。
- local日時をzoneへ解決するとUnique・Ambiguous・Gapがあります。夏時間の重複や欠落で、どの方針を使うかをアプリが明示します。
- timezone databaseはversionを固定し、取得はTimeZones capabilityを要求します。ホストの設定だけでzone規則が変わることを前提にしません。
