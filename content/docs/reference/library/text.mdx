## import

```seseragi
import * as text from "std/text"
```

## 選び方と注意

- indexの単位はUnicode scalarです。UTF-8バイト長や、画面上の一文字を数えるgrapheme APIとは使い分けます。
- split・replaceはliteral Stringを使い、replacementの`$`などは展開しません。正規表現を使う場合は`std/regex`を明示します。
- scalar sliceは終端を含まない範囲を検査し、不正なindexをclampしません。scalarAtなどの走査をO(1)の添字による直接参照として扱わないでください。
- case変換とtrimは共有Unicode規則を使い、ロケール固有の変換はしません。trimはU+FEFFを削除しません。
