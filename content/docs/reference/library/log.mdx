### `LogEvent`

<small className="api-kind">struct</small>

```text
struct LogEvent {
  level: LogLevel,
  message: String,
  fields: List<(String, LogValue)>
}
```

- `level`: 記録するlogのlevel。
- `message`: logの本文。
- `fields`: 名前とLogValueを組にした追加情報の列。
