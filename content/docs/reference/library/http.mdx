## import

```seseragi
import * as http from "std/http"
```

## 選び方と注意

- non-2xx statusもresponseとして成功します。HTTPの業務上の失敗と、DNS・TLS・socketなどのtransport failureを分けて扱います。
- sendBytes/sendEmptyはbodyをメモリへ集めるsmall-response APIです。明示した上限を超えるとキャンセルし、型付きエラーを返します。
- Headersはcase-insensitiveな順序付きmulti-mapです。複数valueをcommaで自動結合しないため、Set-Cookieなどの独立した値を保てます。
- redirect、cookie jar、認証、retry、timeout、Content-Encoding decodeは自動適用しません。bodyのtext/JSON decodeもアプリの方針で明示します。
- exchangeはcoldなStreamです。terminal実行ごとにrequestを開始し、キャンセルや途中終了でもbodyとconnectionのリソースを解放します。

### `ResponseHead`

<small className="api-kind">struct</small>

```text

  version: HttpVersion,
  status: Status,
  headers: Headers
```

- `status`: 検証済みのHTTP status。
- `headers`: 本文とは別に受信した不変のheader列。
