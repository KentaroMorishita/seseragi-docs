## import


## 目的から試す

各断片は、このページ冒頭のimportを使い、`main`の`do`ブロック内で一つずつ試せます。下に示す出力は、断片を含むプログラムで確認しています。入口と実行手順は[最初のプログラム](/docs/learn/first-program)、`do`の順次実行は[Effect](/docs/learn/effects)を参照してください。

### あるキーを読む

singletonで一組だけのMapを作ります。getはキーに対応する値をJustで返します。

{/* example: examples/library/map-recipes.ssrg#get-present */}

```seseragi
map.singleton "visits" 1
|> map.get "visits"
|> show
|> println
```

出力:

```text
Just 1
```

### ないキーを読む

MapにないキーではNothingを返します。数値の0と、キーが存在しないことは別です。

{/* example: examples/library/map-recipes.ssrg#get-missing */}

```seseragi
map.singleton "visits" 1
|> map.get "errors"
|> show
|> println
```

出力:

```text
Nothing
```

### 元のMapを保って更新する

insertは新しいMapを返します。同じキーを更新しても、beforeから読むと1、afterから読むと2です。

{/* example: examples/library/map-recipes.ssrg#persistent-insert */}

```seseragi
let before = map.singleton "visits" 1
let after =
  map.insert "visits" 2 before
before
|> map.get "visits"
|> show
|> println
after
|> map.get "visits"
|> show
|> println
```

出力:

```text
Just 1
Just 2
```

## 選び方と注意

- キーは`Eq`と`Hash`を持ち、等しいキーのハッシュも等しくなる必要があります。適切なハッシュなら検索・個別の更新は期待計算量O(1)ですが、衝突時は線形になります。
- 反復は挿入順です。既存キーの更新は位置を保ち、削除して再挿入したキーは末尾へ移ります。
- `fromEntries`の重複キーは最後の値を採用し、位置は最初の出現位置を保ちます。衝突した値を合成する処理には、明示したresolverを使います。
- MapのEqは挿入順を比較しません。表示やシリアライズは順序を保つため、EqなMapでも出力バイトが同じとは限りません。
