### `get`

<small className="api-kind">Effectを返す関数</small>

指定したstorage領域のキーを読むEffectを返します。キーがなければNothingを返し、読み取りが失敗すればStorageErrorで失敗します。

```seseragi
get
  StorageArea
  -> String
  -> Effect<
       { storage: Storage },
       StorageError,
       Maybe<String>
     >
```
