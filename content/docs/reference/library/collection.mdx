## このページの読み方

以下のsignatureは引数の順に型を並べ、最後に結果の型を示します。カリー化・制約・Effectの環境については[型の読み方](/docs/reference/library#型の読み方)で確認できます。

## 型と型クラス

### `ReduceStep`

<small className="api-kind">内部表現を隠した型</small>

pureなreduce制御です。Nextは継続、Doneは停止です。

```text
ReduceStep<_>
```

### `SizeError`

<small className="api-kind">内部表現を隠した型</small>

```text
SizeError
```

## コンストラクタと値

### `Done`

<small className="api-kind">コンストラクタ</small>

この結果でreduceUntilを終えることを表すReduceStepの値を作ります。

```text
Done<A>
  A
  -> ReduceStep<A>
```

### `Next`

<small className="api-kind">コンストラクタ</small>

次のaccumulatorでreduceUntilを続けることを表すReduceStepの値を作ります。

```text
Next<A>
  A
  -> ReduceStep<A>
```

### `NonPositiveSize`

<small className="api-kind">コンストラクタ</small>

```text
NonPositiveSize
  Int
  -> SizeError
```

## 関数と演算子

### `reduceUntil`

<small className="api-kind">関数</small>

Iterableをsource順にDoneまでfoldし、残りの要素は取得しません。

```text
reduceUntil<C, A, B>
  B
  -> (B -> A -> ReduceStep<B>)
  -> C
  -> B
where
  Iterable<C, A>
```
