## 型と型クラス

### `ReaderT`

<small className="api-kind">struct</small>

```seseragi
struct ReaderT<R, M<_>, A> {
  run: R -> M<A>
}
```

- `run`: 環境Rを受け取り、型構築子Mに入ったAの値を返す関数。
