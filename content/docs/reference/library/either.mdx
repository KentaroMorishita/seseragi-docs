## import

```seseragi
import * as either from "std/either"
```

## 使ってみる

{/* example: examples/library/either.ssrg */}

```seseragi
import * as either from "std/either"

pub effect fn main = {
  let result: Either<String, Int> =
    Right 41
  result
  |> either.mapRight (\n -> n + 1)
  |> show
  |> println
}
```

出力:

```text
Right 42
```

## 目的から試す

各断片は、このページ冒頭のimportを使い、`main`の`do`ブロック内で一つずつ試せます。下に示す出力は、断片を含むプログラムで確認しています。入口と実行手順は[最初のプログラム](/docs/learn/first-program)、`do`の順次実行は[Effect](/docs/learn/effects)を参照してください。

### 成功値だけを変換する

mapRightはRightの整数を変換します。foldで失敗文字列か成功値の表示を選びます。

{/* example: examples/library/either-recipes.ssrg#map-success */}

```seseragi
let success: Either<String, Int> =
  Right 41
success
|> either.mapRight (\n -> n + 1)
|> either.fold (\e -> e) show
|> println
```

出力:

```text
42
```

### 失敗をそのまま残す

LeftにmapRightを適用しても、成功値の関数は使われず、失敗文字列が残ります。

{/* example: examples/library/either-recipes.ssrg#keep-failure */}

```seseragi
let failure: Either<String, Int> =
  Left "offline"
failure
|> either.mapRight (\n -> n + 1)
|> either.fold (\e -> e) show
|> println
```

出力:

```text
offline
```

### 失敗側を変換する

mapLeftで失敗の文字列だけを変換できます。成功側の型はIntのままです。

{/* example: examples/library/either-recipes.ssrg#map-failure */}

```seseragi
let annotated: Either<String, Int> =
  Left "offline"
annotated
|> either.mapLeft (\e -> "API: " + e)
|> either.fold (\e -> e) show
|> println
```

出力:

```text
API: offline
```

## 選び方と注意

- Eitherは評価済みの同期結果です。Left/Rightを作ることは、遅延した処理を実行することではありません。
- `mapLeft`、`bimap`、`fold`は選ばれた分岐のコールバックだけを一度呼びます。成功の続きが前の値へ依存する場合は`flatMap`で合成します。
- `traverse`は複数Leftなら元の順序で最初のLeftを保持しますが、後続pure コールバックの短絡を保証しません。途中停止が必要なら`reduceUntil`を使います。
- 独立した入力のエラーをまとめる場合はValidationを使います。Eitherの失敗をEffectへ持ち上げる場合は`fromEither`を明示します。

## 関数と演算子

### `bimap`

<small className="api-kind">関数</small>

選択されたLeftまたはRightのbranchを一度だけ変換します。

```seseragi
bimap<E, F, A, B>
  (E -> F)
  -> (A -> B)
  -> Either<E, A>
  -> Either<F, B>
```

### `fold`

<small className="api-kind">関数</small>

選択されたbranchの関数だけを呼んでEitherを結果へ変換します。

```seseragi
fold<E, A, B>
  (E -> B)
  -> (A -> B)
  -> Either<E, A>
  -> B
```

### `mapLeft`

<small className="api-kind">関数</small>

Leftのpayloadだけを変換します。

```seseragi
mapLeft<E, F, A>
  (E -> F)
  -> Either<E, A>
  -> Either<F, A>
```

### `mapRight`

<small className="api-kind">関数</small>

標準Functor instanceでRightのpayloadだけを変換します。

```seseragi
mapRight<E, A, B>
  (A -> B)
  -> Either<E, A>
  -> Either<E, B>
```

### `sequence`

<small className="api-kind">関数</small>

identityでwrapped値を走査し、sourceの形と順序を保ちます。

```seseragi
sequence<F<_>, E, A>
  F<Either<E, A>>
  -> Either<E, F<A>>
where
  Traversable<F<_>>
```

### `swap`

<small className="api-kind">関数</small>

payloadを変えずLeftとRightを入れ替えます。

```seseragi
swap<E, A>
  Either<E, A>
  -> Either<A, E>
```

### `traverse`

<small className="api-kind">関数</small>

sourceのTraversableと、このmoduleのApplicativeを使います。別の走査実装は作りません。

```seseragi
traverse<F<_>, E, A, B>
  (A -> Either<E, B>)
  -> F<A>
  -> Either<E, F<B>>
where
  Traversable<F<_>>
```
