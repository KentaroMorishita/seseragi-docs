## このリファレンスの確認範囲

掲載した実行例は、配布版のSeseragi <strong><LanguageVersion /></strong>で確認しています。compilerの配布versionと、manifestの`package.language`が指定する言語versionは別です。manifestには、使っているcompilerが受理する言語rangeを指定します。

仕様に定義された将来の契約を、現在利用できるコマンドやAPIと同じ扱いにはしていません。未提供の機能に触れる場合は、その場所で区別します。最適化についても、消去できる構造と、現在のbackendが必ず行う最適化を分けて説明します。
