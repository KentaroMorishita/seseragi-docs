## このリファレンスについて

載せている例は、配布されているCLIで実行して確かめています。なお、コンパイラーのバージョンと、`seseragi.toml`の`package.language`に書く言語のバージョンは別物です。`package.language`には、使っているコンパイラーが受け付ける言語のバージョンの範囲を書きます。

言語仕様には、まだ実装されていない機能も書かれています。このリファレンスでは、今使える機能とまだ使えない機能を、その都度区別して説明します。最適化についても、「理論上できる最適化」と「今のコンパイラーが必ず行う最適化」を分けて書いています。
