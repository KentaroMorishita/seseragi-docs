TypeScript連携では、TypeScriptのモジュールを、型の付いた入口を通してSeseragiから使えるようにします。TypeScriptのユニオン型・`null`・書き換えられるオブジェクト・例外が、そのままSeseragiの中に入り込むことはありません。

## foreignと引数

foreign blockでホスト exportとSeseragi側の名前・型を宣言します。次は同期的・pureなJavaScript関数を使う、実行確認済みのパッケージ例です。

{/* example: examples/reference/interop/src/main.ssrg */}

```seseragi title="main.ssrg"
foreign "typescript"
from "../host/math.mjs" {
  pure fn add x: Int -> y: Int -> Int
}

pub effect fn main =
  add 20 22
  |> show
  |> println
```

つなぐTypeScriptのファイルは次のとおりです。パッケージの`seseragi.toml`の`[foreign.typescript]`には、TypeScript側の`package.json`とロックファイルを指定します。

```javascript title="host/math.mjs"
export function add(x, y) {
  return x + y;
}
```

出力は42です。Seseragiからは引数を一つずつ受け取る関数に見え、引数がすべてそろったときに、TypeScriptの`add(20, 22)`が一回呼ばれます。引数を一部だけ渡した段階では呼ばれません。TypeScript側のexport名が違う場合は、`= "host_name"`で正確な名前を指定します。

## pureとtask

| mode | 宣言の最後の型 | Seseragiで見える結果 |
| --- | --- | --- |
| `pure fn` | `A` | 普通の`A` |
| `task fn` | `A` | `Effect<{}, Js.Error, A>` |

pure バインディングのauthorは、同期的・決定的・非throw・外部状態の観測/変更なしを保証します。Promiseを返すpure宣言は不正です。保証違反はバインディング defectです。

taskはEffectを実行するまでホスト関数を呼びません。同期throwとPromiseLikeのrejectionを`Js.Error`へ変換します。load、lookup、同期throw、rejectionのphaseを保持するので、原因を一つのStringへ潰しません。

## モジュールの読み込みとクラス

resolved ホスト identityにpure memberが一つでもあるとpure-loadです。モジュールとtransitive ホスト依存関係の初期化にもpure保証が必要です。opaque typeとtask memberだけならtask-loadで、最初の実行までloadを遅延します。並行した初回callはloadを共有し、loadの成功・失敗をmemoizeします。

TypeScriptの名前空間は、`foreign`の中の`namespace`で明示します。`= "metrics.count"`と書いても、`metrics`オブジェクトの`count`という意味にはなりません。メソッドは呼び出す対象を最初の引数として、コンストラクターは`new`として、プロパティは読み取りとして、それぞれ宣言します。普通の関数に`this`が暗黙に渡されることはありません。

## 境界の型と値のコピー

| 境界型 | 扱う値 |
| --- | --- |
| `Js.Unknown`、`Js.Object` | まだ検査していない値。フィールドを直接は触らない |
| `Js.NullOr<A>` | `A`またはnull |
| `Js.UndefinedOr<A>` | `A`またはundefined |
| `Js.Nullable<A>` | nullとundefinedの両方を含むalias |
| `Js.Number`、`Js.String` | まだ検査していないTypeScriptの数値・文字列 |
| `Js.MutableArray<A>` | TypeScriptと共有する、書き換えられる配列 |
| `Js.Callback<Args, Result>` | いつまで使えるかを明示したコールバック |

これらの型が、Seseragiの普通の型に自動で変換されることはありません。`null`になりうる値は、自分で書く変換関数で`Maybe`にします。`Int`として受け取るときは、有限で、整数で、安全な範囲に収まっているかを確かめ、`-0`は0にします。`String`と`Char`は、壊れたサロゲートペアを含む値を受け付けず、`Char`は一文字であることを確かめます。

Array・タプル・レコードは、検査してからコピーして受け取ります。書き換えられるオブジェクトを、不変のレコードとして共有することはしません。`Bytes`はどちら向きでもコピーします。List・struct・ADTは、TypeScriptの値に自動では変換されません。レコードの省略可能なフィールドは、あるかないかがそのまま保たれます。

## 省略可能な引数、オーバーロード、コールバック

raw optional パラメーターは`Js.UndefinedOr<A>`で宣言します。undefinedを一個渡すことと、引数を省略することは別です。本当に省略が必要ならarityごとにバインディングを分けます。末尾のrestは`...parts: Array<A>`として一つだけ宣言できます。

overloadは採用するsignatureごとに別local名を与え、ランタイムで自動dispatchしません。同期pure コールバックはadapterにできますが、保持・非同期呼び出し・Effect実行を伴うコールバックは、解除とキャンセルを持つ明示adapterが必要です。

## .d.tsからの生成と手書きのラッパー

`seseragi dts convert`は、設定した`.d.ts`から、binding・付随情報・変換の結果のレポートを作ります。変換できなかった項目は、何でもありの型で済ませず、レポートに残します。`number`は`Float`に、普通の関数は純粋かどうか分からないので`task`に、省略可能なものは境界の型に変換されます。

生成したファイルは生成用のディレクトリに置かれます。手で書き換えず、`gen/`から手書きのラッパーにimportして使います。境界の型をそのままアプリに公開するのではなく、`Maybe`・`Either`・アプリのADTに変換するラッパーを用意してください。具体的な手順は[TypeScriptとの接続](/docs/guides/typescript-bindings)にあります。
