ソースはUTF-8で書いた`.ssrg`ファイルです。大文字と小文字は区別されます。型・コンストラクター・traitの名前は大文字で、値・関数・フィールド・モジュールの別名は小文字で始めます。`_`は「使わない値」を表す記号で、名前としては使えません。

## リテラルとコメント

| 表記 | 型・意味 |
| --- | --- |
| `42`、`0x2A`、`0b101010`、`0o52` | `Int` |
| `1_000` | 桁間の区切りを持つ`Int` |
| `3.14`、`1.0e-9` | `Float` |
| `True`、`False` | `Bool` |
| `'λ'` | `Char`、Unicodeスカラー値一個 |
| `"text"` | `String` |
| `` `hello ${name}` `` | `Show`による文字列テンプレート |
| `[1, 2]` | `Array<Int>` |
| `` `[1, 2] `` | `List<Int>` |
| `()` | `Unit`の唯一の値 |

`//`から行末まではコメントです。複数行をまとめてコメントにする構文はありません。名前にはUnicodeの文字を使え、末尾に`'`を付けることもできます（`account'`で一つの名前です）。

数値の中の`_`は、数字と数字の間に一つだけ置けます。`01`、`1__0`、`1.`、`.5`、途中で終わった指数部は書けません。正しくない数値や範囲外の数値は`SES-P0203`エラーです。`Int`の範囲と計算の決まりは[型](/docs/reference/types)にあります。

CharとStringでは、`\n`、`\r`、`\t`、`\0`、`\\`、`\u{03BB}`などのエスケープを使えます。Charに入るのは一文字（Unicodeスカラー値一つ）だけです。知らないエスケープは`SES-P0201`、二文字以上のCharは`SES-P0202`エラーです。テンプレート文字列は改行を含められ、`${expression}`は左から順に一度ずつ計算されます。

## 宣言と式

ファイルの一番外側には、importと宣言だけを書きます。`println "hello"`のような式をそのまま書くことはできず、実行したい処理は`pub`の`main`の中に書きます。

`if`・`match`・ブロックは、どれも値を返す式です。`if`の条件は`Bool`で、`else`は省略できず、二つの分岐は同じ型を返します。次のプログラムは`pass`を出力します。

{/* example: examples/reference/syntax.ssrg */}

```seseragi title="syntax.ssrg"
fn grade score: Int -> String =
  if score >= 80 then
    "pass"
  else
    "retry"

pub effect fn main =
  grade 88
  |> println
```

ブロックは`{ ... }`で囲み、最後の式の値を返します。宣言しかないブロックは`Unit`を返します。`{}`は空のレコードなので、何もしないブロックは`{ () }`と書きます。

### 式とブロックの結果

次の二つは式の例です。`let`の右辺に置くと、一つ目は`String`、二つ目は`Int`と推論されます。

{/* example: examples/reference/expression-forms.ssrg#if-value */}

```seseragi title="式: if"
if 3 > 0 then
  "positive"
else
  "zero"
```

この条件式の値は`"positive"`です。

{/* example: examples/reference/expression-forms.ssrg#block-result */}

```seseragi title="式: 最後の値"
{
  let minutes = 2
  minutes * 60
}
```

最後の`minutes * 60`がブロックの結果で、値は120です。

{/* example: examples/reference/expression-forms.ssrg#unit */}

```seseragi title="宣言: Unitを返す"
fn idle -> Unit = { () }
```

`idle ()`は`Unit`の値`()`を返します。次の空のレコードは、`Unit`とは別の型です。

{/* example: examples/reference/expression-forms.ssrg#empty-record */}

```seseragi title="式: empty record"
{}
```

### ifの結果型が違う場合

これは、わざとエラーにした例です。`String`を返す分岐と`Int`を返す分岐の型が合わないので、`SES-T0101`エラーになります。

{/* example: examples/reference/invalid/if-results.ssrg#invalid */}

```seseragi title="意図的な型エラー"
fn choose ready: Bool -> String =
  if ready then "ready" else 0

pub effect fn main =
  choose True
  |> println
```

## 改行と継続

インデントの幅に意味はありません。宣言や式は改行か`;`で区切り、括弧の中では自由に改行できます。行末が`=`のように続きを必要とする記号で終わっている場合や、次の行が`|>`・算術・比較などの演算子で始まる場合は、改行しても式は続いていると見なされます。

パイプラインは、最初の値と各`|>`を同じインデントで縦に並べます。関数呼び出しの途中で改行したいときは、括弧や`$`を使って続いていることをはっきりさせてください。`;`は常に式を区切ります。

## 適用と演算子

`add 1 2`は`(add 1) 2`と同じです。`f(x, y)`のような呼び出しの構文はありません。`x |> f`と`f $ x`は、どちらも`f x`と同じです。`$`は右結合なので、`f $ g $ x`は`f (g x)`です。どちらも、計算を後回しにしたりEffectを実行したりはしません。

優先順位の高い順に並べています。

| 段 | 演算子・構文 | 結合 |
| --- | --- | --- |
| 9 | フィールド、メソッド、添字 | 左 |
| 8 | 空白による関数適用 | 左 |
| 7 | `!`、前置`-`、Signal readの前置`*` | 右 |
| 6 | `**` | 右 |
| 5 | `*`、`/`、`%` | 左 |
| 4 | `+`、`-`、List consの`:` | `:`だけ右 |
| 3 | `==`、`!=`、`<`、`<=`、`>`、`>=` | 結合不可 |
| 2 | `&&` | 左、短絡 |
| 1 | <code>&#124;&#124;</code> | 左、短絡 |
| 0 | `??` | 右、短絡 |
| -1 | `>>=`、`<$>`、`<*>`、パイプライン | 左 |
| -2 | `$` | 右 |
| -3 | `:=` | 右 |

`a < b < c`はエラーなので、`a < b && b < c`と書きます。`&&`・`||`・`??`以外の二項演算子は、左、右の順に両方を一度ずつ計算します。

## 関数値と独自演算子

`(+)`のように二項演算子を括弧で囲むと、引数を一つずつ受け取る関数になります。`&&`・`||`・`??`、`|>`、`$`、Signalの演算子、前置の演算子は関数にできません。

自分の二項演算子は、ファイルの一番外側に`operator`で宣言して作れます。

```seseragi title="宣言構文"
operator infixl 4 <+>
  left: String
  -> right: String
  -> String =
  left + right
```

優先順位は0〜8で、結合は`infixl`（左）・`infixr`（右）・`infix`（結合しない）から選びます。標準の演算子と予約された記号は定義し直せません。自分の演算子をimportするときは、普通の値とは別に明示します。詳しくは[モジュール](/docs/reference/modules)と[型クラス](/docs/reference/type-classes)にあります。
