関数は値です。引数を一つずつ受け取り、ほかの関数に渡したり、関数の結果として返したりできます。`fn`は値を計算するだけで、外の世界とやり取りする処理は[Effect](/docs/reference/effects)として返します。

## 宣言と型

引数の名前と型を`->`でつなぎ、最後に結果の型を書きます。`fn`では、引数の型と結果の型を省略できません。

```seseragi title="宣言の構文"
fn add x: Int -> y: Int -> Int =
  x + y
```

`add`の型は`Int -> Int -> Int`、つまり`Int -> (Int -> Int)`です。引数がないように見える`fn ready -> Bool`も、実際には`Unit`の引数を一つ受け取る関数で、`ready ()`と呼びます。

公開する関数には`pub`を付けます。型パラメーターは`fn identity<A> value: A -> A`のように名前のすぐ後ろに書きます。推論と制約の決まりは[型](/docs/reference/types)と[型クラス](/docs/reference/type-classes)にあります。

## 適用と部分適用

`add 20 22`は、空白で区切った二つの引数`20`と`22`を渡す式です。引数を一部だけ渡すと、残りの引数を待つ関数になります。

適用は左から順に進むので、`add 20 22`は`(add 20) 22`と同じです。ここで括弧は`add 20`という式をまとめています。`add (20 + 1) 22`なら、括弧でまとめた計算結果の21を最初の引数として渡します。

{/* example: examples/reference/functions.ssrg */}

```seseragi title="functions.ssrg"
fn add x: Int -> y: Int -> Int =
  x + y

pub effect fn main = do {
  let increment = add 1
  41
  |> increment
  |> show
  |> println
}
```

`increment`の型は`Int -> Int`です。出力は42です。`value |> function`は`function value`と同じ意味です。標準ライブラリのコレクションの関数は、処理対象のデータを最後の引数に取るので、部分適用してそのままパイプラインに置けます。

### 括弧でまとめる範囲

次の三つは、`main`の`do`の中に置く例です。最初の二つは同じ式を括弧の付け方を変えて書いたもの、最後は引数の計算を括弧でまとめたものです。

{/* example: examples/reference/function-values.ssrg#grouping */}

```seseragi title="mainのdo内: 適用と括弧"
add 10 2
|> show
|> println
(add 10) 2
|> show
|> println
add (10 + 1) 2
|> show
|> println
```

出力は順に12、12、13です。

### 残りの引数を受け取る関数

{/* example: examples/reference/function-values.ssrg#partial */}

```seseragi title="mainのdo内: 部分適用"
let increment = add 1
[1, 2, 3]
|> map increment
|> show
|> println
```

`add 1`の型は`Int -> Int`です。Arrayへ適用した出力は`[2, 3, 4]`になります。

## 評価順とラムダ

Seseragiは、関数を呼ぶ前に引数を計算します（正格評価）。引数は左から右へ一度ずつ計算され、そのあと関数の本体が計算されます。部分適用は、残りの引数を待つ関数を作るだけです。Effectを返す関数を呼んでも、返ってきたEffectが実行されるのはまた別のタイミングです。

ラムダは`\x -> x + 1`、引数が複数なら`\x y -> x + y`と書きます。引数の型は、前後から分かる場合は省略でき、分からない場合は`\x: Int -> x + 1`のように書きます。

```seseragi title="高階関数の構文"
map (\value: Int -> value + 1) [1, 2]
```

ラムダは、外側にある変数のうち使うものを覚えます（クロージャ）。型パラメーターは実行時の値ではないので、ジェネリックな関数の中で型を調べて分岐することはできません。

### 匿名関数と演算子の関数値

ラムダを渡す場合も、名前の付いた関数を渡す場合も、求められる型は同じです。次の例は`[2, 4, 6]`を出力します。

{/* example: examples/reference/function-values.ssrg#lambda */}

```seseragi title="mainのdo内: lambda"
[1, 2, 3]
|> map (\n: Int -> n * 2)
|> show
|> println
```

演算子を括弧で囲むと関数値になり、ふつうの関数と同じように部分適用できます。`(*) 2`は「2を掛ける関数」です。この断片も`[2, 4, 6]`を出力します。

{/* example: examples/reference/function-values.ssrg#operator */}

```seseragi title="mainのdo内: operator value"
[1, 2, 3]
|> map ((*) 2)
|> show
|> println
```


## ブロックとローカル関数

ブロックは最後の式の値を返します。`let`で付けた名前は再代入できず、その行からブロックの終わりまで使えます。ブロックの中で宣言した`fn`（ローカル関数）は、自分自身の本体と、宣言より後ろの行から呼べます。ローカル関数は、宣言より前の変数は使えますが、後ろの変数は使えません。

```seseragi title="local関数の構文"
fn twice value: Int -> Int = {
  fn double x: Int -> Int = x + x
  double value
}
```

関数を宣言しただけでは、本体は実行されません。互いに呼び合うローカル関数は`rec { ... }`でまとめます。ローカル関数に`pub`は付けられません。

### ローカル関数が覚える値

{/* example: examples/reference/local-functions.ssrg#closure */}

```seseragi title="宣言: lexical capture"
fn shifted amount: Int -> value: Int
  -> Int = {
  fn shift n: Int -> Int =
    n + amount
  shift value
}
```

`shift`は外側の引数`amount`を覚えています。`shifted 3 7`は10です。

## 再帰

名前の付いた関数は、自分自身を呼べます。互いに呼び合う関数は、同じ`rec`の中に置きます。`let`の右辺から、その`let`自身は参照できません。

`fn`で定義した関数が、最後の処理として自分自身をすべての引数付きで呼ぶ場合（末尾再帰）は、何回繰り返してもスタックが増えません。互いに呼び合う再帰、呼んだ結果にさらに計算をする再帰、ラムダの中からの呼び出しは、この対象になりません。実行例は[性能](/docs/reference/performance)にあります。

## メソッドとEffect関数

`value.method arg`は、コンパイル時に`Type.method value arg`に置き換えられます。メソッドは、その型を宣言したモジュールの`impl Type`の中に書き、最初の引数は`self: Type`です。実行時にメソッドを探す仕組みや、継承はありません。

`effect fn`は、Effectを返す関数を書くための構文です。引数の受け取り方は普通の関数と同じです。本体が普通の値なら、`succeed`などでEffectに包みます。型を書く形と省く形については[Effectと失敗](/docs/reference/effects)にあります。

部分適用とパイプラインを順に学びたいときは、[関数](/docs/learn/functions)・[パイプライン](/docs/learn/pipelines)・[関数適用演算子](/docs/learn/application-operator)を見てください。
