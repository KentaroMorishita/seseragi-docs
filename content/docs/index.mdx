Seseragiは、静的な型を持つ関数型プログラミング言語です。計算は値を返す式として書き、入出力や状態の変更はEffectで表します。CLIアプリとブラウザのWebアプリを、同じ言語の型と関数で組み立てられます。

このサイトはSeseragiの公式ドキュメントです。まず動くコードから学び、アプリを作り、必要になったときに規則とAPIを調べられるように構成しています。

## 最初の一歩

[最初のプログラム](/docs/learn/first-program)では、文字列を一行表示し、内容を変えて再実行します。続いて、値と式、関数、データの型を、それぞれの小さな例で学びます。

インストールせずに試すなら[Playground](https://seseragi.vercel.app/)、手元で開発するなら[ローカルで使う](/docs/learn/local-development)へ進んでください。

## 押さえる四つの考え方

| 考え方 | コードで何を表すか | 学ぶ場所 |
| --- | --- | --- |
| 値と式 | 計算した結果を、次の式へ渡す | [値と式](/docs/learn/values-and-expressions) |
| 型とパターン | データの形と、状態ごとの扱いを決める | [代数的データ型](/docs/learn/algebraic-data-types)、[パターンマッチ](/docs/learn/pattern-matching) |
| 関数の合成 | 小さな変換を、部分適用とパイプラインでつなぐ | [関数とパイプライン](/docs/learn/functions-and-pipelines) |
| Effect | 必要な環境、失敗、成功値を型で保った処理を作る | [Effect](/docs/learn/effects) |

`if`も`match`も値を返します。出力などの処理はEffectという値で表します。`effect fn`は処理を組み立てるための宣言で、結果のEffect型へ展開されます。Effect値を作ることと、その実行で出力することを区別できます。

## TypeScriptから来た方へ

次の`add`は、整数を二つ受け取り、その和を返す関数です。

```seseragi title="二つの整数を足す関数"
fn add x: Int -> y: Int -> Int =
  x + y
```

呼び出す式は`add 2 3`です。関数名の後へ、空白で区切って`2`と`3`を渡します。結果は`5`です。TypeScriptでは、同じ呼び出しを`add(2, 3)`と書きます。

`add 2`のように一つだけ渡すと、もう一つの整数を受け取る関数になります。部分適用と、括弧で式をまとめる書き方は[関数とパイプライン](/docs/learn/functions-and-pipelines)で順に学べます。`let`は値に名前をつける定義であり、あとから代入する変数ではありません。

欠如は`Maybe`、成功と失敗は`Either`、状態ごとのデータは代数的データ型で表します。Webの状態はSignalで保持し、イベントをActionへ変換して次の状態を求めます。

[TypeScriptからSeseragiへ](/docs/guides/typescript-to-seseragi)で、関数、型、失敗、非同期処理の書き方を比較できます。Reactの経験がある方は、続いて[状態とAction](/docs/guides/state-and-actions)と[コンポーネント](/docs/guides/components)を読むと、画面を組み立てる流れが分かります。

## 対応する版

本文と実行例はSeseragi <strong><LanguageVersion /></strong>を対象にしています。CLIはRustで実装され、現在のコンパイル経路ではTypeScriptとランタイムを使ってプログラムを実行します。ブラウザのPlaygroundはRustコンパイラのWASM版を使います。

Seseragiは開発中の言語です。構文や機能が変わる場合があります。このサイトでは、現在使える機能と、まだ実装へ接続されていない契約を区別しています。
