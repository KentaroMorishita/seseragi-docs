## Declaration

```seseragi
fn add x: Int -> y: Int -> Int =
  x + y
```

Write the parameters after the function name, followed by the result type. The expression after `=` is the body.

| Part | Meaning |
| --- | --- |
| `add` | Function name |
| `x: Int` | First parameter and its type |
| `y: Int` | Next parameter and its type |
| Final `Int` | Result type |

## Application

```seseragi
pub effect fn main =
  add 20 22
  |> println
```

Pass arguments separated by spaces. `add 20 22` returns 42. The `|>` operator passes that value to `println`.

## Partial application

Supplying some arguments produces a function that accepts the remaining ones.

```seseragi
pub effect fn main = {
  let increment = add 1
  increment 41
  |> println
}
```

`increment` takes an integer and returns it plus 1. Here, `let` gives that function a name local to `main`. The output is 42.

## Effectful functions

Mark functions containing operations such as `println` with `effect`. An ordinary `fn` cannot directly print output. [Your first program](/en/docs/learn/first-program) composes a function that returns text with an operation that prints it.

## Types and arguments

An ordinary `fn` declaration specifies the type of each parameter and the result. The type of `add` is `Int -> Int -> Int`, equivalent to `Int -> (Int -> Int)`. Supplying the first integer returns a function that accepts the next one.

You cannot pass a string where an `Int` is expected, as in `add 20 "22"`. The type mismatch is detected before execution.

Arguments are evaluated once, from left to right. The body is then evaluated using those values.

## Block bodies

Use `{ ... }` when the body needs multiple declarations. A block returns the value of its final expression.

```seseragi
fn twice x: Int -> Int = {
  let doubled = x + x
  doubled
}
```

`doubled` is local to this block and cannot be referenced outside it.

See [Your first program](/en/docs/learn/first-program#compose-functions-and-print) for a pipeline in a complete program. [Local development](/en/docs/learn/local-development) explains how to run it on your machine.
