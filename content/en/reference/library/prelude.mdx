Prelude names are available without an import. Purpose-specific operations live in explicit modules.

## Use this reference

The signatures below show types in argument order, then the result. See [how to read library types](/en/docs/reference/library#read-the-types) for currying, constraints, and Effect requirements.

## Functions and operators

### `-` / Sub.sub

<small className="api-kind">Operator</small>

Dispatches through the standard trait instance selected by the operand types.

```seseragi
- via Sub.sub
```

### `:` / List cons

<small className="api-kind">Operator</small>

Persistent List cons. Precedence 4, right associative; evaluates head then tail once and shares the tail in O(1). The operator section (:) is a curried function.

```seseragi
A : List<A> -> List<A>
```

### `!=` / Eq.eq

<small className="api-kind">Operator</small>

Dispatches through the standard trait instance selected by the operand types.

```seseragi
!= via Eq.eq
```

### `??` / List cons

<small className="api-kind">Operator</small>

Maybe fallback. Precedence 0, right-associative. Evaluates the left once; evaluates the fallback only for Nothing. Syntax only: no operator section or overload.

```seseragi
Maybe<A> ?? A -> A
```
