## Import

```seseragi
import * as effect from "std/effect"
```

## Choosing operations

- Effects are cold. Construction or provide does not execute them; each execution repeats the computation. Use defer when construction must happen per execution.
- recover and attempt handle typed failures only, not defects or cancellation. Explicitly align distinct errors into an application ADT with mapError or related operations.
- do/flatMap run sequentially. Request parallelism explicitly and follow that operation’s ordering and resource-ownership contract.
- Register resources with scopes through bracket or acquireRelease. Finalizers run once in reverse order and cannot leave typed failure unhandled.
- Timeout cancels the source and waits for cleanup. retry/repeat rerun the operation; check whether duplicate external writes are acceptable.
