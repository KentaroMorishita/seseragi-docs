## Constructors and values

### `Done`

<small className="api-kind">Constructor</small>


### `Next`

<small className="api-kind">Constructor</small>

## Functions and operators

### `reduceUntil`

<small className="api-kind">Function</small>

Folds an Iterable in source order until Done; does not pull the remaining elements.

```text
reduceUntil<C, A, B>
  B
  -> (B -> A -> ReduceStep<B>)
  -> C
  -> B
where
  Iterable<C, A>
```
