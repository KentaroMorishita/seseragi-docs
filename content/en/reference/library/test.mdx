## Import

```seseragi
import * as test from "std/test"
```

## Choosing operations

- Test is an ordinary immutable tree; constructing it does not execute its body. The runner executes selected cases, discovered through pub let tests in the tests root.
- equal compares with Eq and uses Debug for failure display. Float lacks standard Eq; produce a Bool with the named comparison matching your intended policy.
- expectFailure handles typed failures only. Defects or cancellation do not become successful expected-error assertions.
- Each case has its own environment and resource scope. Provide test doubles for extra services and retain seeds/minimized property inputs for reproduction.
