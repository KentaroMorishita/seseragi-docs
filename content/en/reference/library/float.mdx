## Example

{/* example: examples/library/float.ssrg */}

```seseragi
import * as floats from "std/float"

pub effect fn main =
  match floats.parse "1.5" {
    Right value ->
      value
      |> floats.format
      |> println
    Left _ ->
      println "Invalid number"
  }
```

Output:

```text
1.5
```

## Choosing operations

- Float has no standard Eq, Ord, or Hash because NaN violates reflexivity. Choose ieeeEq for IEEE equality or totalCompare for a total order.
- parse rejects surrounding whitespace and returns a typed error when finite text overflows. Treat NaN, infinities, and negative zero as distinct cases.
- Conversion to Int requires a rounding mode and checks finiteness and safe-integer range. Integer-looking display does not make a Float an Int.
- Float has no standard JSON codec. Choose a wire-number policy using Decimal or an explicit converter.
