## Import

```seseragi
import * as validation
  from "std/validation"
```

## Choosing operations

- Use it to validate independent inputs and collect all errors. Switch to Either when a later step depends on an earlier success value.
- When both sides of Applicative apply are Invalid, left errors precede right errors. Supplying inputs left to right preserves that error order.
- Invalid contains a NonEmptyList. There is no empty-error Invalid, and toEither preserves every error rather than reducing to the first.
- Validation has Functor and Applicative, but no Monad. Do not mix fail-fast flatMap semantics into error accumulation.

## Types and type classes

### `Validation`

<small className="api-kind">Opaque type</small>

Independent validation with a Valid value or a non-empty, source-ordered collection of errors.

```text
Validation<_, _>
```

## Constructors and values

### `Invalid`

<small className="api-kind">Constructor</small>

Constructs an invalid result from a NonEmptyList, preserving error order.

```text
Invalid<E, A>
  NonEmptyList<E>
  -> Validation<E, A>
```

### `Valid`

<small className="api-kind">Constructor</small>

Constructs a successful Validation value.

```text
Valid<E, A>
  A
  -> Validation<E, A>
```

## Functions and operators

### `fromEither`

<small className="api-kind">Function</small>

Explicitly converts Left to one error and Right to Valid.

```text
fromEither<E, A>
  Either<E, A>
  -> Validation<E, A>
```

### `invalid`

<small className="api-kind">Function</small>

Constructs an invalid result containing one error.

```text
invalid<E, A>
  E
  -> Validation<E, A>
```

### `invalidMany`

<small className="api-kind">Function</small>

Constructs an invalid result from a NonEmptyList, preserving error order.

```text
invalidMany<E, A>
  NonEmptyList<E>
  -> Validation<E, A>
```

### `toEither`

<small className="api-kind">Function</small>

Explicitly converts Invalid to Left containing all errors, or Valid to Right.

```text
toEither<E, A>
  Validation<E, A>
  -> Either<NonEmptyList<E>, A>
```

### `valid`

<small className="api-kind">Function</small>

Constructs a successful Validation value.

```text
valid<E, A>
  A
  -> Validation<E, A>
```
