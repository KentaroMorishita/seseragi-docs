## Import

```seseragi
import * as http from "std/http"
```

## Choosing operations

- Non-2xx statuses still arrive as successful responses. Distinguish application-level HTTP failures from DNS, TLS, socket, and other transport failures.
- sendBytes/sendEmpty collect bodies in memory as small-response APIs. Exceeding an explicit limit cancels the response and returns a typed error.
- Headers are a case-insensitive ordered multimap. Values are not automatically comma-joined, preserving independent values such as Set-Cookie.
- Redirects, cookie jars, authentication, retries, timeouts, and Content-Encoding decoding are not automatic. Choose text/JSON body decoding explicitly too.
- exchange is a cold Stream. Each terminal execution starts a request and releases body/connection resources on cancellation or early termination.

### `ResponseHead`

<small className="api-kind">Struct</small>

```text
struct ResponseHead {
  version: HttpVersion,
  status: Status,
  headers: Headers
}
```

- `version`: HTTP protocol version of the response.
- `status`: Validated HTTP response status.
- `headers`: Immutable response headers, separate from its body.
