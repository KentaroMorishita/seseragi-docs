## Example

{/* example: examples/library/array.ssrg */}

```seseragi
import * as arrays from "std/array"

fn even n: Int -> Bool = n % 2 == 0

pub effect fn main =
  [1, 2, 3, 4]
  |> arrays.filter even
  |> show
  |> println
```

Output:

```text
[2, 4]
```

### Find the first matching element

Both 5 and 8 exceed 3. find returns only the first match, wrapped in Just.

{/* example: examples/library/array-recipes.ssrg#find-first */}

```seseragi
[2, 5, 8]
|> array.find (\n -> n > 3)
|> show
|> println
```

Output:

```text
Just 5
```

### Handle no matching element

No element in the same array exceeds 9, so the result is Nothing.

{/* example: examples/library/array-recipes.ssrg#find-none */}

```seseragi
[2, 5, 8]
|> array.find (\n -> n > 9)
|> show
|> println
```

Output:

```text
Nothing
```

### Read an out-of-range index

Indices start at zero. Index 2 does not exist in a two-element array, so get returns Nothing.

{/* example: examples/library/array-recipes.ssrg#get-outside */}

```seseragi
[10, 20]
|> array.get 2
|> show
|> println
```

Output:

```text
Nothing
```

### Take zero elements

Taking zero elements returns an empty array regardless of the source length.

{/* example: examples/library/array-recipes.ssrg#take-zero */}

```seseragi
[10, 20]
|> array.take 0
|> show
|> println
```

Output:

```text
[]
```

## Choosing operations

- Choose Array for indexed sequences. get and indexing return Nothing for negative or out-of-bounds indices.
- Results are strict, immutable Arrays. fromIterable consumes through termination, so it is unsuitable for an infinite Iterator.
- Callbacks normally run in source order. reduceRight proceeds from the end; sortBy computes each key once and uses a stable sort.
- Recursing through an entire Array with [head, ...tail] repeatedly copies rests and takes quadratic time. Use reduce or reduceUntil for large traversals.
