## Choosing operations

- Use extended grapheme clusters for display cursors and character limits, avoiding cuts based only on scalars inside combining sequences or emoji.
- Segmentation follows Unicode UAX #29 but performs no normalization. Concatenating clusters reproduces the original String byte for byte.
- at returns Nothing out of range; slice returns a typed error for invalid end-exclusive ranges. Indices are not silently clamped.
- Each operation traverses input bytes. For repeated positions, consider computing clusters or byteBoundaries once.
