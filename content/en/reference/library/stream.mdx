## Import

```seseragi
import * as stream from "std/stream"
```

## Choosing operations

- Streams are cold; each terminal execution creates its own producer and scope. Executing the same Stream twice does not share subscriptions.
- The default is pull-based. buffer suspends a full producer; dropping policies are explicit through operations such as bufferDropping.
- flatMap consumes each inner stream completely, in sequence. merge is a separate concurrent composition with its own ordering and failure-selection rules.
- Use runCollect for finite streams. An infinite stream never completes and retains collected values; limit it with take when needed. Early termination and cancellation still close upstream resources.
