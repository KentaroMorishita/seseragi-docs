## Import

```seseragi
import * as web_html
  from "std/web/html"
```

## Example

{/* example: examples/library/web-html.ssrg */}

```seseragi
import * as html from "std/web/html"

pub effect fn main =
  html.p { children: "Hello" }
  |> html.renderToString
  |> println
```

Output:

```text
<p>Hello</p>
```

## Choosing operations

- Html is a pure immutable tree, and components are ordinary functions. Construction alone creates no DOM, subscriptions, or hook state.
- Children accept String, Html, and their supported Array/List forms. Convert numbers explicitly with show/text; do not arbitrarily mix String and Html in one Array.
- Text escapes once at SSR/DOM sinks. Use validated URLs and custom attributes rather than inserting unchecked raw HTML Strings.
- SSR executes no events and emits neither event props nor keys as attributes. Browser DOM connections belong in std/web/dom.
