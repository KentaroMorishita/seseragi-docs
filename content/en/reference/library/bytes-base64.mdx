## Types and type classes

### `Base64DecodeError`

<small className="api-kind">Opaque type</small>

Describes a strict RFC 4648 Base64 decoding failure.

```text
Base64DecodeError
```

## Constructors and values

<small className="api-kind">Constructor</small>

```text

  { offset: Int }

```

<small className="api-kind">Constructor</small>

## Functions and operators

### `decode`

<small className="api-kind">Function</small>

Strictly decodes canonical padded RFC 4648 Base64 text.

```text
decode
  String
  -> Either<
       Base64DecodeError,
       Bytes
     >
```

### `decodeUrl`

<small className="api-kind">Function</small>

Strictly decodes canonical unpadded URL-safe Base64 text.

```text
decodeUrl
  String
  -> Either<
       Base64DecodeError,
       Bytes
     >
```

### `encode`

<small className="api-kind">Function</small>

```text
encode
  Bytes
  -> String
```

### `encodeUrl`

<small className="api-kind">Function</small>

Encodes Bytes as canonical unpadded URL-safe Base64 text.

```text
encodeUrl
  Bytes
  -> String
```
