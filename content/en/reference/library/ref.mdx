## Use this reference

The signatures below show types in argument order, then the result. See [how to read library types](/en/docs/reference/library#read-the-types) for currying, constraints, and Effect requirements.

## Types and type classes

### `Ref`

<small className="api-kind">Opaque type</small>

```seseragi
Ref<_>
```

## Functions and operators

### `get`

<small className="api-kind">Function returning Effect</small>

Returns an Effect that atomically reads the current Ref value when executed.

```seseragi
get<A>
  Ref<A>
  -> Effect<{}, Never, A>
```

### `make`

<small className="api-kind">Function returning Effect</small>

Returns an Effect that creates a fresh Ref with the initial value on each execution. The resulting Ref can be passed to later Effects.

```seseragi
make<A>
  A
  -> Effect<{}, Never, Ref<A>>
```

### `modify`

<small className="api-kind">Function returning Effect</small>

Returns a result and updates a Ref in one atomic callback.

```seseragi
modify<A, B>
  (A -> (B, A))
  -> Ref<A>
  -> Effect<{}, Never, B>
```

### `set`

<small className="api-kind">Function returning Effect</small>

Replaces the current Ref value atomically.

```seseragi
set<A>
  A
  -> Ref<A>
  -> Effect<{}, Never, Unit>
```

### `update`

<small className="api-kind">Function returning Effect</small>

Updates a Ref with one pure atomic callback.

```seseragi
update<A>
  (A -> A)
  -> Ref<A>
  -> Effect<{}, Never, Unit>
```
