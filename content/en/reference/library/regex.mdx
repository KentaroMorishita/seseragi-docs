## Try specific cases

Each excerpt can be tried on its own inside the `do` block of `main`, using this page's import. The output below each excerpt is verified against its complete program. For the entry point and execution steps, see [your first program](/en/docs/learn/first-program) and [Effect](/en/docs/learn/effects).

### Match a pattern

compile returns Either. On success, isMatch checks whether the string contains a sequence of digits.

{/* example: examples/library/regex-recipes.ssrg#matched */}

```seseragi
match regex.compile "[0-9]+" {
  Right pattern ->
    "item 42"
    |> regex.isMatch pattern
    |> show
    |> println
  Left _ -> println "Invalid pattern"
}
```

Output:

```text
True
```

### Handle no match

The same pattern returns false for an input with no digits. No match is distinct from failure to compile the pattern.

{/* example: examples/library/regex-recipes.ssrg#unmatched */}

```seseragi
match regex.compile "[0-9]+" {
  Right pattern ->
    "tea"
    |> regex.isMatch pattern
    |> show
    |> println
  Left _ -> println "Invalid pattern"
}
```

Output:

```text
False
```

### Handle an invalid pattern

An unclosed bracket produces Left. Matching an input string has not happened at this stage.

{/* example: examples/library/regex-recipes.ssrg#invalid-pattern */}

```seseragi
match regex.compile "[" {
  Right _ -> println "Valid pattern"
  Left _ -> println "Invalid pattern"
}
```

Output:

```text
Invalid pattern
```

## Types and type classes

### `Regex`

<small className="api-kind">Opaque type</small>

Opaque compiled portable regular expression with pinned Unicode semantics.

```seseragi
Regex
```

### `RegexCapture`

<small className="api-kind">Struct</small>

Captured source text together with its UTF-8 byte span.

```seseragi
struct RegexCapture {
  span: RegexSpan,
  text: String
}
```

- `span`: UTF-8 byte span of the capture.
- `text`: Input text corresponding to the capture span.

### `RegexCompileError`

<small className="api-kind">Struct</small>

Reports a compile failure at a UTF-8 byte offset in the pattern.

```seseragi
struct RegexCompileError {
  kind: RegexCompileErrorKind,
  offset: Int
}
```

- `kind`: Classification of the pattern compilation failure.
- `offset`: Zero-based UTF-8 byte offset in the pattern.

### `RegexCompileErrorKind`

<small className="api-kind">Opaque type</small>

Classifies a portable regular-expression compile failure.

```seseragi
RegexCompileErrorKind
```

### `RegexMatch`

<small className="api-kind">Struct</small>

A leftmost match with ordered and named captures.

```seseragi
struct RegexMatch {
  span: RegexSpan,
  text: String,
  captures: Array<
    Maybe<RegexCapture>
  >,
  named: Map<
    String,
    Maybe<RegexCapture>
  >
}
```

- `span`: UTF-8 byte span of the complete match.
- `text`: Input text of the complete match.
- `captures`: Captures in opening-parenthesis order, excluding group 0; unmatched groups are Nothing.
- `named`: Named captures in declaration order; unmatched groups retain their keys with Nothing values.

### `RegexOptions`

<small className="api-kind">Struct</small>

Controls case folding, multiline anchors, and dot-newline matching.

```seseragi
struct RegexOptions {
  caseInsensitive: Bool,
  multiline: Bool,
  dotMatchesNewline: Bool
}
```

- `caseInsensitive`: Whether to use locale-independent Unicode simple case folding.
- `multiline`: Whether ^ and $ may also match at line boundaries.
- `dotMatchesNewline`: Whether . also matches line terminators.

### `RegexSpan`

<small className="api-kind">Struct</small>

Half-open UTF-8 byte span in the searched text.

```seseragi
struct RegexSpan {
  start: Int,
  end: Int
}
```

- `start`: Inclusive, zero-based UTF-8 byte offset at the start.
- `end`: Exclusive UTF-8 byte offset at the end.

## Functions and operators

### `compile`

<small className="api-kind">Function</small>

Compiles a portable pattern or returns a typed error without throwing.

```seseragi
compile
  String
  -> Either<
       RegexCompileError,
       Regex
     >
```

### `compileWith`

<small className="api-kind">Function</small>

Compiles a portable pattern using explicit RegexOptions.

```seseragi
compileWith
  RegexOptions
  -> String
  -> Either<
       RegexCompileError,
       Regex
     >
```

### `defaultOptions`

<small className="api-kind">Function</small>

```seseragi
defaultOptions
```

### `escape`

<small className="api-kind">Function</small>

```seseragi
escape
```

<small className="api-kind">Function</small>

<small className="api-kind">Function</small>

### `isMatch`
