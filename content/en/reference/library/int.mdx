## Example

{/* example: examples/library/int.ssrg */}

```seseragi
import * as ints from "std/int"

pub effect fn main =
  match ints.parse "42" {
    Right value ->
      value
      |> ints.format
      |> println
    Left _ ->
      println "Invalid integer"
  }
```

Output:

```text
42
```

### Reject non-integer input

parse returns failure in Either, allowing a non-numeric string to be handled without pretending it is an Int.

{/* example: examples/library/int-recipes.ssrg#invalid-integer */}

```seseragi
match int.parse "tea" {
  Right n -> println (show n)
  Left _ -> println "Not an Int"
}
```

Output:

```text
Not an Int
```

### Clamp to lower and upper bounds

clamp 0 10 bounds values below zero to zero and values above ten to ten. The in-range value 4 is unchanged.

{/* example: examples/library/int-recipes.ssrg#bounded */}

```seseragi
[-3, 4, 12]
|> map (int.clamp 0 10)
|> show
|> println
```

Output:

```text
[0, 4, 10]
```

### Detect overflow in addition

Adding one to the maximum Int makes checkedAdd return Nothing rather than an out-of-range Int.

{/* example: examples/library/int-recipes.ssrg#overflow */}

```seseragi
int.maxValue ()
|> int.checkedAdd 1
|> show
|> println
```

Output:

```text
Nothing
```

### Handle division by zero

checkedDivide takes the divisor first. Dividing by zero produces Left, which this example handles by displaying a message.

{/* example: examples/library/int-recipes.ssrg#divide-zero */}

```seseragi
match int.checkedDivide 0 12 {
  Right n -> println (show n)
  Left _ -> println "Cannot divide"
}
```

Output:

```text
Cannot divide
```

## Choosing operations

- Int is a safe integer. Ordinary arithmetic overflow is a defect; use checked operations for overflow that can arise from input. Saturating operations implement a different policy by clamping to bounds.
- parse uses text-input rules, rejecting whitespace, _, and source-literal prefixes such as 0x. Make preprocessing and radix selection explicit.
- Integer division truncates toward zero; remainder has the dividend sign. Checked division/remainder report a typed zero-divisor failure and normalize negative zero to Int zero.
- Int and Float do not implicitly convert. Use BigInt beyond Int range, and check range when narrowing back.
