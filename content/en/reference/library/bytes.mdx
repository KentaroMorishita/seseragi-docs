## Import

```seseragi
import * as bytes from "std/bytes"
```

## Choosing operations

- Bytes is an immutable byte sequence. Foreign Uint8Array adapters copy in both directions rather than sharing mutable host views.
- Byte construction checks 0–255. get returns Nothing out of range; slice reports a typed invalid-range error for end-exclusive ranges instead of clamping.
- A slice may share backing storage. Use copy when retaining a small slice long-term should release the larger original storage.
- Make encoding explicit when treating Bytes as text. Strict UTF-8 decoding reports the invalid position; lossy decoding instead replaces invalid sequences.

## Types and type classes

### `Byte`

<small className="api-kind">Opaque type</small>

Opaque unsigned 8-bit value in the inclusive range 0 through 255.

```text
Byte
```

### `ByteError`

<small className="api-kind">Opaque type</small>

Describes an Int that cannot be represented as a Byte.

```text
ByteError
```

### `Bytes`

<small className="api-kind">Opaque type</small>

Immutable sequence of bytes with explicit copy boundaries.

```text
Bytes
```

### `BytesSliceError`

<small className="api-kind">Opaque type</small>

Describes an invalid half-open Bytes slice range.

```text
BytesSliceError
```
