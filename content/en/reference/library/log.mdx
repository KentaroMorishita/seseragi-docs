### `LogEvent`

<small className="api-kind">Struct</small>

```seseragi
struct LogEvent {
  level: LogLevel,
  message: String,
  fields: List<(String, LogValue)>
}
```

- `level`: Log severity level.
- `message`: Log message text.
- `fields`: Ordered additional fields as name and LogValue pairs.
