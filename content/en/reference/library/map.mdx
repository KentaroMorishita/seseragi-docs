## Import

```seseragi
import * as map from "std/map"
```

## Choosing operations

- Keys need Eq and Hash, with equal keys producing equal hashes. Good hashes give expected O(1) lookup/point updates; collisions can make them linear.
- Iteration follows insertion order. Updating a key preserves its position; removing and reinserting it moves it to the end.
- fromEntries keeps the last value for duplicate keys, but their first position. Use an explicit resolver when colliding values need combination.
- Map equality ignores insertion order. Display and serialization preserve it, so equal Maps need not produce identical bytes.
