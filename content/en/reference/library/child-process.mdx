## Types and type classes

### `CapturedProcess`

<small className="api-kind">Struct</small>

```text
struct CapturedProcess {
  status: ChildExitStatus,
  stdout: Bytes,
  stderr: Bytes
}
```

- `status`: Child process termination status.
- `stdout`: Captured standard output bytes.
- `stderr`: Captured standard error bytes.
