## Example

{/* example: examples/library/maybe.ssrg */}

```seseragi
import * as maybe from "std/maybe"

pub effect fn main =
  Just 42
  |> maybe.withDefault 0
  |> show
  |> println
```

Output:

```text
42
```

### Use a default for absence

Applying withDefault 0 to Nothing returns the Int value 0.

{/* example: examples/library/maybe-recipes.ssrg#default-missing */}

```seseragi
Nothing
|> maybe.withDefault 0
|> show
|> println
```

Output:

```text
0
```

### Keep a present value

The first argument to orElse is an alternative Maybe. The subject Just 9 is kept instead of Just 7.

{/* example: examples/library/maybe-recipes.ssrg#alternative-present */}

```seseragi
Just 9
|> maybe.orElse (Just 7)
|> show
|> println
```

Output:

```text
Just 9
```

### Choose an alternative Maybe

When the subject is Nothing, orElse selects the alternative Just 7.

{/* example: examples/library/maybe-recipes.ssrg#alternative-missing */}

```seseragi
Nothing
|> maybe.orElse (Just 7)
|> show
|> println
```

Output:

```text
Just 7
```

### Collect present values

sequence converts Array&lt;Maybe&lt;Int>> into Maybe&lt;Array&lt;Int>>. When every element is Just, it returns the collected values inside Just.

{/* example: examples/library/maybe-recipes.ssrg#sequence-present */}

```seseragi
[Just 1, Just 2]
|> maybe.sequence
|> show
|> println
```

Output:

```text
Just [1, 2]
```

### Stop collecting on absence

If any element is Nothing, the entire result is Nothing. This operation does not discard absent elements and retain the rest.

{/* example: examples/library/maybe-recipes.ssrg#sequence-missing */}

```seseragi
[Just 1, Nothing]
|> maybe.sequence
|> show
|> println
```

Output:

```text
Nothing
```

## Choosing operations

- Use Maybe when absence is normal. Use Either when a reason is needed and Effect when an operation must execute.
- `withDefault` and `orElse` evaluate arguments strictly, including the alternative expression when the subject is Just. For a lazy alternative to `withDefault` that returns the contained A, use `??`. To preserve Maybe as `orElse` does while delaying the alternative expression, branch with `match`.
- traverse does not guarantee skipping later pure callbacks after Nothing. Use reduceUntil when the traversal itself must stop early.

## Functions and operators

### `orElse`

<small className="api-kind">Function</small>

Selects the fallback Maybe for Nothing, preserving an existing Just.

```text
orElse<A>
  Maybe<A>
  -> Maybe<A>
  -> Maybe<A>
```

### `sequence`

<small className="api-kind">Function</small>

Traverses wrapped values with identity, preserving source shape and order.

```text
sequence<F<_>, A>
  F<Maybe<A>>
  -> Maybe<F<A>>
where
  Traversable<F<_>>
```

### `traverse`

<small className="api-kind">Function</small>

Uses the source Traversable and the module's Applicative without a separate traversal implementation.

```text
traverse<F<_>, A, B>
  (A -> Maybe<B>)
  -> F<A>
  -> Maybe<F<B>>
where
  Traversable<F<_>>
```

### `withDefault`

<small className="api-kind">Function</small>

Selects the fallback for Nothing, or the Just payload. Arguments are strict.

```text
withDefault<A>
  A
  -> Maybe<A>
  -> A
```
