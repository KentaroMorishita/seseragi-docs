## Import

```seseragi
import * as set from "std/set"
```

## Choosing operations

- Use Set for membership with deduplication. Elements need Eq and Hash; iteration follows first insertion order.
- Inserting an existing element preserves order; reinserting after removal moves it to the end. union keeps the left side, then appends right-only elements.
- Equal results of a transformation collapse to one element. Set has no shape-preserving Functor instance; use std/set map explicitly.
- Set equality ignores order. Membership is expected O(1) with suitable hashes, but hash collisions still have a cost.
