## Import


## Choosing operations

- Reading current values and updating sources are Effects. Pure map/combine explicitly declare dependencies rather than tracking reads inside functions.
- Setting the same value notifies by default. Request duplicate suppression explicitly with distinct, which requires Eq.
- A transaction commits updates once and publishes stable derived values. Separate reads do not guarantee one snapshot; combine signals and read the combined value once.
- subscribe emits the current value once, then invokes observers in order. Observers must have Never failure; release subscriptions on scope exit or with unsubscribe.
