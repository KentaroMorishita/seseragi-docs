## Use this reference

## Types and type classes

### `StateT`

<small className="api-kind">Struct</small>

```seseragi
struct StateT<S, M<_>, A> {
  run: S -> M<(A, S)>
}
```

- `run`: Function receiving state S and returning the result A and next state S in type constructor M.

## Functions and operators

### `get`

<small className="api-kind">Function</small>

Constructs a StateT computation that returns the current state and passes it on unchanged.

```seseragi
get<S, M<_>>
  Unit
  -> StateT<S, M<_>, S>
where
  Monad<M<_>>
```
