```seseragi
import * as big_int
  from "std/big-int"
```

## Use this reference

The signatures below show types in argument order, then the result. See [how to read library types](/en/docs/reference/library#read-the-types) for currying, constraints, and Effect requirements.

## Types and type classes

### `BigInt`

<small className="api-kind">Opaque type</small>

Opaque arbitrary-precision signed integer value.

```seseragi
BigInt
```

### `BigIntConversionError`

<small className="api-kind">Opaque type</small>

Describes a BigInt that cannot be narrowed to Int exactly.

```seseragi
BigIntConversionError
```

### `BigIntDivisionError`

<small className="api-kind">Opaque type</small>

Describes checked BigInt division or remainder by zero.

```seseragi
BigIntDivisionError
```

### `BigIntParseError`

<small className="api-kind">Opaque type</small>

Describes an invalid BigInt text or radix without a magnitude limit.

```seseragi
BigIntParseError
```

### `BigIntPowerError`

<small className="api-kind">Opaque type</small>

Describes a checked negative BigInt exponent.

```seseragi
BigIntPowerError
```

## Functions and operators

### `abs`

<small className="api-kind">Function</small>

Returns the exact non-negative magnitude of a BigInt.

```seseragi
abs
  BigInt
  -> BigInt
```

### `checkedDivide`

<small className="api-kind">Function</small>

Divides the second argument by the first, returning a BigInt quotient truncated toward zero or BigIntDivisionByZero for a zero divisor.

```seseragi
checkedDivide
  BigInt
  -> BigInt
  -> Either<
       BigIntDivisionError,
       BigInt
     >
```

### `checkedPower`

<small className="api-kind">Function</small>

Raises a BigInt by a non-negative Int using exact exponentiation.

```seseragi
checkedPower
  Int
  -> BigInt
  -> Either<
       BigIntPowerError,
       BigInt
     >
```

### `checkedRemainder`

<small className="api-kind">Function</small>

Computes truncating BigInt remainder or returns a typed zero-divisor failure.

```seseragi
checkedRemainder
  BigInt
  -> BigInt
  -> Either<
       BigIntDivisionError,
       BigInt
     >
```

### `format`

<small className="api-kind">Function</small>

format

### `formatRadix`

### `fromInt`

<small className="api-kind">Function</small>

### `sign`

<small className="api-kind">Function</small>
