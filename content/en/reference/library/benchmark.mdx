
## Choosing operations

- Benchmark is an ordinary tree containing a measured body. Reconstruct measured work per execution rather than timing retrieval of a result computed beforehand.
- blackBox returns the same value as an optimization barrier against constant elimination. It does not change allocations or execution ordering.
- inputSize attaches a positive problem size to reports. Match warmups, samples, host/toolchain versions, and profiles when comparing baselines.
- Typed failures, defects, and resource leaks are case failures, not measurements. Provide extra services and avoid shared mutable measurement state outside the tree.
