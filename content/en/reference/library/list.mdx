## Example

{/* example: examples/library/list.ssrg */}

```seseragi
import * as lists from "std/list"

pub effect fn main =
  `[10, 20, 30]
  |> lists.toArray
  |> show
  |> println
```

Output:

```text
[10, 20, 30]
```

## Choosing operations

- Choose List when building by prepending. Cons and tail take O(1) and may share an existing tail.
- length, get, last, and init require linear traversal. Consider Array for repeated indexed access.
- append suffix values places suffix after values and takes work proportional to values. Repeated appends accumulate that cost.
- Conversion to Array copies elements in order. List results are strict too; List is not a lazy infinite sequence.
