## Import

```seseragi
import * as text from "std/text"
```

## Choosing operations

- Indices count Unicode scalars. Distinguish them from UTF-8 byte lengths and grapheme APIs for displayed characters.
- split and replace use literal Strings; replacement markers such as $ are not expanded. Use std/regex explicitly for regular expressions.
- Scalar slices validate an end-exclusive range rather than clamping invalid indices. Do not assume O(1) random access for scalarAt and related traversals.
- Casing and trimming use shared Unicode rules, not locale-specific transformations. trim does not remove U+FEFF.
