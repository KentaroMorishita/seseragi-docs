## Import

```seseragi
import * as fs from "std/fs"
```

## Choosing operations

- Path parsing/normalization is lexical. It does not resolve symlinks or authorize sandbox access; keep filesystem permission decisions separate.
- exists maps absence such as NotFound to False, but not permission or I/O failures. Handle typed failures separately.
- readBytes/readTextUtf8 retain complete contents as small-file APIs. Use readChunks for large files, and account for strict UTF-8 validation when reading text.
- Chunk and directory streams own resources in terminal scopes. Early termination, failure, and cancellation close handles; avoid extending lifetimes by retaining iterators outside their intended scope.

## Types and type classes

### `DirectoryEntry`

<small className="api-kind">Struct</small>

```seseragi
struct DirectoryEntry {
  name: String,
  path: Path,
  fileType: Maybe<FileType>
}
```

- `name`: Entry name within the directory.
- `path`: Path of the directory entry.
- `fileType`: Entry type, or Nothing when not supplied.

### `FileMetadata`

<small className="api-kind">Struct</small>

```seseragi
struct FileMetadata {
  fileType: FileType,
  sizeBytes: Int,
  modified: Maybe<Instant>,
  created: Maybe<Instant>
}
```

- `fileType`: File type reported for the path.
- `sizeBytes`: Reported size in bytes.
- `modified`: Modification time, or Nothing when unavailable.
- `created`: Creation time, or Nothing when unavailable.

### `FileSystemError`

<small className="api-kind">Struct</small>

```seseragi
struct FileSystemError {
  operation: FileSystemOperation,
  path: Path,
  otherPath: Maybe<Path>,
  kind: FileSystemErrorKind
}
```

- `operation`: Filesystem operation that failed.
- `path`: Primary path associated with the failure.
- `otherPath`: Additional path for a two-path operation, or Nothing when absent.
- `kind`: Filesystem failure classification.
