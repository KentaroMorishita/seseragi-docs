## About this reference

The examples on these pages have been run with the distributed CLI. Note that the compiler version and the language version written in `package.language` in `seseragi.toml` are different things. `package.language` holds the range of language versions the compiler you use accepts.

The language specification also describes features that are not implemented yet. This reference marks what you can use today and what you cannot yet, wherever it matters. For optimizations, too, it separates what could be optimized in principle from what the current compiler always does.
