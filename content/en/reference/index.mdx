## Verification scope

The runnable examples on these pages were checked with the distributed CLI. The compiler distribution version and the language version selected by `package.language` are separate. A manifest specifies a language range accepted by the compiler in use.

A future contract in the language specification is not presented as an available command or API. Any unimplemented feature discussed here is identified where it appears. Optimization guidance also separates structures that may be erased from optimizations the current backend actually guarantees.
