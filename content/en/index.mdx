---
title: What is Seseragi?
description: A programming language for expressing the shape of data and the flow of computation.
---

In Seseragi, you transform values with functions and describe data with types. You write calculations separately from operations that produce output or update state.

## Run something small

In [Your first program](/en/docs/learn/first-program), you model delivery states and turn them into text. Follow the code to see how types, pattern matching, and function composition fit together.

To try it in your browser, open the [Playground](https://seseragi.vercel.app/). You can edit and run code without installing the CLI. The [Tour](https://seseragi.vercel.app/tour/) takes you from Hello world to Web UI.

## Coming from TypeScript

Seseragi passes arguments using spaces: `label (Sent "Kyoto")`. You can also pass only some arguments to a function and get a new function that accepts the rest.

In TypeScript, calculations and output use the same function syntax. In Seseragi, ordinary `fn` declarations express calculations, while `effect fn` declarations can perform operations such as printing. Compare both versions in the [first program](/en/docs/learn/first-program#compose-functions-and-print).

## Work locally

Download the CLI and LSP from [GitHub Releases](https://github.com/KentaroMorishita/seseragi/releases). Bun is also required to run generated programs. For Web apps, follow [Getting Started](https://github.com/KentaroMorishita/seseragi/blob/main/docs/GETTING_STARTED.md) in the language repository.

## Check the implementation and specification

Seseragi is experimental. See the [implementation status](https://github.com/KentaroMorishita/seseragi/blob/main/docs/STATUS.md) for available features, and the [language specification](https://github.com/KentaroMorishita/seseragi/tree/main/docs/spec) for detailed rules.

This initial site includes a getting-started lesson and a function reference.
