title: Your first program

---

Start by running a program that displays `Hello, Seseragi!`. Once it works, change the text and run it again.

## Display one line

{/* example: examples/hello.ssrg */}

```seseragi title="hello.ssrg"
pub effect fn main =
  println "Hello, Seseragi!"
```

`main` is the program's entry point. `pub` exposes that entry point, and `effect fn` declares the computation that performs output.

`println` prints one line of text. Pass `"Hello, Seseragi!"` after the function name, separated by a space. The double quotes mark the beginning and end of the string.

## Run it in the browser

Open the [Playground](https://seseragi.vercel.app/), paste the code above, and run it. No installation is required.

The program displays one line:

```text title="Output"
Hello, Seseragi!
```

## Run it locally

To use the CLI, save the code as `hello.ssrg`. If you have not installed the CLI, follow [Local development](/en/docs/learn/local-development) first.

From the directory containing the file, run:

```sh
seseragi run hello.ssrg
```

It displays the same `Hello, Seseragi!`.

## Change the text

Replace `"Hello, Seseragi!"` with `"Hello, Kyoto!"` and run the program again. The output changes to `Hello, Kyoto!`.

You can use your own name or message too. Keep the double quotes at both ends.
