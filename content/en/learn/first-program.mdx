Display “Preparing” when a parcel is being packed, or its destination city once it has been sent. Let's define those states and a function that returns the display text.

## Define the states

Define two cases of a type called `Parcel`.

```seseragi
type Parcel =
  | Packing
  | Sent String
```

`Packing` represents a parcel being prepared. `Sent` represents a sent parcel and carries its destination city as a `String`. A type made up of cases like these is called an algebraic data type.

`Sent "Kyoto"` creates a value whose destination is Kyoto. Both `Packing` and `Sent "Kyoto"` are values of type `Parcel`.

## Turn a state into text

`label` takes a `Parcel` and returns a `String` for display.

```seseragi
fn label parcel: Parcel -> String =
  match parcel {
    Packing -> "Preparing"
    Sent city -> `Sent to ${city}`
  }
```

Write the function name and parameter after `fn`. `parcel: Parcel` names the parameter and its type; the final `String` is the result type. The expression after `=` is the body.

`match` checks which case the value belongs to. For `Packing`, it returns `"Preparing"`. For `Sent city`, it extracts the destination into `city`.

Inside a backtick-delimited string, `${city}` inserts that value. Passing `Sent "Kyoto"` returns `"Sent to Kyoto"`.

## Compose functions and print

Apply a function by writing its name followed by space-separated arguments. For example, `label (Sent "Kyoto")` passes a sent parcel to `label`.

The `|>` operator passes the value on its left to the function on its right.

```seseragi
pub effect fn main =
  Sent "Kyoto"
  |> label
  |> println
```

First, pass `Sent "Kyoto"` to `label`. Then pass the resulting string to `println`.

`main` is the program's entry point. Declare it with `pub effect fn` because it produces output. `label` is an ordinary function that returns text; `println` performs the output.

## The complete program

```seseragi title="parcel.ssrg"
type Parcel =
  | Packing
  | Sent String

fn label parcel: Parcel -> String =
  match parcel {
    Packing -> "Preparing"
    Sent city -> `Sent to ${city}`
  }

pub effect fn main =
  Sent "Kyoto"
  |> label
  |> println
```

Running it prints one line:

```text title="Output"
Sent to Kyoto
```

Paste the complete program into the [Playground](https://seseragi.vercel.app/) and run it. With the CLI installed, save it as `parcel.ssrg` and run:

```sh
seseragi run parcel.ssrg
```

## Change the state

Replace `Sent "Kyoto"` in `main` with `Packing`. The output becomes `Preparing`. Change the city to `"Sapporo"` and it becomes `Sent to Sapporo`.

Next, add a new case, `Arrived`, to `Parcel`. Compilation fails because `label` has no branch handling that case. Handling every case lets the compiler check for missing branches before execution.

## The TypeScript equivalent

In TypeScript, represent the same states with a discriminated union and a `switch`.

```ts
type Parcel =
  | { kind: "packing" }
  | { kind: "sent"; city: string };

function label(parcel: Parcel) {
  switch (parcel.kind) {
    case "packing":
      return "Preparing";
    case "sent": {
      const { city } = parcel;
      return `Sent to ${city}`;
    }
  }
}

console.log(label({
  kind: "sent",
  city: "Kyoto",
}));
```

Seseragi declares the cases `Packing` and `Sent` directly in the type. The `Sent city` pattern selects the case and extracts the destination together.
