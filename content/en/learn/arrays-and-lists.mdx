This chapter covers Array and List, which hold many values together. It starts with `map`, which transforms elements, and `filter`, which selects them, then moves on to indexing, reduction, and Lists, and finally combines them.

The code in this chapter uses [Functions](/en/docs/learn/functions) for lambdas, [Pipelines](/en/docs/learn/pipelines) for `|>` and `show`, and [Pattern matching](/en/docs/learn/pattern-matching) for `match`.

## Change elements with map

`[1, 2, 3]` is an array of type `Array<Int>`. `map` creates a new Array by applying a function to each element, just like TypeScript's `array.map(...)`.

{/* example: examples/learn/focused/array-map.ssrg#map */}
```seseragi title="Expression in main"
[1, 2, 3]
|> map (\n -> n * 2)
|> show
|> println
```

```text title="Output"
[2, 4, 6]
```

The lambda that doubles an integer is applied to each of the three elements. The original Array does not change. `map` is available without an import; [Type classes](/en/docs/learn/type-classes) explains how it also works with types other than Array.

## Select elements with filter

`filter` keeps the elements for which the condition function returns `True`. It lives in the `std/array` module, so import it at the top of the file ([Modules](/en/docs/learn/modules) covers imports):

{/* example: examples/learn/focused/array-filter.ssrg#import */}
```seseragi title="Import declaration"
import * as arrays from "std/array"
```

{/* example: examples/learn/focused/array-filter.ssrg#keep */}
```seseragi title="Binding in main"
let kept =
  [1, 2, 3, 4]
  |> arrays.filter (\n -> n % 2 == 0)
```

`kept` is `[2, 4]`. If there are no even numbers, the result is an empty Array:

{/* example: examples/learn/focused/array-filter.ssrg#empty */}
```seseragi title="Binding in main"
let removed =
  [1, 3, 5]
  |> arrays.filter (\n -> n % 2 == 0)
```

`removed` is `[]`. An empty result is not an error, just the ordinary result "nothing was left".

## Reading by index returns Maybe

In TypeScript, reading out of range, as in `array[99]`, returns `undefined`, and the type does not show it. In Seseragi, reading by index has type `Maybe<Int>`. `[10][0]` is `Just 10`; an out-of-range index such as `[10][99]`, or a negative one, gives `Nothing`. Because "there may be no value" is part of the type, you cannot overlook it.

`??` uses the value if there is one, and a fallback otherwise:

{/* example: examples/learn/focused/array-missing-index.ssrg#index */}
```seseragi title="Bindings in main"
let empty: Array<Int> = []
let first = [10][0] ?? 99
let missing = empty[0] ?? 99
```

`first` is 10 and `missing` is 99. An empty Array has no element at index 0, so the fallback 99 is used.

Also note that elements of different types cannot be mixed, as in `[1, "two"]`. An empty Array has an element type too, so when the surrounding code does not make it clear, write `let empty: Array<Int> = []`.

### An initial value and a reduction

`reduce` starts from an initial value and uses each element in turn to build a single result. Here, it appends integers to the end of a string:

{/* example: examples/learn/focused/array-reduce.ssrg#declaration */}
```seseragi title="Function declaration"
fn appendDigit text: String
  -> n: Int -> String =
  `${text}${n}`
```

{/* example: examples/learn/focused/array-reduce.ssrg#fold */}
```seseragi title="Expression in main"
[1, 2, 3]
|> reduce "" appendDigit
|> println
```

This prints `123`. The arguments of `reduce` are the initial value, the function, and the input, in that order. Starting from `""`, it goes `"1"`, `"12"`, `"123"`. As this example shows, the result type (`String`) can differ from the element type (`Int`). For an empty input, the initial value is the result.

## List

Seseragi also has List, separate from Array. An Array is written `[1, 2, 3]`; a List starts with a backtick: `` `[1, 2, 3] ``. Neither can be changed in place. Arrays are good at reading by index; Lists are good at adding to the front and splitting into the first element and the rest. Array and List are different types and are not converted automatically.

First, a function that checks whether a List is empty and looks at its first element:

{/* example: examples/learn/focused/list-empty-and-head.ssrg#declaration */}
```seseragi title="Function declaration"
fn caption values: List<Int>
  -> String =
  match values {
    `[] -> "empty"
    `[head, ..._] -> `first: ${head}`
  }
```

{/* example: examples/learn/focused/list-empty-and-head.ssrg#inputs */}
```seseragi title="Bindings in main"
let empty = caption `[]
let full = caption (1 : `[2, 3])
```

`empty` is `"empty"` and `full` is `"first: 1"`. `` 1 : `[2, 3] `` adds 1 to the front of the List, making `` `[1, 2, 3] ``. The pattern `` `[head, ..._] `` takes the first element as `head`; the rest is not used, so it is `_`.

Next, split a List into "empty" or "first element and the rest" to compute a total:

{/* example: examples/learn/list-patterns.ssrg */}
```seseragi title="list-patterns.ssrg"
fn total values: List<Int> -> Int =
  match values {
    `[] -> 0
    `[head, ...tail] ->
      head + total tail
  }

pub effect fn main =
  1 : `[2, 3]
  |> total
  |> show
  |> println
```

```text title="Output"
6
```

In `` `[head, ...tail] ``, `tail` is the `List<Int>` of the remaining elements. `total` computes the whole sum by adding the first element to the sum of the rest.

Arrays also accept `[head, ...tail]`, and then `tail` is an Array. Lists have no syntax for reading by index.

### Convert between Array and List

Use `toList` from `std/array` and `toArray` from `std/list`:

{/* example: examples/learn/focused/list-array-conversion.ssrg#imports */}
```seseragi title="Import declarations"
import * as arrays from "std/array"
import * as lists from "std/list"
```

{/* example: examples/learn/focused/list-array-conversion.ssrg#conversion */}
```seseragi title="Expression in main"
[1, 2]
|> arrays.toList
|> lists.toArray
|> show
|> println
```

This prints `[1, 2]`. Converting from Array to List and back keeps the elements and their order. Each conversion makes a copy, so pick the one that fits your use from the start rather than converting back and forth.

## Ranges and comprehensions

A range such as `1..=3` is a value that represents a span of integers. It is not an Array, but a comprehension can take values from it to build one.

{/* example: examples/learn/focused/array-ranges.ssrg#inclusive */}
```seseragi title="Binding in main"
let inclusive = [n | n <- 1..=3]
```

{/* example: examples/learn/focused/array-ranges.ssrg#exclusive */}
```seseragi title="Binding in main"
let exclusive = [n | n <- 1..3]
```

`inclusive` is `[1, 2, 3]`; `exclusive` is `[1, 2]`. `..=` includes the end value and `..` does not.

A comprehension can also transform values and keep only some of them:

{/* example: examples/learn/focused/array-ranges.ssrg#comprehension */}
```seseragi title="Binding in main"
let squares =
  [n * n | n <- 1..=5, n % 2 == 0]
```

`squares` is `[4, 16]`. On the right of `|`, `n <- 1..=5` takes 1 through 5 in turn and `n % 2 == 0` keeps only the even ones. The values that remain are transformed by `n * n` on the left of `|`.

## Which one to use

Splitting a List into the first element and the rest does not copy the rest; it reuses part of the original List. Splitting an Array with `[head, ...tail]` copies the remaining Array every time, which gets slow for many elements. To process a whole Array, use `map`, `filter`, `reduce`, and similar functions.

`total` in the List example still has an addition to do after calling itself (it is not tail recursive), so a very long List can run out of stack. For a long List, use the standard `sum`. [Recursion](/en/docs/learn/recursion) explains how to write recursion safely.

## Combine the operations you learned

{/* example: examples/learn/arrays-and-lists.ssrg */}
```seseragi title="arrays-and-lists.ssrg"
import * as arrays from "std/array"

fn square n: Int -> Int =
  n * n

fn even n: Int -> Bool =
  n % 2 == 0

pub effect fn main = do {
  let numbers = [1, 2, 3, 4, 5]
  let total =
    numbers
    |> map square
    |> arrays.filter even
    |> sum
  let first = numbers[0] ?? 0
  println `total: ${total}`
  println `first: ${first}`
}
```

```text title="Output"
total: 20
first: 1
```

`map square` gives `[1, 4, 9, 16, 25]`, `arrays.filter even` gives `[4, 16]`, and `sum` gives 20. No step changes the original `numbers`.

`map` and `sum` work without an import; `filter` is used by importing `std/array` as `arrays`. The `do` in `main` runs the two `println` calls in order; the [Effects](/en/docs/learn/effects) chapter explains `do` in detail.

## Change the filter

In the last example, change `even` to `n % 2 != 0`: the total becomes 35. Change `numbers[0]` to `numbers[99]`: the fallback 0 is printed. The next chapter, [Maybe and Either](/en/docs/learn/maybe-and-either), shows how to handle a missing value as its own case instead of filling it with a fallback.

The [standard library](/en/docs/reference/library) lists the functions, and [Data types](/en/docs/reference/data-types) has the detailed rules for types and indexing.
