This chapter starts with a function that adds two integers. Then you learn partial application, which passes only some of a function's arguments, and lambdas, which create functions without a name. The next two chapters cover `|>`, which chains functions, and `$`, which removes parentheses.

## Declare and apply a function

A function declaration has the form `fn name parameter: Type -> ResultType = body`. With two parameters, list them separated by `->`:

```seseragi
fn add x: Int -> y: Int -> Int =
  x + y
```

Supply 20 and 22 to `add` as follows:

```seseragi title="Application expression"
add 20 22
```

The arguments follow the function name, separated by spaces. This is TypeScript's `add(20, 22)`, and it returns 42.

Put the declaration and the call together in a program you can run:

{/* example: examples/learn/function-application.ssrg */}
```seseragi title="function-application.ssrg"
fn add x: Int -> y: Int -> Int =
  x + y

pub effect fn main = {
  let answer = add 20 22
  println `answer: ${answer}`
}
```

```text title="Output"
answer: 42
```

`add` is an ordinary function that only returns a result. `main` names that result `answer` and displays it with a string template from the previous chapter.

### Call a declaration without named parameters

To call a function without parameters, pass the `Unit` value `()`. Here is a function without parameters:

{/* example: examples/learn/focused/function-unit.ssrg#declaration */}
```seseragi title="Function declaration"
fn ready -> String = "ready"
```

Call it inside `main` and display the result:

{/* example: examples/learn/focused/function-unit.ssrg#use */}
```seseragi title="Expression in main"
ready ()
|> println
```

This prints `ready`. The `()` in `ready ()` is not TypeScript's empty argument list: it passes one value, `()`, as the argument. Writing `ready` alone refers to the function itself without calling it.

## Supply some arguments

`add` has type `Int -> Int -> Int`. Read it as `Int -> (Int -> Int)`: a function that takes an integer and returns "a function that takes an integer and returns an integer". So `add 1` is a function waiting for one more integer.

`let increment = add 1` is "the function that adds 1". Calling `increment 20` gives 21, the same as `add 1 20`. Creating a new function by passing only some arguments is called partial application.

## Group an expression used as an argument

To pass a calculation as an argument, wrap it in parentheses. This example uses `add` from above:

{/* example: examples/learn/focused/function-grouping.ssrg#arithmetic */}
```seseragi title="Binding in main"
let grouped = add (20 + 1) 22
```

`20 + 1` becomes the first argument, so `add` receives 21 and 22, and `grouped` is 43. These parentheses only group an expression; they are not call parentheses like `add(20, 22)`.

Wrap a function's result in parentheses the same way to pass it to another function. Assume `fn double n: Int -> Int = n * 2` is also declared:

{/* example: examples/learn/focused/function-grouping.ssrg#nested */}
```seseragi title="Binding in main"
let nested = double (add 20 1)
```

The result of `add 20 1`, 21, goes to `double`, so `nested` is 42. When parentheses start to nest, rewrite them with `|>` from [Pipelines](/en/docs/learn/pipelines) or `$` from [The application operator](/en/docs/learn/application-operator).

## Create a function without a declaration

A lambda creates a function on the spot, without an `fn` declaration. It corresponds to TypeScript's arrow function `(n) => n * 2`.

{/* example: examples/learn/focused/function-lambda.ssrg#lambda */}
```seseragi title="Binding in main"
let double = \n: Int -> n * 2
```

Call it just like any other function:

{/* example: examples/learn/focused/function-lambda.ssrg#call */}
```seseragi title="Expression in main"
double 21
|> show
|> println
```

This prints 42. When the parameter type is clear from the surrounding code, you can omit it: `\n -> n * 2`. A lambda with two parameters is `\x y -> x + y`. [Arrays and lists](/en/docs/learn/arrays-and-lists) passes lambdas to `map` and `filter`.

### Return a function that uses an outer value

A function can also return another function. `prefixWith` takes a prefix and returns "a function that puts that prefix before a name":

{/* example: examples/learn/focused/function-closure.ssrg#declaration */}
```seseragi title="Function declaration"
fn prefixWith prefix: String
  -> (String -> String) =
  \name -> `${prefix}${name}`
```

Use it like this:

{/* example: examples/learn/focused/function-closure.ssrg#use */}
```seseragi title="Expression in main"
let welcome = prefixWith "Hi, "
welcome "Aki"
|> println
```

This prints `Hi, Aki`. The returned lambda remembers `prefix` even after `prefixWith` has returned. A function that remembers outer values like this is called a closure. There is no way to change the remembered value. Passing `"Hello, "` creates another function that remembers a different prefix.

## Understand what application evaluates

Function arguments are evaluated once each, from left to right. Calling a function never changes a value bound with `let` outside it.

`add` and `double` in this chapter only return values. `println`, by contrast, returns "printing" as a computation, so `main`, which uses it, is an `effect fn`. The [Effects](/en/docs/learn/effects) chapter explains this difference in detail.
