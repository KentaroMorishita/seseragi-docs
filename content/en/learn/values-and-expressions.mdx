[Your first program](/en/docs/learn/first-program) displayed one string. This chapter tries three things, one at a time: naming a value, choosing a value with a condition, and inserting a value into a string.

## Values have types

`82` is an `Int`, `True` is a `Bool`, and `"pass"` is a `String`. The number `82.0` is a `Float`, a different type from `Int`. Addition does not implicitly convert between `Int` and `Float`.

A value's type decides what you can do with it. Integer addition `20 + 22` gives 42, and the comparison `82 >= 80` gives `True`. A comparison returns a `Bool`, not an integer.

## Name a value with let

`let message = "Hello, Seseragi"` gives a string the name `message`; this is called a binding. Wrap the body of `main` in `{ ... }` to write a binding and the output in order.

{/* example: examples/learn/values-and-expressions.ssrg */}
```seseragi title="values-and-expressions.ssrg"
pub effect fn main = {
  let message = "Hello, Seseragi"
  println message
}
```

```text title="Output"
Hello, Seseragi
```

`println message` passes the string that `message` refers to. The right-hand side tells the compiler that `message` is a `String`, so you do not need to write the type. To write it anyway:

```seseragi
let message: String = "Hello"
```

A name bound with `let` cannot be reassigned. It is available only inside the block that binds it. Binding the same name again in an inner block makes the new value visible there (shadowing); it does not change the outer value.

## Select a value with if

The next example chooses `"pass"` when 82 is at least 80 and `"retry"` otherwise, and names the result `verdict`.

{/* example: examples/learn/conditional-expressions.ssrg */}
```seseragi title="conditional-expressions.ssrg"
pub effect fn main = {
  let verdict =
    if 82 >= 80 then
      "pass"
    else
      "retry"
  println verdict
}
```

```text title="Output"
pass
```

In Seseragi, `if ... then ... else ...` is an expression that returns a value, much like TypeScript's `? :` operator. Both branches here are `String`, so the whole `if` is a `String`. The `else` branch cannot be omitted, and both branches must have the same type.

The condition must be a `Bool`. Zero and the empty string are never treated as false. Only the selected branch runs.

## Insert a value into a string

Double quotes create an ordinary string. Backticks create a string template that can contain values.

{/* example: examples/learn/string-templates.ssrg */}
```seseragi title="string-templates.ssrg"
pub effect fn main = {
  let name = "Aki"
  println `Hello, ${name}`
}
```

```text title="Output"
Hello, Aki
```

The value of `name` appears where `${name}` is written. You can insert integers and other non-string values too. [Type classes](/en/docs/learn/type-classes) explains how each value becomes text.

## A block returns its last expression

Inside a block `{ ... }`, you can name intermediate values and then return one result. Here, the block on the right returns `"Hello, Aki"`, which is bound to `message`:

```seseragi
let message = {
  let name = "Aki"
  `Hello, ${name}`
}
```

The last expression of a block is its result, so there is no `return`. `name` exists only inside this block; from outside, only `message` is visible.

## Look up other forms of values

`Int` holds exact integers from −9007199254740991 to 9007199254740991. A calculation that leaves this range stops the program instead of wrapping around or rounding. Types for larger integers and decimals are in the [standard library](/en/docs/reference/library).

`'a'` is a `Char`, a single character, while `"a"` is a `String`; they are different types. `()` is the value of type `Unit`, meaning "no meaningful value", and it is not the same as the empty record `{}`. The [types reference](/en/docs/reference/types) lists every type and how to write it.

## Change one part at a time

In the first example, change the string in `message` to anything you like. In the conditional example, 79 prints `retry` and 80 prints `pass`. Then change only the `else` result to the integer 0: the two branches no longer have the same type, so you get an error before the program runs.

In the template example, changing `name` to `"Haru"` prints `Hello, Haru`. Change one thing at a time so you can see what affected the result.
