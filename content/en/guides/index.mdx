title: Practical guides

Start with whichever guide fits what you want to build. Every guide includes the files to save, the commands to run, and the output you should see. If you have not installed the CLI and Bun yet, read [Local development](/en/docs/learn/local-development) first.

## Start from TypeScript

[From TypeScript to Seseragi](/en/docs/guides/typescript-to-seseragi) compares function calls, types, failures, and side effects side by side with TypeScript. If you know React, also check there where state lives and what functions returning HTML do; it makes the Web guides easier to follow.

## Run a command-line application

[Build a CLI application](/en/docs/guides/cli-app) reads a quantity from standard input, validates it, and prints an amount. [Handle failures](/en/docs/guides/error-handling) represents input failures as a type and turns them into messages for the user.

## Build a browser interface

[Build a Web application](/en/docs/guides/web-app) creates a counter and runs it on the development server. [State and Actions](/en/docs/guides/state-and-actions) organizes how state is updated, and [Forms](/en/docs/guides/forms) connects input and validation results to the screen.

## Divide a larger interface

[Components](/en/docs/guides/components) splits a screen into parts with functions that only return HTML. [Stateful features](/en/docs/guides/stateful-features) gives each feature its own state and hands only its view to the parent.

## Verify and distribute changes

[Testing](/en/docs/guides/testing) automates checks of boundary values. [Packages and deployment](/en/docs/guides/packages-and-deployment) separates the functions you publish from the application entry point. [TypeScript bindings](/en/docs/guides/typescript-bindings) lets Seseragi call TypeScript functions with proper types.

To learn the language step by step, see [Learn](/en/docs/learn/first-program); to look up detailed rules for types and APIs, see the [Reference](/en/docs/reference).
