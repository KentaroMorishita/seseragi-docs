Choose a guide for the task you want to complete. Each includes file paths, commands, and an observable result. Start with [Local development](/en/docs/learn/local-development) if you need the CLI and Bun.

## Start from TypeScript

[From TypeScript to Seseragi](/en/docs/guides/typescript-to-seseragi) connects functions, types, failures, and effects to concepts you already know. If you use React, first establish where state lives and what a function returning HTML does.

## Run a command-line application

[Build a CLI application](/en/docs/guides/cli-app) reads standard input, validates a quantity, and prints an amount. [Handle failures](/en/docs/guides/error-handling) represents input failures with a type and translates them into messages.

## Build a browser interface

[Build a Web application](/en/docs/guides/web-app) creates a counter you can operate through the development server. [State and Actions](/en/docs/guides/state-and-actions) organizes its update function. [Forms](/en/docs/guides/forms) connects entered text and validation results to the interface.

## Divide a larger interface

[Components](/en/docs/guides/components) covers pure functions returning HTML. [Stateful features](/en/docs/guides/stateful-features) creates a Signal for each feature and returns a read-only view to its parent. These guides distinguish rendering a view from creating its state.

## Verify and distribute changes

[Testing](/en/docs/guides/testing) automates boundary checks. [Packages and deployment](/en/docs/guides/packages-and-deployment) separates public functions from the application entry point. [TypeScript bindings](/en/docs/guides/typescript-bindings) wraps host functions with explicit calling contracts.

Use [Learn](/en/docs/learn/first-program) for a guided introduction to syntax and [Reference](/en/docs/reference) for exact type and API contracts.
