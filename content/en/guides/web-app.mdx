title: Build a Web application
description: Store a number in a Signal and update it with buttons.

Build a counter that goes up with “Add one” and back to 0 with “Reset”. Store the number in a [Signal](/en/docs/learn/signals), then connect the screen so it follows changes to the number.

Each button carries a `Task<Unit>` to run when clicked. This is an alias for `Effect<{}, Never, Unit>`: a computation that needs no services, cannot fail, and returns `Unit`. [Effects](/en/docs/learn/effects) explains building and executing computations; [Functions](/en/docs/learn/functions) explains lambdas and partial application.

## Create a project

```sh
seseragi new web counter
cd counter
```

Replace `src/main.ssrg` with the code below. The generated `src/app.ssrg` is not used in this guide.

Keep `seseragi.toml` as generated. See [Local development](/en/docs/learn/local-development) to prepare the CLI and Bun.

## Write the complete counter

{/* example: examples/guides/web-app/src/main.ssrg */}
```seseragi title="src/main.ssrg"
import * as dom from "std/web/dom"
import * as html from "std/web/html"
import * as signals from "std/signal"
import { MutableSignal }
  from "std/signal"

alias Counter = MutableSignal<Int>
alias View = html.Html<Task<Unit>>

fn view count: Counter
  -> current: Int -> View =
  html.main {
    style: html.style {
      margin: "32px auto",
      maxWidth: "32rem",
      padding: "24px"
    },
    children: [
      html.h1 { children: "Counter" },
      html.p {
        children: `Count: ${current}`
      },
      html.button {
        buttonType: "button",
        onClick: signals.update
          (\n: Int -> n + 1) count,
        children: "Add one"
      },
      html.button {
        buttonType: "button",
        onClick: signals.set 0 count,
        children: "Reset"
      }
    ]
  }

fn perform action: Task<Unit>
  -> Task<Unit> = action

fn queryError error: dom.DomError
  -> String = show error

alias DomFailure =
  dom.DomRuntimeError<Never>

fn runtimeError error: DomFailure
  -> String = show error

pub effect fn main = do {
  count <- signals.make 0
  let content =
    signals.map (view count) count
  target <-
    dom.query "#app"
    |> mapError queryError
  let opts = dom.defaultOptions ()
  dom.run opts target perform content
  |> mapError runtimeError
}
```

`Counter` is a [type alias](/en/docs/learn/records-and-structs) for `MutableSignal<Int>`, and `View` is an alias for `Html<Task<Unit>>`. Pass `view` both the Signal to update and the current integer to display. HTML props are records; `children` holds text or child elements.

`signals.update` builds a Task that calculates the next value from the current one; `signals.set` builds a Task that writes the specified value. Placing a Task in `onClick` does not run it. On a click, `dom.run` passes it to `perform` and executes the returned Task.

## Try it on the development server

Update the lock, then start the development server.

```sh
seseragi lock update
seseragi dev --open
```

Open `http://127.0.0.1:3000/` to see “Count: 0”. Press “Add one” twice for “Count: 2”, then “Reset” to return to “Count: 0”.

Saving the source reloads the page, so the counter also returns to 0.

## Connect the Signal to the screen

In `main`, execute `signals.make 0` once to create storage for the number. `signals.map (view count) count` is a read-only Signal that computes HTML from the number. When the number changes, it follows the result of calling `view` with that new number. Computing the screen never recreates state.

Find the `#app` element with `dom.query`, then pass the screen's Signal to `dom.run`. It keeps receiving screen changes and events, and releases its subscriptions and listeners when it ends. Events are processed in order. See the [Web UI reference](/en/docs/reference/web-ui) for the detailed rules.

`queryError` and `runtimeError` turn failures from finding the target or running the screen into `String`. `mapError` aligns their failure types. See [Handle failures](/en/docs/guides/error-handling) for failure handling.

## Style and build it

Pass styles made with `html.style` to `style`. Here, `maxWidth`, `margin`, and `padding` limit the width, center the content, and add inner space. Use `class` for CSS class names.

Stop the development server with `Ctrl-C`, update the lock, and build.

```sh
seseragi lock update
seseragi build .
```

The `dist/` directory contains `index.html`, JavaScript, and CSS. Serve it over HTTP or static hosting.
